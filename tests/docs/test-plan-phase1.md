- 订单管理与泳道看板拖拽
- 销售开单与收银台流程
- 库存、报表、预警等核心模块

- 后端：Node.js + Express + mock-db（端口 3000）
- 前端：Vue 3 + Element Plus + Vite（端口 5173）
- 浏览器：Chrome 最新版
