
# 智享全链管理系统 - 测试计划 (Sprint 1: 2026/06/17 - 2026/06/24

## 1. 项目概述

智享全链管理系统是一个面向酒类进销存与批发/零售的综合业务系统，主要包含：

- 工作台（Admin：管理员/商品/订单/库存/收款/退款/报表
- 门店操作端（Store）：门店库存查询、快速开单、离线收款、挂单/取单、订单接单/完成
- 微信小程序（Miniapp）：商品浏览、下单、订单详情、分享收款页
- 支付回调/分享收款（Payment/Share）：支付状态管理

## 3. 测试范围

### 3.1 功能测试（Functional Testing）

#### 3.1.1 认证模块 (Auth)

- 管理员登录（用户名密码验证）
- JWT Token 有效
- Token 过期处理
- 未登录访问受限接口

#### 3.1.2 商品管理 (Products)

- 商品列表查询（分页/搜索）
- 创建商品（含 SKU、价格体系）
- 查询商品详情
- 商品价格调整

#### 3.1.3 门店管理 (Stores)

- 门店列表
- 新增门店
- 门店信息查询

#### 3.1.4 订单管理 (Orders)

- 订单列表（分页/筛选/搜索）
- 订单详情查询
- 订单状态变更
- 订单导出 CSV

#### 3.1.5 销售单 (Sale Bills)

- 销售单创建
- 销售单列表查询
- 销售单详情查询
- 销售单分享收款链接生成
- 销售单离线收款
- 销售单收款状态变更

#### 3.1.6 库存管理 (Inventory)

- 库存总览
- 库存流水（变动记录
- 库存预警（低库存提醒）
- 门店库存查询
- 门店库存调整

#### 3.1.7 客户管理 (Members)

- 客户列表
- 客户新增
- 客户分配给销售员
- 客户价格历史

#### 3.1.8 收款与退款 (Payment/Refund)

- 分享收款链接管理
- 支付记录查询
- 退款记录查询
- 分享收款页 (miniapp pagesharecollection

#### 3.1.9 挂单 (Hold Orders)

- 创建挂单
- 挂单列表
- 取单恢复挂单
- 删除挂单

#### 3.1.10 报表 (Reports)

- 后台看板（今日销售、待收款、待处理订单、库存预警
- 近 日报销售趋势
- 订单状态分布
- 门店业绩
