## 开发规范

1. Vue 3 Composition API + `<script setup>`
2. 样式使用 CSS Variables（tokens.css）
3. API 调用统一封装在 api.ts
4. 表单校验使用 Element Plus 规则
5. 金额显示保留两位小数，千分位格式化
6. 响应式适配（移动端优先，兼容不同屏幕宽度）
7. 加载状态、空状态、错误提示统一处理
8. 列表页统一分页/下拉刷新模式
