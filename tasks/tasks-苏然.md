### 🟡 P1 - 编写核心模块测试用例 [R4-01]
**截止时间**：6/30（周二）
**预计耗时**：24 小时
**依赖**：阿坚完成 R2-01 分层改造后，配合补充测试

**目标**：为整改后的核心模块编写测试，确保重构不引入回归。

**测试模块清单**：

| 测试模块 | 测试文件 | 覆盖内容 | 预计用例数 |
|---------|---------|---------|-----------|
| 认证模块 | auth.test.ts | 登录/注册/JWT 生成/权限校验/密码加密 | 20+ |
| 商品模块 | product.test.ts | CRUD/价格/状态切换/分类/搜索 | 25+ |
| 订单模块 | order.test.ts | 创建/状态流转/审核/取消/金额计算 | 30+ |
| 库存模块 | inventory.test.ts | 查询/调整/预警/出入库/台账 | 25+ |
| 支付模块 | payment.test.ts | 收款/退款/状态同步/对账 | 20+ |
| tenant 隔离 | tenant.test.ts | 多租户数据隔离验证/越权检查 | 15+ |

**每个模块测试覆盖**：
1. **正常流程** - 主要业务路径
2. **异常流程** - 参数错误、权限不足、数据不存在
3. **边界值** - 金额精度、数量极值、分页边界
4. **并发场景** - 同时下单、同时收款、库存并发扣减
5. **数据一致性** - 事务回滚、状态流转完整性

**重点关注（金额精度）**：
- 0.01 元精度测试
- 大额金额（9999999.99）测试
- 多商品合计精度
- 折扣/抹零计算精度
- 四舍五入边界值

**重点关注（tenant 隔离）**：
- 租户 A 创建的数据，租户 B 看不到
- 租户 A 修改/删除不了租户 B 的数据
- 全局列表/统计仅返回当前租户数据
- 越权访问返回 403 或空数据

**验收标准**：
- [ ] 至少 6 个测试文件
- [ ] 核心 API 测试覆盖率达到 60% 以上
- [ ] 所有测试通过
- [ ] tenant 隔离专项测试完整
