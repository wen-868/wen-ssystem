## 详细说明

### 1. 管理后台工作台 设计稿
- **输出位置**：`docs/design/specs/dashboard-admin.html`
- **设计范围**：经营概览页 + 数据看板页
- **关键设计点**：
  - 顶部：欢迎语 + 日期 + 门店选择器（多门店切换）
  - 核心指标行：8个指标卡片（今日销售额/订单数/毛利/客单价/待收款/库存预警/待处理订单/今日新增客户），每卡片含数值+环比/同比标签
  - 图表区：2x2 网格布局（近7天/30天销售趋势折线图、品类销售占比饼图、Top10商品排行柱状图、Top10客户排行柱状图）
  - 预警区：多维度预警列表（库存预警/临期预警/应收逾期/待处理订单），支持折叠展开
  - 响应式：大屏4列卡片 → 中屏2列 → 小屏1列
  - 遵循 Design Tokens v3.0 色彩体系
- **说明**：工作台是管理后台首页，需体现"一眼看清经营全貌"的设计理念。参考 Element Plus 设计规范，但需要更强的视觉层次感。

### 2. 商户端工作台 设计稿
- **输出位置**：`docs/design/specs/dashboard-merchant.html`
- **设计范围**：商户首页 Dashboard + 待办列表
- **关键设计点**：
  - 顶部：门店名称 + 角色标签 + 消息铃铛（带未读红点）+ 日期
  - 核心指标：2x2 网格卡片（今日销售额/今日收款/待配送订单/待收款金额），每卡片含迷你趋势图
  - 待办提醒区：横向滑动卡片或列表，按类型分组（库存预警/订单待处理/客户跟进），含优先级色标
  - 销售趋势：近7天柱状图（移动端适配的简化图表）
  - 快捷入口：可配置的宫格布局（默认3x2或4x2），含图标+文字
  - 消息通知预览：最近3条通知摘要，点击展开全部
  - 遵循 Vant 设计规范，移动端触控友好
- **说明**：商户端首页是老板/店员最常打开的页面，需突出"关键指标+待办+快捷入口"三要素。参考 Vant Design 组件库。

### 3. 消息通知 设计稿
- **输出位置**：`docs/design/specs/notification-center.html`
- **设计范围**：管理后台消息中心页面 + 商户端通知页面增强
- **关键设计点**：
  - 管理后台消息中心：右侧滑出抽屉或独立页面，Tab分类（全部/系统/订单/支付/预警/信用/召回），列表项含图标+标题+摘要+时间+已读状态，支持全部已读/批量操作
  - 消息铃铛图标：顶部导航栏显示未读计数红点
  - 商户端通知页面：当前 `NotificationView.vue` 已基本完整，需增强：支持消息推送设置（免打扰时段/通知类型开关）、消息分组折叠
  - 通知详情：管理后台用弹窗展示，商户端沿用现有页面跳转
- **说明**：管理后台消息中心从零设计，商户端通知页面基于现有设计做增强。统一通知中心设计语言。

### 4. 快捷入口 设计稿
- **输出位置**：`docs/design/specs/quick-entry-config.html`
- **设计范围**：管理后台快捷入口配置页 + 快捷入口展示组件
- **关键设计点**：
  - 配置页面：左侧可拖拽入口列表 + 右侧预览区，支持拖拽排序、启用/禁用开关、分组管理、角色可见性设置
  - 入口卡片：图标选择器（内置 Element Plus Icons）+ 名称编辑 + 路由关联
  - 展示组件：管理后台 Dashboard 页面的快捷入口区域（宫格或横向滚动），商户端 HomeView 的快捷入口区域
  - 分组展示：按 group_name 分组，每组一个标题栏
  - 默认预设：管理后台8个入口 + 商户端6个入口，作为初始化数据
- **说明**：快捷入口需同时设计配置端和展示端。配置端给管理员使用，展示端嵌入工作台。需考虑不同角色看到的入口不同。
