## 详细说明

### 1. 经营总览+销售分析设计稿
- **场景**：管理后台首页经营驾驶舱 + 销售深度分析
- **经营总览内容**（~40字段）：
  - 顶部4个概要卡片：今日销售额（含环比%箭头）、今日订单数（含环比%箭头）、今日毛利（含环比%箭头）、客单价（含环比%箭头）
  - 销售趋势图：近30日销售额/订单数双轴折线柱状混合图
  - 时段销售分布：按小时统计的销售热力分布（柱状图）
  - 门店排行：各门店销售额/订单数/毛利横向柱状图
  - 品类销售占比：饼图
  - 支付方式分布：饼图
  - 最近订单列表：最新10笔订单（单号/客户/金额/状态）
  - 日期切换：今日/昨日/本周/本月/自定义
- **销售分析内容**（~45字段）：
  - 销售趋势折线图（日/周/月粒度切换，销售额+订单数+客单价三线）
  - 时段热力图（横轴日期×纵轴小时，颜色深浅表示销售额）
  - 销售排行TOP20：商品/客户/门店/业务员四个维度Tab切换
  - 同期对比：本期vs上期销售额/订单数/客单价对比表
  - 销售日报明细表：日期/销售额/订单数/客单价/退款金额/退款率
- **输出**：`docs/design/specs/20-dashboard-sales-analysis.html`

### 2. 在线收款专项分析设计稿
- **场景**：管理后台收款漏斗和渠道分析（~50字段）
- **内容**：
  - 收款总览卡片：累计收款总额/本月收款/今日收款/待收金额/退款率/平均收款周期
  - 收款漏斗图（Funnel Chart）：分享数→查看数→支付数→支付成功数，各环节标注转化率和流失率
  - 收款趋势图：近30日收款金额/笔数双轴折线图，支持按渠道拆分
  - 渠道分布图：饼图展示各渠道收款金额占比（微信/支付宝/银行卡/现金/其他）
  - 渠道转化率对比表：渠道名称/分享数/查看数/支付数/支付金额/转化率/占比
  - 超时未付分析：超时订单列表（订单号/客户/金额/超时时长/状态），超时区间分布饼图（<30min/30-60min/1-2h/2-24h/24h+）
  - 超时趋势图：近30日超时率趋势折线图
  - 退款分析：退款金额/退款率趋势，退款原因分类饼图
- **输出**：`docs/design/specs/21-collection-analysis.html`

### 3. 商品分析+客户分析设计稿
- **场景**：管理后台商品和客户维度深度分析
- **商品分析内容**（~45字段）：
  - 商品概览卡片：SKU总数/动销SKU数/动销率/库存总额/库存周转天数
  - 畅销TOP20排行榜：商品名/品类/销量/销售额/毛利/毛利率，支持排序切换
  - 滞销预警列表：商品名/品类/库存量/最近销量/滞销天数/预警等级（红/橙/黄）
  - 毛利排行：商品名/品类/销售额/成本/毛利/毛利率，支持正序倒序
  - 品类销售分析：各品类销售额/销量/毛利/占比，含饼图和柱状图
  - 商品ABC分析：按销售额累计占比分为A类（前70%）/B类（70-90%）/C类（90-100%），饼图展示占比和SKU数
  - 新品表现：近30天上架新品销售额排行
- **客户分析内容**（~35字段）：
  - 客户概览卡片：客户总数/本月新增/活跃客户数/流失客户数/复购率
  - 客户贡献排行TOP20：客户名/累计消费金额/订单数/客单价/最近消费日期
  - 复购率趋势图：按月统计复购率折线图
  - 客单价分布：按区间（<100/100-300/300-500/500-1000/1000-3000/3000+）的客户数/订单数分布柱状图
  - RFM分析矩阵：散点图或分组表格，按R/F/M评分分群（8个客户群体）
  - 新增客户趋势：按月新增客户数折线图
  - 流失客户预警：超过N天未消费客户列表，含流失趋势
- **输出**：`docs/design/specs/22-product-customer-analysis.html`

### 4. 库存分析+采购分析设计稿
- **场景**：管理后台库存和采购维度分析
- **库存分析内容**（~30字段）：
  - 库存概览卡片：库存总额/库存总量（按箱/瓶）/库存SKU数/呆滞品数量/周转天数
  - 库存周转天数趋势：近12月周转天数折线图
  - 库龄分布：按入库时间分段（<30天/30-60天/60-90天/90-180天/180天+）的库存金额/占比柱状图和饼图
  - 呆滞品预警列表：商品名/品类/库存量/库龄/最近出库日期/预警等级，支持按预警等级筛选
  - 库存价值排行：按库存金额排序的商品TOP20
  - 出入库趋势：近30日入库/出库数量/金额双轴折线图
  - 安全库存预警：库存低于安全库存的商品列表
- **采购分析内容**（~25字段）：
  - 采购概览卡片：本月采购总额/采购笔数/到货率/采购成本/供应商数
  - 采购趋势图：近12月采购金额/笔数趋势折线图
  - 供应商采购排行TOP10：供应商名/采购金额/采购笔数/占比/到货率
  - 品类采购分析：按品类统计采购金额/占比饼图
  - 采购成本变动：主要商品采购单价趋势折线图
  - 采购到货时效：下单到到货平均天数趋势
- **输出**：`docs/design/specs/23-inventory-purchase-analysis.html`

### 5. 财务分析+员工绩效设计稿
- **场景**：管理后台财务和员工维度分析
- **财务分析内容**（~30字段）：
  - 财务概览卡片：本月收入/本月支出/净利润/利润率/应收余额/应付余额
  - 利润趋势图：近12月收入/成本/费用/利润四线折线图
  - 收入结构分析：销售收入/其他收入占比饼图
  - 支出结构分析：采购成本/人员工资/运营费用/其他支出占比饼图
  - 费用分类分析：按费用类别（日常/差旅/办公/运输/其他）统计金额/占比柱状图+饼图
  - 应收应付趋势：近12月应收/应付余额双线折线图
  - 现金流趋势：近12月现金流入/流出/净现金流三线图
  - 毛利率趋势：近12月毛利率折线图
- **员工绩效分析内容**（~40字段）：
  - 员工概览卡片：销售人员总数/本月销售冠军/人均销售额/人均订单数
  - 员工业绩排行TOP10：员工名/销售额/订单数/毛利/客单价/新客数/复购率
  - 员工销售趋势：选定员工近12月销售额/订单数趋势折线图
  - 员工对比雷达图：选定2-3名员工的销售额/订单数/毛利/客单价/新客数/复购率六维雷达图
  - 员工时段分析：各员工按小时的销售分布热力图
  - 员工业绩达成率：目标vs实际销售额对比柱状图
- **输出**：`docs/design/specs/24-finance-staff-analysis.html`

### 6. 商户端报表设计稿
- **场景**：商户移动端查看经营数据
- **内容**：
  - 商户经营概览：今日销售额/订单数/毛利/客单价4个卡片，近7日销售趋势迷你折线图
  - 商户销售分析页：日/周/月销售趋势折线图，商品销售排行TOP10列表，客户贡献排行TOP10列表
  - 商户收款分析页：收款总额卡片，收款渠道分布饼图，待收列表（客户/金额/到期日/状态），收款记录列表
  - 商户库存分析页：库存概览卡片（库存总额/SKU数/周转天数），库存预警列表（红/橙/黄分级），呆滞品列表
  - 商户客户分析页：客户贡献排行TOP10，新客/老客/流失客户分布饼图，客户采购排行列表
  - 商户财务分析页：本月收入/支出/利润卡片，收支趋势折线图，费用分类饼图
  - 底部Tab导航：经营概览/销售/收款/库存/客户/财务
  - 适配移动端：卡片式布局，下拉刷新，时间筛选器
- **输出**：`docs/design/specs/25-merchant-reports.html`
