## 详细说明

### 1. 支付配置页面设计稿
- **文件**：`docs/design/specs/payment-config-page.html`
- **内容**：管理后台支付配置页面，3个Tab（微信支付/支付宝/银行账号）
- **微信支付Tab**：启用开关 + 重要提示 + 6个表单字段（AppID/商户号/API密钥/证书序列号/私钥/回调地址）+ 测试连接
- **支付宝Tab**：启用开关 + 4个表单字段
- **银行账号Tab**：3张银行卡片（工行默认/建行/农行）+ 添加/编辑弹窗 + 脱敏显示

### 2. 小程序配置页面设计稿
- **文件**：`docs/design/specs/miniapp-config-page.html`
- **内容**：管理后台小程序配置页面，4个平台Tab（微信/支付宝/抖音/快手）
- **凭证配置**：AppID + AppSecret + 名称 + 图标上传
- **模板选择**：3列网格（经典蓝白/暖橙商务/深色臻品），选中态蓝色边框
- **一键发布**：loading spinner + 成功/失败结果 + 发布历史表格

### 3. 3套模板预览设计稿
- **文件**：`docs/design/specs/miniapp-template-preview.html`
- **内容**：3套模板 x 3个页面 x 375px手机框 = 9个预览页面
- **经典蓝白**：蓝色主题，简洁大方，step式下单
- **暖橙商务**：橙色主题，温暖亲切，list式下单
- **深色臻品**：黑金配色，高端奢华，minimal式下单
- **模板对比表**：14项styleConfig对比维度
