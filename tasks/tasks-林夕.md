### 1. 营销活动中心统一设计稿

- **接口/文件**：`docs/design/specs/26-marketing-center.html`
- **关键设计元素**：
  - 营销中心首页布局：顶部活动概览卡片（进行中/即将开始/已结束活动数量统计）

  - 中央工作区：Tab切换式内容区，默认展示优惠券模板列表

- **说明**：
  - 作为营销中心的统一入口页面，整合现有 MarketingView.vue 和 MarketingPromotion.vue 的功能布局
  - 提供清晰的活动生命周期视觉呈现（草稿-进行中-已结束）
  - 设计需与现有 UI 设计规范（01-design-system-spec.html）保持一致

### 2. 限时折扣+满赠设计稿

- **接口/文件**：`docs/design/specs/27-limited-discount-gift.html`
- **关键设计元素**：
  - 限时折扣Tab：
    - 折扣活动列表：表格展示活动名称、折扣力度、时间范围、适用商品数、库存状态、参与人数
    - 新建/编辑表单：活动基本信息（名称/描述/时间）、折扣类型选择（百分比/固定金额）、折扣值输入
    - 商品选择器：弹窗式商品选择（支持搜索/分类筛选/多选），展示商品名称/原价/折扣价
    - 库存管理：显示总库存/已售/剩余，库存进度条
    - 倒计时组件：距活动开始/结束的动态倒计时（天-时-分-秒）
  - 满赠规则Tab：
    - 满赠规则列表：规则名称、满赠条件（满X元/满X件）、赠品信息、有效期、状态
    - 多级满赠配置：可视化层级编辑器（满100赠A，满200赠B，满300赠C）
    - 赠品选择器：弹窗选择赠品商品、设置赠送数量
    - 库存联动提示：赠品库存不足时红色警告标识
    - 规则预览：模拟购物车满赠效果预览
  - 统一表单交互：时间段选择器（日期+时间）、启停开关、删除确认
- **说明**：
  - 限时折扣和满赠规则共用一个页面，通过 Tab 切换
  - 折扣活动需突出时间紧迫感，倒计时使用醒目颜色
  - 满赠规则的层级编辑器需直观展示阶梯关系

### 3. 积分商城设计稿

- **接口/文件**：`docs/design/specs/28-points-mall.html`
- **关键设计元素**：
  - 兑换商品管理列表：
    - 商品卡片网格布局（4列），每张卡片展示：商品图片、商品名称、所需积分（大字号突出）、市场参考价（删除线）、库存余量
    - 上架/下架状态标签（绿色ON/灰色OFF）
    - 操作按钮：编辑、上架/下架、删除
  - 新建/编辑兑换商品表单：
    - 商品图片上传（支持拖拽）、商品名称、描述
    - 所需积分输入（整数校验）、市场参考价
    - 库存设置（总库存/每人限兑次数/总限兑次数）
    - 排序权重设置
  - 兑换记录列表：
    - 表格展示：兑换编号、用户信息、商品名称、消耗积分、兑换数量、兑换时间、状态
    - 状态筛选：待确认/已确认/已取消
    - 操作：确认兑换、取消兑换（退回积分）
  - 积分统计卡片：商城总兑换量、总消耗积分、热门兑换商品排行
- **说明**：
  - 商品卡片设计需有吸引力，突出积分消耗的"价值感"
  - 库存不足商品自动展示"已兑完"遮罩
  - 兑换记录支持分页和时间范围筛选

### 4. 营销看板+素材库设计稿

- **接口/文件**：`docs/design/specs/29-marketing-dashboard.html`
- **关键设计元素**：
  - 营销看板Tab：
    - 顶部概览卡片行：活动总数、进行中、已结束、参与总人数、发放优惠券数、核销率
    - 活动效果趋势图（ECharts 折线图）：按日/周/月展示参与人数、转化率、优惠金额趋势
    - 活动ROI排行（ECharts 柱状图）：各活动投入产出比对比
    - 活动类型分布（ECharts 饼图）：优惠券/满减/限时折扣/满赠/积分各类型占比
    - 活动对比表：选择2-4个活动，对比参与人数、转化率、GMV、ROI
    - 时间筛选器：日期范围选择器 + 快捷按钮（今天/本周/本月/近30天）
  - 素材库Tab：
    - 素材网格布局（瀑布流）：图片缩略图、素材名称、分类标签、使用场景标签
    - 左侧分类树：按使用场景分类（海报/优惠券背景/秒杀背景/公众号文章/其他）
    - 素材详情弹窗：大图预览、文件信息（大小/尺寸/格式）、使用统计（下载/查看/使用次数）
    - 上传区域：拖拽上传区，支持批量上传，上传进度条
    - 素材操作：重命名、修改标签、发布/归档、删除
    - 搜索筛选栏：关键词搜索 + 类型筛选 + 分类筛选 + 标签筛选
  - 响应式：看板图表在平板端堆叠为单列，素材瀑布流自适应列数
- **说明**：
  - 营销看板需使用 ECharts 图表库，配色与系统主题一致
  - 素材库需支持图片预览（lightbox效果）
  - 素材库的上传区域需有清晰的视觉引导

### 5. 商户端营销中心设计稿

- **接口/文件**：`docs/design/specs/30-merchant-marketing.html`
- **关键设计元素**：
  - 营销Tab页入口：
    - 底部导航栏新增"营销"Tab（图标：促销喇叭）
    - 营销中心首页：顶部轮播Banner（当前热门活动）、活动分类入口卡片
    - 入口卡片设计：优惠券（券图标+数量角标）、限时折扣（闪电图标+倒计时）、积分商城（金币图标+积分余额）、秒杀（灰色置灰+即将上线标签）
  - 优惠券页面：
    - 顶部Tab切换：可用券、领取中心、我的券包
    - 可用券列表：券卡片设计（面值大字/使用条件/有效期/适用范围），可领取按钮
    - 领取中心：可领取券列表，领取按钮+领取进度条
    - 我的券包：已领取券列表，按状态分组（未使用/已使用/已过期），使用按钮（去使用）
  - 限时折扣页面：
    - 折扣商品列表：商品卡片（商品图/原价删除线/折扣价红色大字/倒计时/已售进度条）
    - 限时折扣专区：头部倒计时Banner（距结束还有XX:XX:XX）
    - 库存标签：库存紧张（红色）/ 库存充足（绿色）
  - 积分商城页面：
    - 顶部积分余额展示：当前积分（大字号），积分明细入口
    - 兑换商品列表：商品卡片（商品图/所需积分/市场参考价/库存余量）
    - 兑换按钮：积分不足时灰色置灰+提示
    - 兑换记录：我的兑换列表（商品/消耗积分/兑换时间/状态）
  - 移动端适配：375px 基准，卡片式布局，触控友好的按钮尺寸（最小44px）
- **说明**：
  - 商户端是移动端H5/小程序场景，设计需轻量高效
  - 优惠券领取需有动画反馈（领取成功飘落效果）
  - 秒杀模块灰色置灰，标记"即将上线"
  - 积分商城设计需突出"免费兑换"的心智

### 6. 营销设计规范补充

- **接口/文件**：`docs/design/specs/31-marketing-design-system.html`
- **关键设计元素**：
  - 促销色系定义：
    - 主促销色：`#FF4757`（促销红，用于折扣标签、秒杀按钮、倒计时）
    - 辅助促销色：`#FF6348`（橙红，用于满减标签）、`#FFA502`（暖橙，用于优惠券）
    - 积分色：`#F9CA24`（金币黄，用于积分展示）
    - 成功/库存充足：`#2ED573`（翠绿）
    - 警告/库存紧张：`#FF4757`（促销红）
    - 置灰/不可用：`#B2BEC3`（灰蓝）
  - 倒计时组件规范：
    - 数字字体：DIN / monospace，字号 24px/20px/16px（大/中/小）
    - 分隔符 ":" 闪烁动画（1s周期）
    - 背景：深色半透明卡片 `rgba(0,0,0,0.6)`
    - 颜色：距结束>1小时白色，<1小时促销红，<10分钟脉冲闪烁动画
  - 抢购动效：
    - 按钮点击波纹效果（从点击中心扩散，300ms ease-out）
    - 商品卡片 hover 上浮效果（translateY(-4px) + 阴影加深，200ms）
    - 库存减少进度条动画（linear 过渡）
    - 领取成功飘落动画（粒子效果，从按钮位置向上飘散）
  - 促销标签组件：
    - "限时"标签：红色背景+白色文字+闪电图标
    - "满赠"标签：橙色背景+礼物图标
    - "秒杀"标签：红色渐变背景+文字+脉冲动画
    - "已领完"标签：灰色背景+文字
  - 活动状态徽章：
    - DRAFT：灰色圆角矩形
    - ACTIVE：绿色圆角矩形+左侧呼吸灯
    - PAUSED：黄色圆角矩形
    - ENDED/EXPIRED：灰色圆角矩形+删除线效果
  - 与现有设计规范衔接：继承 01-design-system-spec.html 的色彩/字体/间距/圆角体系
- **说明**：
  - 本文件是营销模块的视觉规范补充，定义营销特有的色彩、动效和组件
  - 需提供完整的 CSS 变量定义和 Tailwind 扩展配置
  - 倒计时和动效需提供 CSS Animation 关键帧代码参考
  - 所有组件需同时提供浅色/深色两套配色方案
