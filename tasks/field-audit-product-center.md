### 4.1 标签与属性管理（P0，~50字段）

酒水行业需要的标签体系：

| 标签类型 | 示例值 | 实现方式 |
|---------|--------|------|
| 香型 | 酱香型/浓香型/清香型/米香型/兼香型/凤香型 | 标签组（可配置） |
| 度数段 | 低度(<38°)/中度(38°-50°)/高度(>50°) | 自动计算（基于 alcohol_content） |
| 产区 | 茅台镇/宜宾/泸州/汾阳/宿迁/亳州 | 标签组（可配置） |
| 适用场景 | 自饮/宴请/送礼/收藏/商务 | 标签组（可配置） |
| 年份 | 2024/2023/2020/老年份 | 标签组（可配置） |

需要新建 `product_tag_group` 和 `product_tag` 和 `product_tag_relation` 表。

### 4.2 商品营销标签（P0，~26字段）

| 营销标签 | 用途 |
|---------|------|
| 新品 | 新品推荐位 |
| 爆款 | 销量排行 |
| 热销 | 热门推荐 |
| 推荐 | 编辑推荐 |
| 限时特价 | 促销活动 |
| 清仓 | 库存清理 |

在 `product_spu` 表新增 `marketing_tags` JSON 字段存储。

### 4.3 批次追溯与有效期（P1，~45字段）

`inventory_batch` 表已存在，需要：
- 后端：批次列表/详情/追溯链查询 API
- 管理后台：批次管理页面（列表 + 详情 + 追溯链可视化）
- 移动端：批次信息查看
