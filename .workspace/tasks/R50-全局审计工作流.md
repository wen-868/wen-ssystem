**负责人**：阿坚
**预计**：0.5天
**前置**：无，可立即开始

### 修改清单

| 文件 | 当前前缀 | 修改为 | auth |

| `backend/src/routes/platform-review.routes.ts` | `/api/platform-review` | `/api/platform/reviews` | requirePlatformAuth ✅ |
| `backend/src/routes/platform-tenant.routes.ts` | `/api/platform-tenant` | `/api/platform/tenants` | none → **requirePlatformAuth** |
| `backend/src/routes/platform-monitor.routes.ts` | `/api/platform-monitor` | `/api/platform/monitor` | none → **requirePlatformAuth** |
| `backend/src/routes/platform-auth.routes.ts` | `/api/platform-auth` | `/api/platform/auth` | none（登录路由，合理） |

### 验收标准
- `tsc --noEmit` 0 错误
- 全局搜索 `prefix.*"/api/platform-` 无结果（除 platform-reconciliation/review/tenant/monitor/auth 外均应无匹配）

**负责人**：阿坚
**预计**：1天
**前置**：无，可立即开始

### 问题描述

约16个 `admin-*.routes.ts` 文件的 `auth` 字段为 `"none"`，意味着这些路由没有中间件认证保护。部分路由可能是登录/公开接口（合理），但大部分应该是业务路由，需要 `requireAuthWithTenant`。

- `admin-auth.routes.ts` — 登录路由，合理
- `admin-staff.routes.ts` — 可能需要认证
- `error-log.routes.ts` — 可能需要认证
- `feedback.routes.ts` — 可能需要认证

**auth=none 大概率不合理**（应该加认证）：
- `admin-product.routes.ts` — 商品管理，应该加 `requireAuthWithTenant`
- `admin-inventory.routes.ts` — 库存管理，应该加 `requireAuthWithTenant`
- `admin-store.routes.ts` — 门店管理，应该加 `requireAuthWithTenant`
- `admin-order.routes.ts` — 订单管理，应该加 `requireAuthWithTenant`
- `admin-report.routes.ts` — 报表，应该加 `requireAuthWithTenant`
- `admin-system.routes.ts` — 系统设置，应该加 `requireAuthWithTenant`
- `admin-credit.routes.ts` — 信用管理，应该加 `requireAuthWithTenant`
- `admin-customer.routes.ts` — 客户管理，应该加 `requireAuthWithTenant`
- `admin-marketing-*.routes.ts` 系列 — 营销，应该加 `requireAuthWithTenant`
- `inventory-profit-loss.routes.ts` — 损益，应该加 `requireAuthWithTenant`

**非标准前缀路由（需要同时修正前缀）**：
