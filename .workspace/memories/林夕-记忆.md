## 七、踩坑教训（林夕相关）

### 颜色体系不统一

- **现象：** onepan.cn 首页重设计方案最初使用金色（#C8A45C）主题，与系统统一蓝色（#1677FF）不匹配
- **原因：** 参考了原网站的酒行业金色配色，未核对系统统一设计令牌
- **解决：** 全部替换为系统蓝色主题，grep 确认零金色残留
- **教训：** 所有设计稿必须使用 `admin-web/src/styles/tokens.css` 中的设计令牌，不得自定义品牌色

### onepan.cn 页面分析受限

- **现象：** WebFetch 返回的是 HTML Sitemap 而非实际页面内容
- **原因：** onepan.cn 对某些 User-Agent 返回 sitemap
- **解决：** 改用 `curl -sL` 直接下载页面源码到本地文件进行分析
- **教训：** 页面分析优先使用 curl 下载源码，不依赖 WebFetch

### 设计稿颜色硬编码问题

- **现象：** R8-L2 审查发现 Reports.vue、Orders.vue 等前端代码中存在硬编码颜色值
- **原因：** 开发人员未使用设计令牌，直接写了 hex 色值
- **解决：** 在审查报告中标注，建议替换为 `var(--color-*)` 令牌
- **教训：** 设计规范中必须明确标注令牌变量名，方便开发人员引用

### 第十二章：强制闭环流程（全员必遵守）

```
读取任务 → 执行 → 验证 → 总结 → 提交 → 更新踩坑日志 → 推送
```
