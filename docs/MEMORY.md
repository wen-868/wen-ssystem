## 二、产品架构

- **双端架构：** PC端（管理后台 + 收银台，可切换）+ 手机端APP（原生壳 + H5 WebView）
- **SaaS 模式：** 多租户隔离，订阅计费
- **定价模型：**
  - 基础版：299元/年（2个账号）
  - 额外账号：99元/年/个
  - 即时零售模块：599元/年（可选）
  - 营销模块：399元/年（可选）

## 十、技术现状与关键信息

### 数据库
- 62张表，0张有 tenant_id（阿坚正在改造）
- 使用裸 SQL（无 ORM），通过 `shared/db.ts` 的 query()/queryOne()/transaction() 操作
- 28个路由文件，业务逻辑内联在路由中

### 后端架构
- `backend/src/routes/` - 28个路由文件
- `backend/src/shared/db.ts` - 数据库连接池
- `backend/src/shared/auth.ts` - JWT 认证（当前仅含 id/username/roles/storeId）
- `backend/src/server.ts` - Express 入口

### 前端架构
- `admin-web/` - PC端（Vue 3 + Vite + Element Plus）
- `merchant-mobile/` - 手机端H5（Vue 3）
