## 一、设计语言总述

**一句话**：以 Swiss 结构语言为骨架（品牌蓝、白底、1px 细线、左对齐、克制无装饰），融入参考图的高端卡片精致度（卡片分层、柔和阴影、圆角、适中留白、精致图表、清晰字体层级）。

### 1.1 三条铁律

1. **配色纪律**：页面只出现 白/中性灰/品牌蓝 #3F6FEF/语义状态色（成功/警告/危险/信息），禁止装饰性彩色与花哨渐变（登录页品牌区除外）。
2. **字体纪律**：大标题（页头 20px/700）→ 正文（13-14px/400-500）→ 辅助文字（12px/#999）；金额/数量一律 `font-variant-numeric: tabular-nums` 等宽对齐。
3. **图标纪律**：统一使用 Element Plus 图标库（扁平线性），禁止 emoji/unicode 字符当图标、禁止 AI-slop 文案、禁止玻璃拟态（登录品牌区除外）。

### 1.2 参考图要点（已提炼）

| 维度 | 参考图表现 | 本项目落地 |
|------|-----------|-----------|
| 卡片 | 轻阴影分层、圆角 8-12px | `--shadow-card` / `--shadow-hover` / `--shadow-modal` 三档 + 圆角 10px |
| 指标卡 | 大数字构图（28-32px/700）+ 环比小字 | `--metric-value-size: 28px` + 环比标签 |
| 表格 | 表头灰底、适中行高、状态标签语义色 | 表头 `#F8F8F8`、行高 44px、浅底彩字标签 |
| 图表 | 渐变/统一配色/网格线 hairline | `--chart-*` 色板 + `--chart-grid` 网格色 |
| 留白 | 适中（信息密度适度放宽） | 页面 padding 24px、卡片 gap 16px |

### 2.4 间距 / 圆角 / 状态标签

- 间距：4px 基准 8 级（`--space-1..8`），页面 `--space-page-padding: 24px`、卡片 `--space-card-padding: 16px`。
- 圆角：控件 4-6px（`--radius-xs/sm`）、卡片 10px（`--radius-lg`）、弹窗 12px（`--radius-xl`），禁止胶囊（登录/收银台特例除外）。
- 状态标签：浅底彩字（底 = 语义色 12% 透明，字 = 语义色），`--tag-radius: 6px`、`--tag-padding: 3px 10px`、12px/500。
- 图表色：`--chart-1..6`（蓝/绿/橙/红/紫/青），网格线 `--chart-grid: #EEF0F3`。

## 四、四种页面骨架

### 4.1 列表页骨架（示范：商品列表）

```
页头（标题 20px/700 + 说明 + 操作按钮）
  ↓
统计条（StatBar / .stat-grid 指标卡行，大数字）
  ↓
筛选栏（.filter-bar 卡片内，el-input/el-select + 查询/重置）
  ↓
表格（.table-card 容器 + el-table，状态标签用语义色）
  ↓
分页（.table-card-footer 右对齐）
```

代码模板：

```html
<div class="page">
  <div class="page-header">
    <div class="page-header-main">
      <h2 class="page-title">页面标题</h2>
      <p class="page-desc">一句话说明</p>
    </div>
    <div class="page-header-actions">
      <el-button type="primary"><el-icon><Plus /></el-icon>&nbsp;新增</el-button>
      <el-button>刷新</el-button>
    </div>
  </div>

  <div class="filter-bar">
    <el-input v-model="keyword" placeholder="关键词" style="width: 200px" clearable />
    <el-button type="primary">查询</el-button>
  </div>

  <div class="table-card">
    <el-table :data="rows">…</el-table>
    <div class="table-card-footer">
      <el-pagination background layout="total, prev, pager, next" :total="total" />
    </div>
  </div>
</div>
```

### 4.2 表单页骨架（示范：销售开单）

```
页头（标题 + 操作按钮：保存草稿 / 提交）
  ↓
表单卡片分区（.form-card：基础信息 / 商品明细）
  ↓
右侧金额汇总（.summary-card sticky，应收大数字品牌蓝）
  ↓
底部操作栏（.form-actions-bar：取消 / 提交）
```

要点：`el-form` 三件套（ref + :model + :rules）；分区用 `.form-card-header` + `.form-card-body`；金额一律 `.amount-text` 等宽。

### 4.3 详情页骨架（示范：商品详情抽屉）

```
页头（标题 + 返回/操作）
  ↓
详情卡片 / DetailDrawer（el-descriptions 双列 + 主图）
  ↓
关联区块（.detail-section：SKU 列表 / 价格历史 / 标签）
```

要点：`.detail-section-title` 带 3px 品牌蓝竖条；描述列表标签灰、值黑；状态字段用语义色标签。

### 4.4 看板页骨架（示范：首页工作台）

```
页头（欢迎语 + 日期 + 快捷操作）
  ↓
指标卡行（.metric-card：大数字 + 环比 + 迷你趋势图）
  ↓
今日焦点（待办 / 快捷入口 / 经营助手 三卡）
  ↓
图表区（.chart-card：ECharts 灰阶 + 单蓝 accent + hairline 网格）
  ↓
明细表（.compact-table：最新订单 / 预警列表）
```

图表规范：ECharts 配色只用 `--chart-*`；网格线 `--chart-grid`；柱状/面积图可用 `--chart-gradient-primary` 渐变；金额/数量 tooltip 等宽。

## 八、可达性偏差登记（S3-47，2026-09-17 凌舟裁定）

**裁定原则：可达性优先于设计稿字面值。** 当某 token 的稿面取值不满足 WCAG AA 时，
在"达标且最接近设计稿"的范围内取值，并**在本节登记偏差**，使"改了哪里、为什么改"可追溯。

### 8.1 已登记偏差

| 项 | 设计稿原值 | 采用值 | 位置 | 依据 |
|---|---|---|---|---|
| 弱化文本（muted） | `#999999` | **`#6D6D6D`** | `admin-web/src/styles/tokens.css` → `--text-muted` | 原值在本项目四种浅底上仅 **2.50~2.85:1** |
| 侧边栏弱化文本 | `#999999` | **`#6D6D6D`** | `tokens.css` → `--sidebar-text-muted` | 原值在 `--bg-sidebar #FAFAFA` 上仅 **2.73:1** |
| Element 次级文本 | `#999999` | **`#6D6D6D`** | `admin-web/src/styles.css` → `--el-text-color-secondary` | 同左（Element 的 secondary 文本同样受 `color-contrast` 约束） |
| saas-admin 弱化文本（muted） | `#999999` | **`#6D6D6D`** | `saas-admin/src/styles/tokens.css` → `--text-muted` | 原值浅底 2.50~2.85:1；#6D6D6D 在最深浅底 `--bg-soft #f0f0f0` 上 4.54:1（约束边界同 admin-web） |
| saas-admin 侧边栏弱化文本 | `#9CA3AF` | **`#6D6D6D`** | `saas-admin/src/styles/tokens.css` → `--sidebar-text-muted` | 设计稿 `.sh-nav .ng` 取暗色侧栏值；v1.6 侧栏改白底仅 2.54:1；#6D6D6D 白底 5.17:1 |
| 图表 muted 文本（ECharts） | `#999999`（设计稿 `#a3a3a3`） | **`#6D6D6D`** | `admin-web/src/styles/theme.ts` → `CHART_COLORS.textMuted` | canvas 文字 4.5:1 / 图形 3:1；#6D6D6D 白底 5.17:1 双达标 |

### 8.2 取值推导（可复算）

本项目浅底 surface token：`--bg-card #FFFFFF`、`--bg-sidebar #FAFAFA`、`--bg-page #F5F5F5`、`--bg-soft #F0F0F0`。

| 灰阶 | vs #FFFFFF | vs #FAFAFA | vs #F5F5F5 | vs #F0F0F0 | 结论 |
|---|---|---|---|---|---|
| `#999999`（原） | 2.85 | 2.73 | 2.61 | **2.50** | ❌ 全部不达 AA 4.5:1 |
| `#767676` | 4.54 | 4.35 | **4.17** | **3.99** | ❌ 白底勉强够，但页面底色/浅灰底仍不达 |
| **`#6D6D6D`（采用）** | 5.17 | 4.96 | 4.75 | **4.54** | ✅ 四种浅底全部 ≥4.5:1 |

**约束边界**：最严场景是 `--bg-soft #F0F0F0`（4.54:1，仅高于阈值 0.04）。
⇒ **若将来新增比 `#F0F0F0` 更深的 surface token，本项必须重新计算**（不能默认沿用 `#6D6D6D`）。
