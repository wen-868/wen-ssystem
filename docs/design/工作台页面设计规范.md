## 一、设计语言总述

**一句话**：以 Swiss 结构语言为骨架（品牌蓝、白底、1px 细线、左对齐、克制无装饰），融入参考图的高端卡片精致度（卡片分层、柔和阴影、圆角、适中留白、精致图表、清晰字体层级）。

### 1.1 三条铁律

1. **配色纪律**：页面只出现 白/中性灰/品牌蓝 #3F6FEF/语义状态色（成功/警告/危险/信息），禁止装饰性彩色与花哨渐变（登录页品牌区除外）。
2. **字体纪律**：大标题（页头 20px/700）→ 正文（13-14px/400-500）→ 辅助文字（12px/#999）；金额/数量一律 `font-variant-numeric: tabular-nums` 等宽对齐。
3. **图标纪律**：统一使用 Element Plus 图标库（扁平线性），禁止 emoji/unicode 字符当图标、禁止 AI-slop 文案、禁止玻璃拟态（登录品牌区除外）。

### 1.2 参考图要点（已提炼）

| 维度 | 参考图表现 | 本项目落地 |
|------|-----------|-----------|
| 卡片 | 轻阴影分层、圆角 8-12px | `--shadow-card` / `--shadow-hover` / `--shadow-modal` 三档 + 圆角 10px |
| 指标卡 | 大数字构图（28-32px/700）+ 环比小字 | `--metric-value-size: 28px` + 环比标签 |
| 表格 | 表头灰底、适中行高、状态标签语义色 | 表头 `#F8F8F8`、行高 44px、浅底彩字标签 |
| 图表 | 渐变/统一配色/网格线 hairline | `--chart-*` 色板 + `--chart-grid` 网格色 |
| 留白 | 适中（信息密度适度放宽） | 页面 padding 24px、卡片 gap 16px |

## 二、Design Tokens（`admin-web/src/styles/tokens.css` v4.1）

### 2.1 颜色

| Token | 值 | 用途 |
|-------|----|------|
| `--color-primary` | `#3F6FEF` | 品牌蓝：按钮/链接/激活态/选中 |
| `--color-primary-hover` | `#5A83F2` | 主按钮 hover |
| `--color-primary-active` | `#2F5BD6` | 主按钮按下 |
| `--color-primary-soft` | `rgba(63,111,239,.12)` | 激活底/标签底 |
| `--color-primary-bg` | `rgba(63,111,239,.06)` | 浅蓝底（筛选/导航激活） |
| `--color-success/-warning/-danger/-info` | `#0EA879 / #D48B3A / #C0392B / #3F6FEF` | 仅状态使用 |
| 灰阶 | `--gray-50`(F8F8F8) → `--gray-900`(111111) | 白底黑字中间灰 |

### 2.2 字体层级

| Token | 值 | 用途 |
|-------|----|------|
| `--text-page-title` | 20px/700 | 页头大标题 |
| `--text-regular` / `--text-md` | 14px | 常规正文 |
| `--text-body` / `--text-base` | 13px | 表格/正文默认 |
| `--text-caption` / `--text-sm` | 12px | 辅助说明 |
| `--text-hint` / `--text-xs` | 11px | 最小辅助 |
| `--text-amount-lg` | 26px/700 | 指标卡大数字（紧凑） |
| `--text-amount-xl` | 32px/700 | 指标卡大数字（Hero） |

### 2.3 阴影三档（柔和分层，参考图标准）

| Token | 值 | 场景 |
|-------|----|------|
| `--shadow-card` | `0 1px 2px rgba(16,24,40,.04), 0 1px 3px rgba(16,24,40,.06)` | 卡片静态 |
| `--shadow-hover` | `0 4px 8px -2px rgba(16,24,40,.08), 0 8px 16px -4px rgba(16,24,40,.10)` | 卡片悬浮/下拉 |
| `--shadow-modal` | `0 24px 48px -12px rgba(16,24,40,.18), 0 8px 16px -8px rgba(16,24,40,.10)` | 弹窗/抽屉 |

### 2.4 间距 / 圆角 / 状态标签

- 间距：4px 基准 8 级（`--space-1..8`），页面 `--space-page-padding: 24px`、卡片 `--space-card-padding: 16px`。
- 圆角：控件 4-6px（`--radius-xs/sm`）、卡片 10px（`--radius-lg`）、弹窗 12px（`--radius-xl`），禁止胶囊（登录/收银台特例除外）。
- 状态标签：浅底彩字（底 = 语义色 12% 透明，字 = 语义色），`--tag-radius: 6px`、`--tag-padding: 3px 10px`、12px/500。
- 图表色：`--chart-1..6`（蓝/绿/橙/红/紫/青），网格线 `--chart-grid: #EEF0F3`。

## 三、Element Plus 主题定制（`admin-web/src/styles/styles.css` R99 段）

> 踩坑须知：所有 `--el-*` 变量覆盖必须写在 `:root:root`（特异性 0,2,0）块内，否则会被按需注入的 `element-plus/theme-chalk/base.css` 静默覆盖（踩坑日志 [31]）。

| 组件 | 定制内容 |
|------|---------|
| el-card | 1px hairline 边框 + `--shadow-card` + 10px 圆角；header 14px/600 带底部分隔线 |
| el-button | 三档：主按钮（实心蓝+微投影）、默认按钮（白底灰边、hover 蓝边蓝字）、文字按钮；32/40/28px 三档高度 |
| el-table | 表头 `#F8F8F8` + 12px/600，正文 13px，行高 44px，hover `#F5F7FA`，hairline 边框 |
| el-form/input | 标签灰黑 500，输入框 32px + 聚焦双环（1px 蓝边 + 3px 柔光） |
| el-dialog/drawer | 12px 圆角 + `--shadow-modal`，header 带分隔线、footer 带顶线 |
| el-pagination | 圆角按钮 + 1px 边框，激活页品牌蓝实底 |
| el-tag | 统一 6px 圆角 + 3px 10px 内边距 + 12px/500 |
| el-tabs | hairline 底边 + 品牌蓝激活条 |
| el-popper | 下拉/日期弹层 8px 圆角 + `--shadow-md` |
| el-empty | 80px 插图 + 灰字说明 |

## 四、四种页面骨架

### 4.1 列表页骨架（示范：商品列表）

```
页头（标题 20px/700 + 说明 + 操作按钮）
  ↓
统计条（StatBar / .stat-grid 指标卡行，大数字）
  ↓
筛选栏（.filter-bar 卡片内，el-input/el-select + 查询/重置）
  ↓
表格（.table-card 容器 + el-table，状态标签用语义色）
  ↓
分页（.table-card-footer 右对齐）
```

代码模板：

```html
<div class="page">
  <div class="page-header">
    <div class="page-header-main">
      <h2 class="page-title">页面标题</h2>
      <p class="page-desc">一句话说明</p>
    </div>
    <div class="page-header-actions">
      <el-button type="primary"><el-icon><Plus /></el-icon>&nbsp;新增</el-button>
      <el-button>刷新</el-button>
    </div>
  </div>

  <div class="filter-bar">
    <el-input v-model="keyword" placeholder="关键词" style="width: 200px" clearable />
    <el-button type="primary">查询</el-button>
  </div>

  <div class="table-card">
    <el-table :data="rows">…</el-table>
    <div class="table-card-footer">
      <el-pagination background layout="total, prev, pager, next" :total="total" />
    </div>
  </div>
</div>
```

### 4.2 表单页骨架（示范：销售开单）

```
页头（标题 + 操作按钮：保存草稿 / 提交）
  ↓
表单卡片分区（.form-card：基础信息 / 商品明细）
  ↓
右侧金额汇总（.summary-card sticky，应收大数字品牌蓝）
  ↓
底部操作栏（.form-actions-bar：取消 / 提交）
```

要点：`el-form` 三件套（ref + :model + :rules）；分区用 `.form-card-header` + `.form-card-body`；金额一律 `.amount-text` 等宽。

### 4.3 详情页骨架（示范：商品详情抽屉）

```
页头（标题 + 返回/操作）
  ↓
详情卡片 / DetailDrawer（el-descriptions 双列 + 主图）
  ↓
关联区块（.detail-section：SKU 列表 / 价格历史 / 标签）
```

要点：`.detail-section-title` 带 3px 品牌蓝竖条；描述列表标签灰、值黑；状态字段用语义色标签。

### 4.4 看板页骨架（示范：首页工作台）

```
页头（欢迎语 + 日期 + 快捷操作）
  ↓
指标卡行（.metric-card：大数字 + 环比 + 迷你趋势图）
  ↓
今日焦点（待办 / 快捷入口 / 经营助手 三卡）
  ↓
图表区（.chart-card：ECharts 灰阶 + 单蓝 accent + hairline 网格）
  ↓
明细表（.compact-table：最新订单 / 预警列表）
```

图表规范：ECharts 配色只用 `--chart-*`；网格线 `--chart-grid`；柱状/面积图可用 `--chart-gradient-primary` 渐变；金额/数量 tooltip 等宽。

## 五、通用组件用法（`admin-web/src/components/`）

| 组件 | 用途 | 关键 Props |
|------|------|-----------|
| `PageCard.vue` | 页面卡片容器（标题 + 可选说明 + extra 插槽） | `title` / `description` / `#extra` |
| `StatBar.vue` | 顶部统计条（label/value，primary 高亮） | `stats: { label, value, primary? }[]` |
| `DataTable.vue` | 表格 + 分页一体（columns 声明式 + 空态插槽） | `columns` / `data` / `total` / `page` / `pageSize` / `emptyText` / `#empty` |
| `TableSkeleton.vue` | 表格加载骨架屏（默认 8 行卡片样式） | `rows` |
| `DetailDrawer.vue` | 详情抽屉（默认 600px，标题 + 内容插槽） | `modelValue` / `title` / `width` |

空态规范：`el-empty`（80px 插图 + 真实文案 + 可选操作按钮），禁止"功能开发中"占位。
加载态规范：列表用 `TableSkeleton`，页面级用 `el-skeleton` 卡片骨架。
状态标签规范：只用 `el-tag` 语义色（success/warning/danger/info/primary），浅底彩字。

## 七、验收检查清单（R99-02/03 全页面套用）

1. 页面只含 白/灰/品牌蓝/语义色；无渐变（登录除外）、无玻璃拟态、无 emoji 图标。
2. 金额/数量 `tabular-nums` 等宽；表格行高 ≤44px；表头浅灰 600。
3. 每个字符串命名真实信息，无编造数据；空态有真实文案与操作。
4. 列表/表单/详情/看板均按本章骨架结构组织。
5. `npm run build`（admin-web）exit 0；本地 H5 截图走查与参考图对照。
6. 全局样式一次生效，其余页面无样式回归（Element Plus 主题 + tokens 自动覆盖）。
