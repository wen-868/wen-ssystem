# 智享全链 PC 端 UIUX 设计方案(基于设计技能方法论)

> 作者：凌舟 | 日期：2026-08-04
> 依据：《智享PC收银-UIUX设计总览.pdf》(15 页设计稿) + frontend-design 技能(8 锚点) + design-taste 技能(design read/反默认纪律)

---

## 一、Design Read(设计判读)

**Reading this as:** 酒饮批零 B2B SaaS 收银管理后台的重设计，面向门店店长/收银员/管理员的严肃数据工作台，采用 **Swiss 瑞士风格**语言，追求精确、克制、高信息密度，彻底去除 AI 生成感。

**选择理由(一行):** PDF 设计稿的视觉语言——纯白底、1px 细分隔线、左对齐排版、大数字构图、单一品牌蓝、高密度表格——本身就是 Swiss；选择 Swiss 而非 Industrial(黑底终端，不适合日间收银)或 Organic(暖色，不适合 B2B 数据)，是唯一与设计稿和业务场景同时吻合的锚点。

## 二、三拨盘(Dial Settings)

| 拨盘 | 值 | 说明 |
|------|----|------|
| DESIGN_VARIANCE | 4 | 克制、对称平衡，允许极少数非对称构图 |
| MOTION_INTENSITY | 2 | 几乎静态，仅 hover/焦点微反馈 |
| VISUAL_DENSITY | 8 | 高密度数据界面(收银台/列表页) |

## 三、锚点 Token 体系(Swiss)

### 3.1 Surface(表面)

| Token | 值 | 用途 |
|-------|----|------|
| `--surface-page` | `#FFFFFF` | 页面主底 |
| `--surface-neutral` | `#F7F7F8` | 侧栏/分区底 |
| `--surface-soft` | `#F0F0F0` | 表头/hover |
| `--hairline` | `#E2E2E2` | 1px 细线(核心结构元素) |
| `--hairline-light` | `#F0F0F0` | 更轻分隔线 |

### 3.2 Typography(字体)

单一无衬线家族：`PingFang SC / Helvetica Neue / Inter / system-ui`。

| Token | 值 | 用途 |
|-------|----|------|
| 数字 | `font-variant-numeric: tabular-nums` | 金额/数量等宽对齐 |
| 大数字 | 28-32px / 700 | 指标卡数值(构图元素) |
| 正文 | 13-14px / 400-500 | 表格/正文 |
| 辅助 | 12px / #999 | 说明文字 |

### 3.3 Accent(强调色——单一、克制)

品牌蓝(对齐 PDF 主色 #3F6FEF)：

| Token | 值 | 用途 |
|-------|----|------|
| `--accent` | `#3F6FEF` | 按钮/链接/激活态/选中 |
| `--accent-soft` | `rgba(63,111,239,0.10)` | 激活底/标签底 |
| `--accent-active` | `#2F5BD6` | 按下态 |

语义色仅用于状态(不用于装饰)：

| Token | 值 | 用途 |
|-------|----|------|
| `--sem-success` | `#0EA879` | 成功/营业中/充足 |
| `--sem-warning` | `#D48B3A` | 警告/低库存 |
| `--sem-danger` | `#C0392B` | 错误/缺货/欠款 |

### 3.4 Structure(结构纪律)

- **1px hairline 分隔线**取代阴影与卡片悬浮——结构靠线不靠影
- **左对齐**排版；数字右对齐(表格列)
- **网格对齐**：内容贴 4px 基准网格
- **去装饰**：无渐变(登录页品牌区除外)、无玻璃拟态、无胶囊圆角、无 emoji 图标(用 Element Plus 图标)

### 3.5 内容纪律(Content Discipline)

- 每个字符串必须命名真实信息；无真实数据的槽位留空，禁止编造
- 标准 UI 文案用标准说法(登录/记住账号/结算，不搞"Authenticate Session"式替换)
- 禁止 unicode 字符当图标、禁止 AI-slop 腔(「Ask the grid.」式副标题)

## 四、页面设计规范

### 4.1 登录页(PDF p02)

已完成首版：左蓝底品牌区(批零一体主张 + 4 特性)，右白底登录表单。按 Swiss 校准：

- 品牌区用纯色蓝(#3F6FEF)或克制的线性渐变(仅此一处允许)
- 表单区白底、1px 边框、左对齐标签
- 大标题"登录工作台"、标准表单文案

### 4.2 全局框架(业务页通用)

```
┌────────┬──────────────────────────────────────────┐
│ 侧栏    │ 顶栏: [门店·营业中] [全局搜索] [后台|收银] [通知] [用户] │
│ 白底    ├──────────────────────────────────────────┤
│ 图标+文 │                                          │
│ 分组:   │  页面内容(白底网格 + hairline 分区)        │
│ 工作台  │                                          │
│ 业务    │                                          │
│ 系统    │                                          │
└────────┴──────────────────────────────────────────┘
```

- 侧栏：`#F7F7F8` 浅底、深灰文字、激活项 `accent-soft` 底 + accent 字
- 顶栏：纯白、hairline 底边、门店状态点(绿)+ 搜索框 + 模式切换
- 内容区：页面白底，模块用 hairline 分区，不用卡片阴影堆叠

### 4.3 工作台(PDF p03)

- 欢迎区：问候 + 日期 + 门店营业状态(左对齐，大号问候语)
- 指标行：4-6 个指标卡，白底 + hairline 边框，大数字(tabular-nums)+ 环比小字
- 今日焦点三卡：待办事项(真数据计数)/ 本页可帮你(快捷入口)/ 经营助手(本地模型状态)
- 图表区：ECharts 使用灰阶 + 单蓝 accent，网格线 hairline
- 表格：紧凑行高(48px→40px)、表头 #F7F7F8、状态用语义色标签

### 4.4 收银台(PDF p11/p12)

- 顶部状态条：购物车件数/应收(大数字)+ 快捷键提示(F2/F3/F8/F9,等宽 kbd)
- 左侧商品网格：白底卡片 + hairline 边框、库存色标(红/橙/灰)、价格大字
- 右侧购物车：会员行、紧凑商品列表、应收汇总(accent 大数字)、结算按钮
- 结算弹窗：应收金额大数字、支付方式横向选择、找零、确认收款

### 4.5 列表页统一(PDF p04-p08)

统一结构：顶部统计条(大数字) → 筛选栏(hairline 分隔) → 紧凑表格(40px 行高、状态标签) → 分页。

## 六、验收标准

1. 每个页面配色只含：白/中性灰/品牌蓝/语义状态色
2. 无渐变(登录品牌区除外)、无玻璃拟态、无胶囊圆角、无 emoji 图标
3. 数字 tabular-nums 对齐；表格紧凑(≤40px 行高)
4. 屏幕上的每个字符串命名真实信息，无编造数据
5. `npm run build` exit 0；浏览器逐页走查
