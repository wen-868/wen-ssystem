# 全端表单统一规范 v1

> 制定：2026-08-12 | 适用范围：admin-web / saas-admin / app-mobile / miniapp 全部业务表单
> 配套台账：docs/design/表单清单.md（208 处，逐项勾选防遗漏）

## 一、表单三态与按钮规范

| 表单类型 | 默认态 | 操作按钮 | 说明 |
|---------|--------|---------|------|
| 详情+编辑表单（如商品详情） | 查看（只读） | 修改 / 保存 / 保存并增加 | 点「修改」进入编辑态；「保存」提交并返回查看态；「保存并增加」提交后新建同类型单据 |
| 新增表单 | 编辑 | 保存 / 保存并增加 / 取消 | 保存并增加=连续录入 |
| 纯只读详情（单据/日志/追溯） | 只读 | 无操作按钮 | 只展示，不出现编辑入口 |
| 筛选/搜索表单 | 编辑 | 查询 / 重置 | 属于工具栏，不套用底部按钮 |

## 二、查看/编辑双模式规则

1. 默认打开为查看模式：所有输入控件只读、操作列/操作按钮隐藏，仅保留「修改」。
2. 点「修改」进入编辑模式：控件可编辑，出现「保存」「保存并增加」与行内操作（如添加单位/删除）。
3. 保存成功自动返回查看模式；保存失败提示并停留在编辑模式。
4. 只读态下不得出现任何编辑性操作按钮（含行内按钮、删除、上传等）。

## 三、排版规则

1. 分区标题：`表单分区标题`（基本信息 / 扩展信息 / 明细），避免单页长表单无层级。
2. 主图/图片区独立成面板（移动端可置顶大图），与字段区左右或上下分离。
3. 明细表（SKU/单位/行项目）支持逐行维护：行内可编辑、行操作明确（添加/删除），换算类字段自动推导并标注。
4. 全局性开关（追溯、参与促销等）独立于明细行，不随明细行重复。
5. 编码类字段（SPU/SKU/单号）不进入展示区；创建/更新时间作为辅助信息置底。

## 四、共享组件

- admin-web：`components/DetailDrawer.vue` 已支持 `editable / showSaveAndAdd / saving / update:editing`，可编辑详情统一走该组件。
- 移动端：新增/编辑页底部固定操作栏（保存 / 保存并增加），uni-app 统一封装 `FormFooter`。

## 五、验收口径（防遗漏）

1. 以表单清单.md 逐项勾选，禁止无台账改造。
2. 每端改造后跑构建 + 关键流程冒烟（新增→保存→详情→修改→保存并增加）。
3. 只读态无操作按钮、编辑态保存后回查看态，为必检项。
