页面总览

员工管理模块负责维护连锁门店所有员工的基础信息，包括员工账号创建、信息编辑、角色分配、门店归属、离职/复职、密码重置等功能。管理员可通过工号、姓名、手机号快速搜索，结合门店、角色、状态等多维度筛选快速定位目标员工。

字段规范

字段名 数据类型 必填 说明 示例值
emp_code VARCHAR(20) 是 工号，系统自动生成 EMP001
username VARCHAR(50) 是 用户名，登录账号，唯一 zhangjianguo
real_name VARCHAR(50) 是 员工真实姓名 张建国
phone VARCHAR(20) 是 手机号，唯一 138****6789
store_code VARCHAR(20) 是 所属门店编码，关联门店表 ST001
role VARCHAR(20) 是 角色：admin-管理员 manager-店长 staff-员工 admin
position VARCHAR(50) 否 职位名称 系统管理员
status TINYINT 是 状态：1-在职 0-离职 1
password VARCHAR(128) 是 密码哈希值（加密存储） $2a$10$...
hire_date DATE 是 入职日期 2023-06-01
leave_date DATE 否 离职日期 2024-12-31
last_login_at DATETIME 否 最后登录时间 2024-06-30 18:00:00
created_at DATETIME 是 创建时间 2023-06-01 09:00:00
updated_at DATETIME 是 最后修改时间 2024-06-28 15:42:10

验收标准

  • 员工列表页面正常加载，表头与数据列对齐
  • 搜索框支持按工号进行模糊搜索
  • 搜索框支持按姓名进行模糊搜索
  • 搜索框支持按手机号进行模糊搜索
  • 门店筛选下拉框正确加载全部门店列表
  • 角色筛选下拉框支持按管理员/店长/员工筛选
  • 状态筛选下拉框支持按在职/离职筛选
  • 角色标签正确显示：管理员（红色）、店长（橙色）、员工（蓝色）
  • 状态标签正确显示：在职（绿色）、离职（灰色）
  • 点击新增员工按钮弹出新增弹窗，表单字段完整
  • 工号自动生成，格式为 EMP + 三位数字序号
  • 表单必填字段（工号、用户名、姓名、手机号、所属门店、角色、状态）校验提示
  • 手机号格式校验（11位数字，1开头）
  • 用户名唯一性校验，重复时给出提示
  • 点击编辑按钮加载对应员工数据到弹窗表单
  • 点击离职按钮，在职员工变更为离职状态
  • 点击复职按钮，离职员工恢复为在职状态
  • 点击重置密码按钮弹出二次确认弹窗
  • 密码重置确认弹窗提示内容包含员工姓名
  • 确认重置后密码还原为初始密码，并提示成功
  • 分页组件正常翻页，显示总条数
  • 统计卡片数据（员工总数/在职/离职/本月新增）与列表数据一致
  • 所有操作均有 loading 状态与成功/失败提示
