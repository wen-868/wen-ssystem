页面总览

营销活动中心是工作台的核心模块之一，为运营人员提供统一的营销活动管理入口。页面采用经典的左侧导航 + 右侧工作区布局，左侧导航树涵盖优惠券、满减满赠、限时折扣、秒杀拼团、积分商城、活动叠加规则六大子模块。右侧工作区顶部展示活动概览统计卡片，下方为筛选搜索区和优惠券模板列表，支持快速新建活动、批量管理模板。

字段规范

营销活动中心和优惠券模板涉及的核心数据字段定义，确保前后端接口对齐。

活动表字段

字段名 类型 必填 说明 示例值
activity_id String(32) 是 活动唯一标识 ACT20260630001
activity_name String(100) 是 活动名称 新人专享优惠券
activity_type Enum 是 活动类型：COUPON / FULL_REDUCTION / FLASH_SALE / POINTS COUPON
status Enum 是 状态：DRAFT / ACTIVE / PAUSED / ENDED / EXPIRED ACTIVE
start_time DateTime 是 活动开始时间 2026-06-01 00:00:00
end_time DateTime 是 活动结束时间 2026-07-31 23:59:59
total_limit Integer 否 总发放量限制，-1 表示不限 1000
user_limit Integer 否 每人限领数量 1
created_at DateTime 是 创建时间 2026-06-30 10:00:00

优惠券模板字段

字段名 类型 必填 说明 示例值
template_id String(32) 是 模板唯一标识 TPL20260630001
template_name String(100) 是 模板名称 新人专享优惠券
coupon_type Enum 是 券类型：FULL_REDUCTION / DISCOUNT / FREE_SHIPPING FULL_REDUCTION
threshold_amount Decimal 条件 使用门槛金额（满减券/折扣券） 200.00
discount_value Decimal 是 优惠面值（满减券为减免金额，折扣券为折扣率） 30.00
total_issued Integer 是 已发放数量 780
total_used Integer 是 已使用数量 520
valid_days Integer 否 领取后有效天数 30

验收标准

以下为营销活动中心模块上线前必须通过的验收检查项。

  • 顶部导航栏「营销中心」菜单项高亮激活，点击可正确跳转至营销活动中心页面。
  • 左侧导航树展示 6 个子模块，其中「优惠券管理」为默认激活项，秒杀拼团带锁图标置灰不可点击。
  • 活动概览统计卡片（进行中 / 即将开始 / 已结束 / 活动总数）数据与后端实时同步，误差不超过 5 分钟。
  • 筛选搜索栏支持按活动名称关键词搜索、按状态筛选、按券类型筛选和按时间范围筛选，各条件可组合使用。
  • 优惠券模板列表表格正确展示模板名称、类型标签、面值、有效期、发放/使用进度条和状态标签，分页组件功能正常。
  • 状态标签颜色与含义一致：DRAFT 灰色、ACTIVE 绿色、PAUSED 黄色、ENDED 红色、EXPIRED 灰色。
  • 点击「新建活动」按钮弹出活动创建表单，包含名称、类型、优惠规则、时间范围、发放限制等字段，提交后列表自动刷新。
  • 页面在 1440px 及以上分辨率完整显示，表格无横向滚动溢出，所有交互元素可点击区域不小于 32x32px。
