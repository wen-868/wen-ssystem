字段规范

商户端报表模块涉及的核心数据字段定义，确保前后端接口对齐、数据口径一致。

字段名 类型 说明 示例值 所属模块
daily_sales_amount Decimal 今日销售额（元） 8500.00 经营概览

gross_profit Decimal 毛利（销售额 - 成本） 2550.00 经营概览
avg_order_value Decimal 客单价（销售额 / 订单数） 708.33 经营概览
sales_trend_7d Array<Decimal> 近7日每日销售额 [6200,5800,7100,8400,6900,9200,8500] 经营概览 / 销售
product_sales_rank Array<Object> 商品销售排行（名称/销量/金额） [{name, qty, amount}] 销售分析
customer_contribution_rank Array<Object> 客户贡献排行（名称/订单数/金额） [{name, orders, amount}] 销售 / 客户

customer_distribution Object 客户分布（新客/老客/流失占比） {new:30, regular:55, churned:15} 客户分析

验收标准

以下为商户端报表模块上线前必须通过的验收检查项。

  • 商户登录后可在底部导航栏切换 6 个标签页（经营概览 / 销售 / 收款 / 库存 / 客户 / 财务），每个标签页加载对应数据。
  • 经营概览页展示今日 4 项 KPI（销售额、订单数、毛利、客单价），数据与后端实时同步，误差不超过 5 分钟。
  • 销售分析页支持日/周/月切换，TOP10 排行列表数据正确、排序无误，点击商品可查看详情。
  • 收款分析页收款渠道饼图比例与后端数据一致，待收列表按到期日排序，逾期项以红色标识。
  • 库存分析页库存预警按红/橙/黄三级展示，缺货商品（库存低于安全库存 50%）标记为红色。
  • 客户分析页客户分布饼图比例正确，采购排行与销售数据交叉验证一致。
  • 财务分析页收支趋势图展示近 6 个月数据，费用分类饼图与财务系统数据对齐。
  • 所有页面在 375px 宽度手机屏幕上完整显示，无横向滚动条，页面加载时间不超过 2 秒。
