页面总览

限时折扣+满赠模块是营销活动中心下的核心子模块，通过 Tab 切换分别管理限时折扣活动和满赠规则。限时折扣 Tab 支持折扣活动的创建、编辑、查看详情，包含倒计时组件和活动详情卡片。满赠规则 Tab 支持多级满赠层级配置，包含赠品选择器和规则预览区，便于运营人员实时查看满赠效果。

字段规范

限时折扣活动和满赠规则涉及的核心数据字段定义。

限时折扣活动字段

字段名 类型 必填 说明 示例值
discount_id String(32) 是 折扣活动唯一标识 DIS20260628001
discount_name String(100) 是 活动名称 飞天茅台限时抢购
discount_type Enum 是 折扣类型：PERCENTAGE / FIXED_AMOUNT PERCENTAGE
discount_value Decimal 是 折扣值（百分比类型为折扣率，固定金额为减免额） 7.5
start_time DateTime 是 活动开始时间 2026-06-28 10:00:00
end_time DateTime 是 活动结束时间 2026-06-30 22:00:00
product_ids Array<String> 是 适用商品ID列表 ["PRD001","PRD002","PRD003"]
total_stock Integer 是 活动总库存数量 100
sold_count Integer 是 已售/已抢数量 85
participant_count Integer 是 参与人数 1286
status Enum 是 状态：PENDING / ACTIVE / ENDED / CANCELLED ACTIVE

满赠规则字段

字段名 类型 必填 说明 示例值
gift_rule_id String(32) 是 满赠规则唯一标识 GFT20260630001
gift_rule_name String(100) 是 规则名称 周年庆阶梯满赠
condition_type Enum 是 条件类型：BY_AMOUNT / BY_QUANTITY BY_AMOUNT
tiers Array<Object> 是 满赠层级列表（threshold / gift_product_id / gift_quantity） [{threshold:100, gift:"PRD_G01", qty:1}]
tier_mode Enum 是 层级模式：HIGHEST_ONLY / ALL_ELIGIBLE HIGHEST_ONLY
start_time DateTime 是 规则生效时间 2026-06-01 00:00:00
end_time DateTime 是 规则失效时间 2026-06-30 23:59:59
status Enum 是 状态：PENDING / ACTIVE / ENDED ACTIVE

验收标准

以下为限时折扣+满赠模块上线前必须通过的验收检查项。

  • 左侧导航栏「满减满赠」为激活项，右侧 Tab 可在「限时折扣」和「满赠规则」之间切换，默认展示限时折扣 Tab。
  • 限时折扣 Tab 列表表格正确展示活动名称、折扣力度（红色大字）、时间范围、适用商品数、库存进度条、参与人数和状态标签。
  • 倒计时组件使用 DIN / Courier New 等宽字体，深色背景 rgba(0,0,0,0.75)，数字格式为「天-时-分-秒」，实时更新。
  • 新建/编辑折扣活动弹窗包含活动名称、描述、折扣类型（百分比/固定金额）、折扣值、时间范围、商品选择器，所有必填字段校验通过后方可提交。
  • 商品选择器支持关键词搜索、分类筛选、多选复选框，库存不足商品以红色标识提醒。
  • 满赠规则 Tab 列表表格展示规则名称、满赠条件、赠品信息、有效期和状态，支持新建、编辑、停用操作。
  • 多级满赠层级编辑器清晰展示阶梯关系（满100赠A -> 满200赠B -> 满300赠C），每级显示条件、赠品名称、数量和库存状态，支持添加/删除层级。
  • 赠品选择器弹窗展示可选赠品列表，库存不足（低于安全阈值）商品以红色库存警告标识，选择后回填至层级编辑器。
  • 规则预览区模拟购物车满赠效果，展示当前购物车商品、合计金额、触发的赠品档位和赠品信息，层级模式切换后预览结果实时更新。
  • 所有折扣标签使用红色 #FF4757，倒计时组件使用深色背景，与设计规范一致，页面在 1440px 及以上分辨率完整显示。
