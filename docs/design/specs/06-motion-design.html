4. 内置动画类

/* 淡入上移 */
@keyframes fade-in-up {
  0% { opacity: 0; transform: translateY(16px); }
  100% { opacity: 1; transform: translateY(0); }
}

/* 缩放入场 */
@keyframes scale-in {
  0% { opacity: 0; transform: scale(0.95); }
  100% { opacity: 1; transform: scale(1); }
}

/* 右侧滑入 */
@keyframes slide-in-right {
  0% { opacity: 0; transform: translateX(24px); }
  100% { opacity: 1; transform: translateX(0); }
}

/* 骨架屏闪光 */
@keyframes shimmer {
  0% { opacity: 0.6; }
  50% { opacity: 1; }
  100% { opacity: 0.6; }
}

5. 动效设计原则

原则说明
出场快于入场出场动画 150ms，入场动画 250-350ms。用户等待的是内容出现，不是消失
弹性用于强调spring 弹性曲线仅用于需要吸引注意力的场景（弹窗、通知），不可滥用
不超过 400ms任何动画不超过 400ms，超过会让用户感到等待
尊重用户偏好prefers-reduced-motion: reduce 时关闭所有动画和过渡
有意义才动动效应有明确目的：引导注意力、提供反馈、展示状态变化，不为动而动
一致性同类元素使用相同的动效参数，不一致会让产品显得不专业
性能优先仅动画 transform 和 opacity，避免触发重排的 width/height/top/left
