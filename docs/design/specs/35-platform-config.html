京东秒送 · 美团外卖 · 饿了么 多平台统一对接配置

1. 页面总览

平台对接配置页面用于管理京东秒送、美团外卖、饿了么三大即时配送平台的接入配置，包括密钥配置、回调通知、数据同步和同步日志等功能模块。支持可视化配置、一键测试连接、自动同步等能力。

支持平台

• 京东秒送 - 京东到家即时配送服务，覆盖全国主要城市

• 美团外卖 - 美团外卖平台订单接入，支持美团配送

• 饿了么 - 饿了么平台订单接入，支持蜂鸟配送

配置流程

1. 填写平台密钥（AppKey / AppSecret / Merchant ID / Store ID）

2. 配置回调通知（Webhook URL / 验签密钥 / 事件订阅）

3. 测试连接并保存配置

4. 开启自动同步，设置同步频率

3. 字段规范表

3.1 平台配置字段

字段名类型必填说明
platformenum是平台标识：jd / meituan / eleme
app_keystring是应用 AppKey，平台开放平台申请
app_secretstring是应用 AppSecret，加密存储
merchant_idstring是商户 ID
store_idstring是门店 ID
webhook_urlstring是回调通知地址，系统自动生成
sign_secretstring是验签密钥，用于验证回调请求
subscribe_eventsarray是订阅事件列表：order / product / refund / review
auto_syncboolean否是否开启自动同步，默认 false
sync_intervalinteger否同步间隔（分钟）：5 / 10 / 30 / 60
statusenum是连接状态：connected / disconnected / unconfigured
last_connected_atdatetime否最后成功连接时间

3.2 同步日志字段

字段名类型必填说明
log_idstring是日志唯一标识
platformenum是平台：jd / meituan / eleme
sync_typeenum是同步类型：product / order / inventory
statusenum是状态：success / failed
request_paramsjson是请求参数
response_datajson否返回结果
error_messagetext否错误信息（失败时）
durationfloat是耗时（秒）
trigger_typeenum是触发方式：manual / auto / webhook
created_atdatetime是同步时间

4. 验收标准清单

以下为设计验收检查项，确保设计质量和用户体验。

  • 密钥安全：AppSecret 等敏感字段默认隐藏，支持显示/隐藏切换
  • 一键复制：回调 URL 支持一键复制，复制成功有明确反馈
  • 测试连接：点击测试连接后，实时显示连接状态和结果
  • 连接状态：已连接/未连接/未配置三种状态视觉区分明显
  • 平台切换：三个平台 Tab 切换流畅，配置数据独立不串扰
  • 事件订阅：checkbox 列表清晰，支持批量选择和取消
  • 自动同步：开关状态持久化，频率选择直观易懂
  • 同步日志：成功/失败状态颜色区分，失败日志突出显示
  • 日志详情：弹窗展示请求参数、返回结果、错误信息，支持代码块复制
  • 表单校验：必填字段有明确标识，提交前校验完整
  • 操作反馈：保存、同步等操作有加载状态和成功/失败提示
  • 响应式布局：支持 1280px ~ 1920px 屏幕宽度自适应
