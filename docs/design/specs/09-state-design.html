🌐

2. 空状态设计规范

场景图标文案操作
列表无数据空盒子图标"暂无数据""新增"按钮
搜索无结果搜索图标"未找到匹配结果""清空筛选"
筛选无结果筛选图标"当前筛选条件下无数据""重置筛选"
详情不存在文件图标"数据不存在或已删除""返回列表"
购物车为空购物车图标"购物车还是空的""去逛逛"

空状态设计原则

  • 始终提供明确的下一步操作按钮
  • 图标使用灰色调，不抢眼
  • 文案简洁友好，不要用技术术语
  • 空状态不是"什么都没有"，而是"从这里开始"

4. 错误状态设计规范

错误类型视觉文案模板操作
网络错误红色横幅 + 错误图标"网络连接异常，请检查网络后重试"重试按钮
服务器错误红色横幅"服务器繁忙，请稍后重试"重试 / 联系管理员
权限不足黄色横幅"您没有权限执行此操作"返回 / 申请权限
数据不存在灰色提示"数据不存在或已被删除"返回列表
表单验证失败红色文字 + 红色边框"请输入正确的XXX"修正后重新提交
超时黄色横幅"请求超时，请稍后重试"重试按钮

5. 边界状态处理

场景处理方式
数据量过大分页加载（每页20条），虚拟滚动（超过1000条）
金额为0显示 ¥0.00（不隐藏），灰色显示
数量为0显示 0，库存为0时红色高亮
长文本溢出省略号截断 + Tooltip 显示完整内容
图片加载失败显示默认占位图 + 商品名称首字
并发操作冲突提示"数据已被他人修改，请刷新后重试"
离线状态显示离线提示，缓存最近数据
浏览器兼容不支持的特性降级处理，不阻断核心功能
