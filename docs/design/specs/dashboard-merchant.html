页面总览

商户端工作台是面向门店店长和店员的核心工作入口，在移动端（手机）上使用。页面聚焦商户日常经营所需的关键数据与待办事项，帮助商户快速掌握当日经营状况、及时处理待办任务。页面采用移动端常见的卡片式布局，自上而下依次展示核心指标、待办提醒、销售趋势、快捷入口、消息通知等模块，底部固定 Tab 导航栏支持快速切换功能模块。

字段规范

以下为商户端工作台核心数据指标及待办事项的字段定义规范。

字段名称 字段标识 数据类型 显示格式 说明
今日销售额 today_sales Decimal(12,2) ￥x,xxx 当前门店当日累计销售额
今日收款 today_collected Decimal(12,2) ￥x,xxx 当日已确认收款金额
待配送订单 pending_delivery Integer 数字 已接单待配送的订单数量
待收款金额 pending_receivables Decimal(12,2) ￥x,xxx 已发货未收款订单总额
库存预警数 inventory_alert_count Integer 数字 低于安全库存阈值的SKU数量
待接单数 pending_accept Integer 数字 待商户确认接单的订单数
客户跟进数 follow_up_count Integer 数字 本月未复购需跟进的客户数
销售环比变化 sales_change_pct Decimal(5,2) +xx.x% 与昨日销售对比的变化率
待办类型 todo_type Enum — inventory_alert / order_pending / customer_followup
待办优先级 todo_priority Enum — urgent(紧急) / warning(注意) / normal(普通)

验收标准

以下为商户端工作台页面及待办列表页的功能与交互验收清单。

  • 商户首页在 375px 宽度下所有卡片布局正确，无横向溢出
  • 顶部标题栏正确显示门店名称和角色标签"店长"
  • 消息铃铛正确显示未读消息红色角标数字"3"
  • 日期显示当前日期和星期，格式为"YYYY年M月D日 星期X"
  • 核心指标 2x2 网格布局，今日销售额以金色大字突出显示
  • 待收款金额指标卡片正确显示红色警告图标
  • 待办提醒区域支持横向滑动，展示 3 张不同级别的待办卡片
  • 待办提醒卡片左侧边框颜色与级别匹配（红/橙/蓝）
  • 近7天销售趋势柱状图正确渲染 7 根柱子，最高柱高亮蓝色
  • 快捷入口 3x2 宫格布局，6 个入口图标和文字正确显示
  • 最新消息区域展示 3 条通知摘要，含图标和发布时间
  • 底部 Tab 导航栏"首页"处于 active 高亮状态
  • 点击"更多"链接可跳转至待办事项列表页
  • 待办事项页顶部有返回按钮和标题"待办事项"
  • 待办 Tab 切换栏正确显示各分类及数量角标
  • 默认选中"全部"Tab，展示所有待办卡片
  • 库存预警卡片使用红色左边框，订单待处理使用橙色左边框，客户跟进使用蓝色左边框
  • 每个待办卡片显示详细信息（商品名/库存/阈值 或 订单号/客户/金额/时间）
  • 待办卡片底部有对应的操作按钮（处理/接单/联系）
  • 页面底部显示下拉刷新提示
