1. Toast 轻提示

用于操作结果的即时反馈，自动消失，不打断用户操作。

✓操作成功
⚠库存不足，请及时补货
✗保存失败，请重试
ℹ系统将在5分钟后维护

Toast 规范

属性值
位置页面顶部居中（桌面端）/ 顶部（移动端）
显示时长Success 2秒 / Warning 3秒 / Error 5秒 / Info 3秒
动画spring 弹性入场，ease-in 淡出
最大数量同时最多显示 3 条，超出后队列排队
关闭方式自动消失 + 点击关闭按钮

2. Dialog 对话框

用于需要用户确认的操作，打断当前流程，必须用户做出选择。

确认删除
确定要删除该供应商吗？此操作不可撤销，相关采购订单将保留但无法关联。
提交成功
✓
采购订单 CGDD240601001 已提交审核

Dialog 类型

类型标题确认按钮使用场景
确认操作"确认XXX"危险色按钮删除、作废等不可逆操作
提交确认"提交XXX"主色按钮提交审核、确认订单
成功提示"操作成功"主色按钮（知道了）操作完成后展示结果
警告提示"请注意"主色按钮库存不足、重复操作等
表单弹窗"新增/编辑XXX"保存 + 取消新增/编辑表单
