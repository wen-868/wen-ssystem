1. 表单布局规范

场景布局标签位置列数
弹窗表单垂直单列顶部对齐1 列

表格内编辑内联无标签单元格内

2. 验证规则

字段类型验证规则错误提示
必填字段非空验证"请输入XXX"
手机号/^1[3-9]\d{9}$/"请输入正确的手机号"
邮箱/^[\w.-]+@[\w.-]+\.\w+$/"请输入正确的邮箱地址"
金额正数，最多2位小数"请输入正确的金额"
数量正整数或正数"请输入正确的数量"
日期合法日期格式"请选择日期"
编码字母数字组合"编码格式不正确"
税率0-100 的数字"税率应在0-100之间"

验证时机

时机说明
失焦验证 (blur)默认方式，字段失去焦点时验证
即时验证 (input)输入过程中实时验证（仅用于简单规则）
提交验证 (submit)表单提交时全量验证，滚动到第一个错误

3. 表单状态演示

请输入供应商全称，最多50个字符
请输入正确的手机号
验证通过

4. 提交反馈

状态视觉行为
提交中按钮 loading 状态 + 禁用所有输入显示旋转动画，禁止重复提交
成功绿色 Toast "保存成功" + 可能关闭弹窗刷新列表 / 跳转详情 / 关闭弹窗
失败红色 Toast 错误信息保持表单数据，高亮错误字段
网络错误红色提示 + 重试按钮"网络异常，请重试"
超时警告提示"请求超时，请稍后重试"

5. 表单设计最佳实践

原则说明
必填标识必填字段用红色星号 (*) 标记，非必填标注"（选填）"
智能默认值合理预填默认值（如税率默认13%），减少用户输入
即时反馈输入后立即验证，不等提交时才报错
保留输入提交失败后保留用户已输入的数据，不要让用户重新填写
防重复提交提交后禁用按钮，防止重复请求
离开确认表单有未保存修改时，离开页面弹出确认提示
键盘友好Tab 键顺序合理，Enter 键提交，Esc 键关闭
