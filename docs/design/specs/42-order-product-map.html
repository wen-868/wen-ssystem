页面总览
全渠道商品映射功能用于管理本地商品与各渠道（微信、抖音、美团、饿了么、京东等）平台商品的对应关系。 通过建立本地SKU与渠道SKU的映射关系，实现跨渠道商品数据的统一管理、价格同步及订单自动关联。 主要功能包括：映射关系的增删改查、批量导入导出、未映射商品快速匹配、渠道商品同步状态监控等。 目标用户为运营管理人员，使用场景为PC端后台管理系统。

字段规范

映射关系字段

字段名 类型 必填 说明
mapping_id string 是 映射关系唯一标识
channel enum 是 渠道类型：wechat/douyin/meituan/eleme/jd
channel_sku_code string 是 渠道平台商品SKU编码
channel_product_name string 是 渠道平台商品名称
channel_price decimal 是 渠道平台商品价格，单位元
local_sku_code string 是 本地系统商品SKU编码
local_product_name string 是 本地系统商品名称
local_price decimal 是 本地系统商品价格，单位元
sync_status enum 是 同步状态：synced/pending/failed
last_sync_time datetime 否 最后同步时间
created_at datetime 是 创建时间
updated_at datetime 是 更新时间

未映射商品字段

字段名 类型 必填 说明
unmapped_id string 是 未映射商品记录唯一标识
channel enum 是 渠道类型
channel_sku_code string 是 渠道平台商品SKU编码
channel_product_name string 是 渠道平台商品名称
related_order_count integer 是 关联的订单数量
first_seen_at datetime 是 首次发现时间
验收标准
  • 映射列表页面正确展示全渠道商品映射数据，支持按渠道Tab筛选
  • 每个渠道Tab显示已映射数和未映射数角标，数据准确
  • 搜索框支持按渠道SKU编码和本地商品名进行模糊搜索
  • 新增映射弹窗：渠道下拉可选择全部渠道，本地SKU搜索选择器支持搜索并自动填充
  • 编辑映射功能正常，可修改渠道商品信息和关联的本地商品
  • 删除映射需二次确认，删除后列表刷新
  • 批量导入：支持CSV/Excel文件上传，预览表格展示正确，确认后显示导入结果统计
  • 批量导入失败行显示具体失败原因
  • 批量同步功能可一键同步所有未同步的映射关系
  • 同步状态标签正确显示：已同步(绿色)、未同步(黄色)、同步失败(红色)
  • 未映射商品列表支持按渠道筛选，显示关联订单数
  • 快速映射功能：弹窗只读展示渠道商品信息，选择本地商品后完成映射
  • 分页功能正常，支持翻页和跳转
  • 表格数据各列对齐正确，渠道标签颜色与渠道对应
