5. 字段规范

字段类型说明
statementNoString对账单号，格式 DZD + 年月日 + 序号
supplierIdUUID供应商ID
supplierNameString供应商名称
periodStartDate对账期间起始日期
periodEndDate对账期间截止日期
purchaseAmountDecimal本期采购金额合计
paidAmountDecimal本期已付金额
returnAmountDecimal本期退货金额
balanceAmountDecimal应付余额 = 采购金额 - 已付 - 退货
statusEnumPENDING / CONFIRMED / DISPUTED
itemsArray明细行列表（入库/退货/付款记录）
item.typeEnumIN_STOCK / RETURN / PAYMENT
item.directionEnumDEBIT（应付）/ CREDIT（冲减/已付）

6. 验收标准

#验收项标准
1对账单列表展示供应商/期间/金额/余额/状态，支持筛选
2生成对账单弹窗选择供应商+日期范围，自动汇总数据
3对账单详情汇总卡片 + 明细列表（入库/退货/付款），金额计算正确
4确认对账确认后状态变为"已确认"，不可修改
5标记争议争议状态下可备注原因，保留记录
6金额精度所有金额保留2位小数，千分位格式化
7余额计算余额 = 采购金额 - 已付金额 - 退货金额，实时计算
