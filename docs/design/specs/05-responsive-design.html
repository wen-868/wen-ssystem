3. Merchant-Mobile 商家端H5 — 移动端优先

策略说明
基准宽度375px（iPhone 6/7/8 设计稿基准）
适配方案rem 适配 + viewport 缩放，最大宽度 480px 居中
组件库Vant 4，天然支持移动端触摸交互
平板适配最大宽度限制 480px，居中显示，两侧留白
横屏适配部分表单布局改为双列，按钮缩小
/* merchant-mobile 响应式核心 */
@media (max-width: 480px) {
  .container { padding: 0 12px; }
  .card { border-radius: 8px; }
}
@media (min-width: 481px) {
  .container { max-width: 480px; margin: 0 auto; }
}

4. Store-Terminal 门店终端 — 固定优化

策略说明
基准宽度1024px（平板/触屏POS机）
最小宽度800px，低于此宽度缩小字体和按钮
触屏优化按钮最小触控区域 44x44px，间距 ≥ 12px
键盘快捷键F1/F2/F3 快捷收款，数字键盘直接输入金额
打印适配小票打印区域独立样式，不随屏幕变化

6. 响应式最佳实践

原则说明
Mobile First先写移动端样式，再用 min-width 媒体查询向上覆盖
弹性布局优先使用 flexbox/grid，避免固定宽度
相对单位使用 rem/%/vw 替代 px，字体最小 12px
触控区域交互元素最小 44×44px（iOS 规范），间距 ≥ 8px
图片优化使用 srcset 提供多分辨率图片，图标使用 SVG
隐藏/显示非核心内容在小屏可隐藏，用 .hide-mobile / .show-desktop 控制
表格处理小屏表格可横向滚动，或转为卡片式布局
