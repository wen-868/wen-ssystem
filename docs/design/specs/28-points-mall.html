页面总览

积分商城是平台运营核心模块，支持管理员创建和管理兑换商品，设置积分定价与库存策略。 用户可通过积分兑换商品，管理员可查看和管理所有兑换记录，包含确认、取消等操作。 页面包含商品管理网格视图、兑换记录列表、新建/编辑商品弹窗等核心功能区域。

验收标准

积分商城模块上线前必须通过的验收检查项。

  • 积分商城页面顶部统计卡片正确展示：商城总兑换量、总消耗积分（金币黄色标识）、热门兑换商品排行。
  • 商品管理Tab以4列网格展示兑换商品卡片，每张卡片包含商品图片、名称、所需积分（大字号突出显示，金币黄色）、市场参考价（删除线）、库存余量、上架/下架状态标签。
  • 库存为0的商品卡片显示"已兑完"半透明遮罩层，状态自动切换为"已下架"。
  • 操作栏支持关键词搜索和状态筛选（全部/已上架/已下架），点击"新建商品"按钮打开弹窗。
  • 新建/编辑弹窗包含商品图片拖拽上传区（虚线边框）、商品名称、描述、所需积分（整数校验）、市场参考价、库存设置（总库存/每人限兑/总限兑）、排序权重字段。
  • 每张商品卡片提供编辑、上架/下架、删除操作按钮，上架/下架按钮文案根据当前状态动态切换。
  • 兑换记录Tab以表格形式展示兑换编号、用户信息、商品名称、消耗积分、兑换数量、兑换时间、状态标签，支持按状态筛选和分页。
  • 待确认状态的兑换记录提供"确认"和"取消"操作按钮，已确认/已取消状态不显示操作按钮。
  • 所有交互操作（新建、编辑、删除、上架/下架、确认/取消兑换）需有二次确认机制。
  • 页面在 1440px 分辨率下完整显示，商品卡片网格自适应，无横向滚动条。
