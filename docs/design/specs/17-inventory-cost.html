4. 字段规范

字段类型说明
skuIdUUIDSKU唯一标识
skuNameStringSKU名称（含规格）
categoryNameString品类名称
beginQtyNumber期初数量
beginCostDecimal期初成本总额
inQtyNumber本期入库数量
inCostDecimal本期入库成本
outQtyNumber本期出库数量
outCostDecimal本期出库成本（按移动平均价）
endQtyNumber期末数量

avgPriceDecimal移动平均单价 = 期末成本 / 期末数量
periodString核算期间，格式 YYYY-MM

5. 验收标准

#验收项标准
1成本明细表按SKU展示期初/入库/出库/期末的数量和成本，支持按品类筛选
2移动平均价每次入库后实时计算：新均价 = (库存成本+入库成本) / (库存数量+入库数量)
3成本趋势展示近6个月移动平均成本变化趋势，柱状图可视化
4汇总卡片期末库存总值/本期入库成本/本期出库成本/SKU数
5金额精度所有金额保留2位小数，千分位格式化
6期间筛选支持按月切换核算期间
