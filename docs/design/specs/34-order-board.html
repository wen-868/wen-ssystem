34 · 60秒接单工作台 — 设计规格文档

门店大屏展示 · 实时接单 · 多平台订单统一管理

1. 页面总览

60秒接单工作台是面向门店的大屏实时接单系统，用于集中展示来自京东秒送、美团外卖、饿了么三大平台的订单，支持60秒倒计时接单、订单状态跟踪、批量操作等功能。设计采用深色主题，确保门店后厨等环境下的可读性和醒目性。

核心功能

• 新订单弹窗提示，60秒倒计时自动接单/拒单

• 三列订单看板：待接单、进行中、已完成

• 多平台订单统一展示（京东/美团/饿了么）

• 实时数据统计：今日订单、销售额、待接单、配送中

• 音效提醒：新订单、超时告警、操作确认

• 批量操作：批量接单、批量拒单、自动接单开关

3. 字段规范表

3.1 订单表字段

字段名类型必填说明
order_idstring是平台订单号，唯一标识
platformenum是平台来源：jd / meituan / eleme
statusenum是订单状态：pending / accepted / delivering / completed / rejected
user_namestring是用户昵称
user_phonestring是用户手机号（脱敏显示）
addressstring是配送地址
itemsarray是商品明细列表
total_amountdecimal是实付金额（元）
delivery_feedecimal是配送费（元）
discountdecimal否优惠金额（元）
remarkstring否订单备注
countdowninteger是接单倒计时（秒），默认60秒
created_atdatetime是下单时间

3.2 配送表字段

字段名类型必填说明
delivery_idstring是配送单号
order_idstring是关联订单号
rider_namestring是骑手姓名
rider_phonestring是骑手手机号（脱敏显示）
statusenum是配送状态：picking / delivering / arrived
estimated_arrivaldatetime是预计送达时间
progressinteger是配送进度百分比（0-100）

3.3 操作日志字段

字段名类型必填说明
log_idstring是日志ID
order_idstring是关联订单号
actionenum是操作类型：accept / reject / batch_accept / batch_reject
operatorstring是操作人
reasonstring否拒单原因（拒单时必填）
created_atdatetime是操作时间

4. 验收标准清单

以下为设计验收检查项，确保设计质量和用户体验。

  • 大屏可读性：深色主题下文字对比度不低于 4.5:1，远距离清晰可辨
  • 倒计时准确性：60秒倒计时精度误差不超过 0.5秒，支持暂停/继续
  • 倒计时颜色渐变：从绿色（60-40s）→ 黄色（40-20s）→ 红色（20-0s）
  • 新订单弹窗动画：脉冲边框动画流畅，不遮挡其他订单列表
  • 音效提醒：新订单、超时告警、操作确认音区分明显，可独立开关
  • 多平台标识：京东/美团/饿了么平台色值准确，品牌辨识度高
  • 三列布局：待接单/进行中/已完成三列等宽，卡片间距一致
  • 批量操作：批量接单/拒单支持多选，操作前有确认弹窗
  • 自动接单：自动接单开关状态持久化，开启时有明确视觉提示
  • 拒单流程：拒单需选择原因，支持自定义原因输入
  • 实时刷新：订单状态实时更新，刷新按钮手动触发有加载状态
  • 全屏模式：支持全屏/退出全屏切换，全屏下布局自适应
  • 响应式：支持 1280px ~ 1920px 屏幕宽度自适应
  • 数据统计：今日订单、销售额等数据准确，与实际订单一致
