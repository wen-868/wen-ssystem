页面总览

订单异常处理中心是 OMS 订单管理系统的核心模块之一，负责集中管理和处理多平台订单在流转过程中出现的各类异常情况。涵盖缺货、取消、退款、超时、配送失败、支付失败等异常类型，支持异常自动识别、分级告警、人工介入处理，并提供完整的处理记录追踪与统计分析功能，确保订单异常得到及时、高效的处理。

字段规范

异常记录字段

字段名 类型 必填 说明
exception_id String 是 异常记录唯一标识，格式 EXC-YYYYMMDD-NNNN
order_no String 是 关联订单号
exception_type Enum 是 异常类型：OUT_OF_STOCK / CANCEL / REFUND / TIMEOUT / DELIVERY_FAIL / PAY_FAIL
exception_level Enum 是 异常级别：WARNING(预警) / ERROR(错误) / CRITICAL(严重)
channel Enum 是 来源渠道：WECHAT / DOUYIN / MEITUAN / ELEME / JD / OFFLINE
exception_detail JSON 是 异常详情数据，JSON 格式，结构随异常类型不同而变化
summary String 是 异常摘要描述，最大 200 字符
status Enum 是 处理状态：PENDING / PROCESSING / RESOLVED / CLOSED
assignee String 否 处理人，初始为空
created_at DateTime 是 异常创建时间
resolved_at DateTime 否 异常解决时间

处理记录字段

字段名 类型 必填 说明
record_id String 是 处理记录唯一标识
exception_id String 是 关联异常记录 ID
action Enum 是 处理动作：CREATE / ASSIGN / PROCESS / RESOLVE / CLOSE
operator String 是 操作人，系统自动操作为 "SYSTEM"
solution String 否 处理方案描述，RESOLVE 动作时必填
result String 否 处理结果摘要
created_at DateTime 是 记录创建时间

验收标准

  • 异常统计卡片正确展示待处理异常数、今日新增、本周解决数、平均处理时长
  • 异常类型分布饼图使用 conic-gradient 正确展示各类型占比
  • 各渠道异常率柱状图数据准确，异常率最高的渠道以醒目颜色标出
  • 异常趋势折线图正确展示近 7 天异常数量变化趋势
  • 筛选栏支持按异常类型、级别、处理状态、渠道、日期范围、订单号组合筛选
  • 异常列表表格展示异常级别图标和颜色标签（WARNING黄色 / ERROR橙色 / CRITICAL红色）
  • 异常列表包含至少 10 行数据，涵盖不同级别（CRITICAL/ERROR/WARNING）和类型
  • 异常表格中"处理"按钮对"待处理"和"处理中"状态可见，"已解决"和"已关闭"仅显示"详情"
  • 点击"详情"按钮弹出异常详情弹窗（含左中右三栏布局）
  • 弹窗左侧展示异常基本信息（ID/类型/级别/状态/时间）和异常详情 JSON 代码块
  • 弹窗中间展示关联订单信息（订单号/渠道/客户/金额/商品明细/支付信息）
  • 弹窗右侧展示处理记录时间线（创建 -> 分配 -> 处理中 -> 已解决），含操作人/时间/方案
  • 弹窗底部支持分配处理人、填写处理方案、标记已解决、关闭异常操作
  • 分页组件支持翻页和每页条数切换
