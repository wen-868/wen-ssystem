页面总览

审批流程功能是平台核心工作流模块，支持多级审批链的灵活配置与执行。该模块包含三个子功能：审批规则（管理员配置审批链模板）、我的申请（用户发起和跟踪审批申请）、我的待办（审批人处理待审批任务）。支持条件触发、多级审批、SLA时效管控及超时自动升级等特性。

字段规范

审批规则字段

字段 字段标识 类型 必填 说明
规则名称rule_nameString是审批规则名称，最大50字符
描述descriptionString否规则描述，最大200字符
业务类型business_typeEnum是采购订单/销售退货/价格变更/信用额度
触发条件trigger_conditionJSON否JSON格式条件表达式，满足条件时触发审批
审批链approval_chainArray[Object]是审批级别数组，每个级别含审批人类型和值
SLA时效sla_hoursInteger是单位小时，超时触发升级
升级级别escalation_levelInteger否超时后自动升级到的审批级别

审批申请字段

字段 字段标识 类型 必填 说明
审批标题titleString是审批申请标题
审批规则IDrule_idString(UUID)是关联的审批规则
业务单号business_noString是关联的业务单据编号
审批内容contentText是审批内容详情
附件attachmentsArray[URL]否附件文件URL列表
状态statusEnum—审批中/已通过/已拒绝/已撤回
当前步骤current_stepInteger—当前审批进行到第几步

审批记录字段

字段 字段标识 类型 必填 说明
审批步骤stepInteger—审批步骤序号
审批人approverString—审批人姓名
审批结果resultEnum—已通过/已拒绝/待审批/未开始
审批意见commentText否审批人填写的意见
审批时间approved_atDateTime否审批操作时间

验收标准

  • 审批规则Tab：规则列表表格正确展示5条数据，包含不同业务类型标签
  • 审批规则Tab：点击"新增规则"按钮弹出大弹窗，包含所有必填字段
  • 新增规则弹窗：触发条件展示JSON代码编辑器样式，包含编辑按钮
  • 新增规则弹窗：审批链配置支持动态添加/删除审批级别，每个级别可独立选择审批人类型
  • 新增规则弹窗：审批级别支持拖拽调整顺序（显示拖拽手柄）
  • 新增规则弹窗：SLA时效和升级级别输入框正常工作
  • 我的申请Tab：列表正确展示6条申请记录，状态标签颜色正确（审批中=橙色/已通过=绿色/已拒绝=红色/已撤回=灰色）
  • 我的申请Tab：点击"提交新审批"弹出提交弹窗，包含审批标题、规则选择、业务单号、内容、附件上传
  • 我的申请Tab：点击"查看详情"可跳转至审批详情页，展示描述列表、审批内容和审批时间线
  • 审批详情页：垂直时间线正确展示每个审批步骤，含审批人头像(圆形)、姓名、状态标签、审批意见、时间
  • 审批详情页：时间线节点颜色正确（已通过=绿色、待审批=橙色、未开始=灰色）
  • 我的待办Tab：列表正确展示5条待办记录，SLA倒计时显示为红色
  • 我的待办Tab：点击"通过"或"拒绝"弹出确认弹窗，包含审批意见文本框和通过/拒绝/取消按钮
  • 通过/拒绝弹窗：通过按钮为绿色，拒绝按钮为红色，取消按钮为默认样式
  • 所有列表分页组件正常工作
  • 字段规范表完整覆盖审批规则、审批申请、审批记录三个实体
