页面总览

系统参数配置功能用于统一管理平台全局业务参数。管理员可通过此页面配置公司信息、订单规则、支付通道、库存策略及通知设置等核心参数。所有配置项按业务域分组为五个Tab页，支持即时保存与重置，变更后实时生效。

字段规范

配置项 字段标识 类型 所属分组 默认值 说明
公司名称 company_name String 通用配置 智云科技有限公司 系统全局显示的公司名称，最大50字符
公司Logo company_logo String(URL) 通用配置 — 图片URL，支持 PNG/JPG，建议 200x200px
联系电话 contact_phone String 通用配置 400-888-9999 对外公示的联系电话
系统主题色 theme_color String(Hex) 通用配置 #1677FF 十六进制颜色值，影响全局UI色调
自动接单 auto_accept Boolean 订单配置 true 开启后新订单自动接单，无需人工确认
订单超时时间 order_timeout Integer 订单配置 30 单位分钟，超时未支付自动取消
订单自动取消时间 auto_cancel_time Integer 订单配置 120 单位分钟，已接单但未处理的订单自动取消
自动确认收货天数 auto_confirm_days Integer 订单配置 15 发货后天数，超时自动确认收货
微信支付 wechat_pay.enabled Boolean 支付配置 true 开启后需填写 AppID、商户号、API密钥
支付宝 alipay.enabled Boolean 支付配置 true 开启后需填写 AppID、私钥、公钥
线下支付 offline_pay Boolean 支付配置 false 开启后支持货到付款等线下支付方式
低库存预警阈值 low_stock_threshold Integer 库存配置 10 库存低于此数量时触发预警
保质期预警天数 expiry_warning_days Integer 库存配置 30 距离保质期不足此天数时触发预警
自动补货 auto_replenish Boolean 库存配置 true 开启后低于阈值自动生成补货单
自动补货阈值 replenish_threshold Integer 库存配置 20 触发自动补货的库存数量
短信通知 notify.sms Boolean 通知配置 true 开启后通过短信渠道发送通知
微信通知 notify.wechat Boolean 通知配置 true 开启后通过微信渠道发送通知
站内信 notify.in_app Boolean 通知配置 false 开启后通过站内信渠道发送通知
通知事件 notify.events Array[String] 通知配置 ["订单通知","库存预警","异常告警"] 多选，控制哪些事件触发通知

验收标准

  • 页面顶部显示"参数配置"标题，导航面包屑正确显示层级路径
  • 左侧导航树中"参数配置"菜单项高亮为激活状态
  • 五个分组Tab（通用配置/订单配置/支付配置/库存配置/通知配置）可正常切换
  • 通用配置：公司名称输入框正常输入，Logo上传区显示虚线边框和预览图
  • 通用配置：系统主题色选择器展示圆形色块及调色板，点击可切换颜色
  • 订单配置：自动接单开关默认开启，超时时间等数字输入框带单位标签
  • 支付配置：微信支付/支付宝开关开启时展开对应配置项（AppID/商户号/密钥等）
  • 支付配置：线下支付开关关闭时不展开配置项
  • 库存配置：自动补货开启时显示自动补货阈值输入框
  • 通知配置：通知事件多选checkbox组正常工作，至少包含4个事件选项
  • 底部固定操作栏始终可见，包含"保存配置"蓝色主按钮和"重置"按钮
  • 点击"保存配置"按钮后触发保存逻辑，所有配置项值正确提交
  • 点击"重置"按钮后所有配置项恢复为上次保存的值
  • 字段规范表完整列出所有配置项的字段标识、类型、默认值等属性
