页面总览

订单分发与路由模块负责将聚合后的全渠道订单，按照预设的规则自动分发到对应门店或仓库进行处理。 支持灵活的路由规则配置，包括按渠道、区域、金额范围、商品类别、时间段、适用门店等维度进行条件匹配， 并支持自动分配门店、分配仓库、订单拆分等动作。同时提供分发日志追溯和分发看板可视化功能， 帮助运营团队实时掌握各门店订单负载情况，支持手动干预分发决策。

字段规范

路由规则字段

字段名 类型 必填 说明 示例值
rule_id String 是 规则唯一编号 RULE-001
rule_name String 是 规则名称 微信高端白酒
priority Integer 是 优先级，数字越小优先级越高 1
channels Array 是 适用渠道列表 ["wechat"]
region_province String 否 适用省份 北京市
region_city String 否 适用城市/区 朝阳区
min_amount Decimal 否 最低金额 0.00
max_amount Decimal 否 最高金额 50000.00
categories Array 否 适用商品类别 ["白酒"]
time_start Time 否 时间段开始 00:00
time_end Time 否 时间段结束 23:59
target_store String 是 目标门店ID STORE-001
target_warehouse String 否 目标仓库ID WH-001
split_enabled Boolean 否 是否启用拆分 true
split_condition Enum 否 拆分条件：by_category/by_quantity/by_amount by_category
enabled Boolean 是 启用状态 true

分发日志字段

字段名 类型 必填 说明 示例值
log_id String 是 日志唯一编号 LOG-20260630001
order_id String 是 聚合订单号 AGG2026063000123
channel Enum 是 来源渠道 wechat
trigger_rule String 否 触发的路由规则名称 微信高端白酒
source_store String 否 来源门店 --
target_store String 是 目标门店 北京朝阳旗舰店
dispatch_status Enum 是 分发状态：success/failed/pending success
dispatch_time DateTime 是 分发时间 2026-06-30T10:23:18Z
reason String 否 分发原因或失败原因 匹配规则优先级1

验收标准

  • 路由规则Tab页默认展示，支持切换到分发日志和分发看板Tab，切换时数据正确加载
  • 路由规则列表展示所有已配置规则，包含规则名称、适用渠道、优先级、条件摘要、启用状态
  • 点击"新增规则"按钮打开规则编辑弹窗，弹窗包含规则基本信息、条件构建器、动作选择三个区域
  • 条件构建器支持多渠道多选、区域选择、金额范围滑块、商品类别多选、时间段选择、门店多选
  • 金额范围滑块支持拖拽调节最低和最高金额，实时显示当前值
  • 动作选择支持指定分配门店、分配仓库，拆分规则开关可独立控制
  • 启用/禁用开关操作即时生效，关闭后对应规则不再参与自动分发
  • 分发日志列表展示所有分发记录，支持按分发状态、日期范围、关键词筛选
  • 分发日志中失败记录高亮显示，并展示具体失败原因
  • 分发看板以卡片形式展示各门店当前订单量和接单能力状态（空闲/忙碌/超载）
  • 接单能力状态颜色正确：绿色空闲、黄色忙碌、红色超载
  • 手动分发功能支持勾选待分发订单，选择目标门店/仓库后确认分发
  • 规则优先级匹配正确：多个规则同时满足时，按优先级数值从小到大依次匹配
  • 分页组件功能正常，支持页码切换和总记录数展示
