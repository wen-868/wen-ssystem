页面总览

订单状态同步模块负责管理多平台（微信、抖音、美团、饿了么、京东、线下）订单状态的双向同步。支持手动同步、定时任务自动同步，并提供同步日志查询与统计分析功能。通过统一的同步中心，确保各渠道订单状态与系统内订单状态保持一致，降低人工核对成本，提升运营效率。

字段规范

同步日志字段

字段名 类型 必填 说明
sync_id String 是 同步记录唯一标识，UUID v4
order_no String 是 订单号，格式 ORD-YYYYMMDD-NNN
channel Enum 是 渠道：WECHAT / DOUYIN / MEITUAN / ELEME / JD / OFFLINE
sync_type Enum 是 同步类型：PULL(拉取) / PUSH(推送)
source_status String 是 同步前的订单状态
target_status String 是 同步后的订单状态
sync_result Enum 是 同步结果：SUCCESS / FAIL
error_msg String 否 失败时的错误信息，最大 500 字符
sync_time DateTime 是 同步完成时间，格式 yyyy-MM-dd HH:mm:ss
duration_ms Integer 是 同步耗时，单位毫秒

定时任务配置字段

字段名 类型 默认值 说明
schedule_enabled Boolean true 定时同步开关
sync_interval Enum EVERY_30_MIN 同步频率：EVERY_5_MIN / EVERY_10_MIN / EVERY_30_MIN / EVERY_HOUR
sync_scope Enum ALL 同步范围：ALL(全部) / SPECIFIED(指定渠道)
sync_channels Array [] 当 scope=SPECIFIED 时生效，指定渠道列表
alert_on_fail Boolean false 失败时是否告警
alert_channels Array [] 告警方式：IN_APP / SMS / EMAIL

验收标准

  • 支持手动输入单个订单号进行即时同步，同步完成后显示结果反馈
  • 支持按渠道批量同步订单，同步前展示待同步订单数量确认
  • 支持全量同步所有渠道订单，操作前弹出二次确认提示
  • 同步进度条实时展示当前同步进度（百分比 + 已完成数/总数）
  • 统计卡片正确展示今日同步总数、成功数、失败数、待同步数
  • 各渠道同步成功率柱状图数据准确，低于90%的渠道以警告色标出
  • 定时任务支持配置同步频率（5分钟/10分钟/30分钟/每小时）
  • 定时任务支持选择全部渠道或指定渠道同步
  • 同步开关可正常开启/关闭定时任务，关闭后不再自动执行
  • 失败告警开关开启后，同步失败时按配置的告警方式发送通知
  • 同步日志表格支持按渠道、同步类型、同步结果、日期范围筛选
  • 同步日志表格展示 PULL/PUSH 类型标签，成功/失败结果标签颜色正确
  • 失败记录的 Tooltip 可以查看详细错误信息
  • 分页组件支持翻页和每页条数切换
