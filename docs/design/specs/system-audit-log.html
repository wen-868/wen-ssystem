版本 V1.0 | 2026-07-01 | 状态：设计中

页面总览

操作日志功能用于记录和追溯系统中所有用户的关键操作行为。系统自动捕获每次操作的操作用户、操作类型、资源类型、 操作描述、IP地址、设备信息及操作时间等关键信息。管理员可通过多维筛选条件（操作类型、资源类型、操作人、日期范围） 快速定位目标日志，并查看每条日志的详细请求参数和变更数据，满足安全审计和问题排查需求。

字段规范表

操作日志表 (sys_audit_log)

字段名 类型 必填 说明
id BIGINT 是 主键ID，自增
user_id VARCHAR(50) 是 操作人ID
username VARCHAR(50) 是 操作人姓名
operation_type VARCHAR(20) 是 操作类型：CREATE/UPDATE/DELETE/QUERY/LOGIN/EXPORT
resource_type VARCHAR(30) 是 资源类型：PRODUCT/ORDER/CUSTOMER/EMPLOYEE/STORE/MARKETING/SYSTEM
resource_id VARCHAR(100) 否 资源ID，非资源操作时为"-"
description VARCHAR(500) 是 操作描述
ip_address VARCHAR(45) 是 操作来源IP地址
device_info VARCHAR(200) 否 设备信息（浏览器/操作系统）
request_params TEXT 否 请求参数（JSON格式）
change_data TEXT 否 变更前后数据（JSON格式，含old和new）
trace_id VARCHAR(64) 否 链路追踪ID
created_at DATETIME 是 操作时间（索引列）

验收标准清单

  • 操作日志列表页正确展示所有日志记录，包含ID、操作人、操作类型、资源类型、操作描述、IP、设备、操作时间
  • 统计卡片区域正确展示今日操作、新增、修改、删除、查询、操作用户六项数据，数值与后端数据一致
  • 操作类型筛选下拉框包含全部、新增、修改、删除、查询、登录、导出七个选项，切换后表格数据正确过滤
  • 资源类型筛选下拉框包含全部、商品、订单、客户、员工、门店、营销、系统八个选项，筛选功能正常
  • 操作人ID输入框支持模糊搜索，输入后点击搜索按钮正确过滤日志
  • 日期范围选择器支持选择起止日期，筛选后仅显示该时间段内的日志
  • 操作类型标签颜色正确：新增-绿色、修改-蓝色、删除-红色、查询-灰色、登录-橙色、导出-橙色
  • 点击"导出"按钮触发当前筛选条件下的日志数据导出，导出格式为 Excel
  • 点击"详情"按钮从右侧展开日志详情抽屉，显示基本信息、请求参数、变更数据
  • 日志详情抽屉中基本信息以描述列表形式展示，包含日志ID、操作人、操作类型、资源类型、资源ID、操作描述、IP地址、设备、操作时间
  • 请求参数以JSON代码块展示，灰色背景、等宽字体，语法高亮
  • 变更数据以diff对比形式展示，红色背景行表示变更前数据（删除行），绿色背景行表示变更后数据（新增行）
  • 分页功能正常，支持页码切换、上一页/下一页，显示总记录数
  • 表格支持响应式水平滚动，小屏幕下不破坏布局
