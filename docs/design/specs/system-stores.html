页面总览

门店管理模块用于维护连锁门店的基础信息，支持门店的新增、编辑、查看详情、启用/停用等操作。管理员可通过搜索条件快速定位门店，查看门店营业状态、联系方式及地理位置信息，并与微信商户信息进行关联配置。

字段规范

字段名 数据类型 必填 说明 示例值
store_code VARCHAR(20) 是 门店编码，系统自动生成，可手动修改 ST001
store_name VARCHAR(100) 是 门店名称 朝阳旗舰店
address VARCHAR(255) 是 门店详细地址 北京市朝阳区建国路88号
phone VARCHAR(20) 是 联系电话 010-88886666
contact_person VARCHAR(50) 否 联系人姓名 张经理
delivery_radius DECIMAL(5,1) 否 配送半径，单位 km 5.0
status TINYINT 是 营业状态：1-营业中 2-已关闭 3-暂停中 1
app_id VARCHAR(64) 否 微信小程序 AppID wx1234567890abcdef
mch_id VARCHAR(64) 否 微信商户号 MCH-20240115001
api_key VARCHAR(128) 否 商户 API 密钥（加密存储） ***********
avatar_url VARCHAR(255) 否 门店头像图片 URL /uploads/store/avatar/001.jpg
open_time TIME 否 营业开始时间 08:00:00
close_time TIME 否 营业结束时间 22:00:00

latitude DECIMAL(10,7) 否 门店纬度 39.9087654

验收标准

  • 门店列表页面正常加载，表头与数据列对齐
  • 搜索框支持按门店编码进行模糊搜索
  • 搜索框支持按门店名称进行模糊搜索
  • 营业状态标签正确显示：营业中（绿色）、已关闭（灰色）、暂停中（橙色）
  • 点击新增门店按钮弹出新增弹窗，表单字段完整
  • 门店编码自动生成，格式为 ST + 三位数字序号
  • 门店编码支持手动修改，且校验唯一性
  • 表单必填字段（门店编码、门店名称、地址、电话、营业状态）校验提示
  • 联系电话格式校验（支持座机与手机号）
  • 微信小程序 AppID 拉取按钮可正常调用接口
  • 门店头像支持图片上传，限制格式与大小
  • 营业时间选择器支持开始-结束时间范围选择
  • 点击编辑按钮加载对应门店数据到弹窗表单
  • 点击停用按钮，营业中门店变为暂停中状态
  • 点击启用按钮，已关闭/暂停中门店恢复正常
  • 点击详情按钮，右侧展开详情抽屉
  • 详情抽屉显示完整门店信息（基本信息、微信商户、地图定位、营业信息）
  • API密钥在详情抽屉中以掩码形式显示
  • 地图定位区域正确渲染地图组件
  • 分页组件正常翻页，显示总条数
  • 统计卡片数据（门店总数/营业中/暂停中/已关闭）与列表数据一致
  • 所有操作均有 loading 状态与成功/失败提示
