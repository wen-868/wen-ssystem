页面总览

支付配置页面是管理后台「系统设置」模块下的核心功能页面，用于集中管理平台的支付渠道配置。 管理员可以在此页面配置和测试微信支付、支付宝以及银行账号信息，确保支付功能正常运行。

页面采用 Tab 切换设计，包含三个标签页：

  • 微信支付 -- 配置微信支付商户平台相关参数，包括 AppID、商户号、API 密钥、证书及回调地址
  • 支付宝 -- 配置支付宝开放平台应用参数，包括 AppID、应用私钥、支付宝公钥及回调地址
  • 银行账号 -- 管理银行收款账号信息，支持添加、编辑、删除、设为默认账号等操作

字段规范表

支付配置字段

字段名 所属渠道 必填 类型 控件 说明
app_id 微信支付 * String 输入框 微信支付 AppID，来自 pay.weixin.qq.com 商户平台
mch_id 微信支付 * String 输入框 微信支付商户号
api_v3_key 微信支付 * String 密码输入框 API v3 密钥，敏感字段，加密存储
serial_no 微信支付 * String 输入框 证书序列号
private_key 微信支付 * Text 文本域 商户私钥，PEM 格式，monospace 字体
notify_url 微信支付 * String 输入框 支付回调地址，接收微信支付结果通知
alipay_app_id 支付宝 * String 输入框 支付宝开放平台 AppID
alipay_private_key 支付宝 * Text 文本域 应用私钥，敏感字段，加密存储，monospace 字体
alipay_public_key 支付宝 * Text 文本域 支付宝公钥，非敏感字段
alipay_notify_url 支付宝 * String 输入框 支付回调地址

银行账号字段

字段名 必填 类型 控件 说明
bank_name * String 输入框 银行名称
branch_name * String 输入框 支行名称
account_name * String 输入框 开户名
account_number * String 输入框 银行账号，列表展示时脱敏
bank_code * String 输入框 银行联行号
qrcode_image 否 File 图片上传 收款码图片，虚线边框上传区
remark 否 Text 文本框 备注信息
is_default 否 Boolean 按钮 是否默认账号，仅一个为默认

验收标准清单

  • 页面顶部导航栏正确显示 Logo、系统设置菜单高亮、用户头像
  • 左侧导航树中「系统设置」分组展开，子菜单「支付配置」处于选中高亮状态
  • 页面顶部面包屑导航正确显示「系统设置 / 支付配置」
  • 三个 Tab（微信支付、支付宝、银行账号）可正常切换，切换后内容正确显示
  • 微信支付 Tab 默认启用，toggle 开关为绿色开启状态
  • 微信支付 Tab 的重要提示卡片以黄色背景显示，内容包含 AppID 来源说明
  • 敏感字段（API v3 密钥、应用私钥）使用密码输入框，包含显示/隐藏眼睛图标
  • 点击密码字段的眼睛图标可在明文/密文之间切换
  • 商户私钥字段使用文本域控件，monospace 字体，说明文字为「PEM格式私钥内容」
  • 微信支付 Tab 底部操作栏包含「测试连接」按钮（蓝色）和「保存」按钮（绿色）
  • 测试连接后显示连接状态标签（成功为绿色，失败为红色）及最后测试时间
  • 支付宝 Tab 默认未启用，toggle 开关为灰色关闭状态
  • 银行账号 Tab 显示至少 3 张银行卡片，其中 1 张标记为「默认」（金色标签）
  • 银行账号列表中的账号以脱敏格式显示（**** **** **** 1234），包含显示/隐藏眼睛图标
  • 每张银行卡片包含：银行名称、支行名称、开户名、账号、联行号、收款码占位图、操作按钮
  • 默认银行账号卡片的「设为默认」按钮处于禁用状态
  • 添加/编辑银行账号弹窗包含所有必填字段、收款码上传区（虚线边框）、保存和取消按钮
  • 字段规范表正确列出支付配置字段和银行账号字段，包含字段名、必填标记、类型、控件、说明
