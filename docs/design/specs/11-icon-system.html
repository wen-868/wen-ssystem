图标与插画系统规范

Iconography & Illustration System — 供应链管理系统三端统一图标库

1. 设计原则

图标系统遵循以下核心原则，确保三端视觉一致性

一致性

统一描边宽度2px，圆角半径2px，视觉密度14px

可识别性

图标语义清晰，无需文字辅助即可理解

可缩放性

支持16/20/24/32px四档尺寸，SVG矢量格式

无障碍

满足WCAG 2.1 AA对比度标准，支持高对比度模式

8. 插画系统（Illustrations）

用于空状态、错误页、Onboarding、成功反馈等场景的插画

空状态 - 无数据

用于列表/表格无数据时展示。画面简洁，传达"暂无内容"信息，引导用户创建首条记录。

Empty State

错误状态 - 操作失败

用于接口请求失败、操作异常等场景。红色调传达错误信息，引导用户重试。

Error State

成功状态 - 操作完成

用于提交成功、保存成功、入库完成等场景。绿色调传达正面反馈，增强用户信心。

Success State

警告状态 - 需确认

用于删除确认、库存预警、数据异常等场景。橙色调传达警示信息，提示用户注意。

Warning State

加载状态 - 数据加载中

用于页面/列表/卡片加载中。蓝色调传达"处理中"语义，脉动动画增强感知。

Loading State

权限不足 - 无访问权限

用于403无权限页面。紫色调传达"受限"语义，提示用户联系管理员。

403 Forbidden

9. 图标使用规范

规范项要求说明
描边宽度2px所有线性图标统一描边宽度
圆角2px线条端点与连接处圆角
视觉密度14px图标在16px容器内的视觉尺寸
最小间距4px图标与相邻文字/元素的最小间距
颜色currentColor使用SVG currentColor继承父级文字颜色
对比度≥3:1图标与背景对比度满足WCAG AA标准
点击区域≥44x44px可交互图标的最小触摸/点击区域
格式SVG统一使用SVG格式，支持缩放和颜色继承
命名icon-{category}-{name}如 icon-nav-dashboard, icon-action-add
