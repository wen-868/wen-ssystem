4. 字段规范

字段类型说明
cardNoString卡号，格式 SV + 序号
customerIdUUID客户ID
customerNameString客户名称
balanceDecimal当前余额
totalRechargeDecimal累计充值金额
totalConsumeDecimal累计消费金额
statusEnumACTIVE / FROZEN / CANCELLED
openDateDate开卡日期
recordsArray充值/消费记录列表
record.typeEnumRECHARGE / CONSUME / REFUND
record.amountDecimal变动金额（正=充值，负=消费）
record.balanceAfterDecimal变动后余额

5. 验收标准

#验收项标准
1开卡弹窗选择客户+初始金额+支付方式，确认后生成卡号
2充值支持多次充值，余额累加，生成充值记录
3消费关联销售订单自动扣减余额，余额不足提示
4冻结/解冻支持冻结卡片（禁止消费），解冻恢复
5消费记录完整展示充值/消费/退款流水，按时间倒序
6退款支持退款操作，退回余额，生成退款记录
