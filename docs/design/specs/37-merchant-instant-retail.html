37 · 商户端即时零售 — 设计规格文档

移动端 H5 / 小程序 · 订单管理 · 订单详情 · 库存同步

1. 页面总览

商户端即时零售模块是面向门店商户的移动端订单处理与库存管理工具，整合京东到家、美团、饿了么等多平台订单，提供统一接单、订单处理、配送跟踪、库存同步等核心功能。商户可通过移动端实时处理各平台订单，同步商品库存，提升即时零售运营效率。

设计目标：统一多平台订单入口、加速接单响应、降低库存超卖、提升订单履约效率。

2. 移动端原型

375px 手机视口，并排展示订单管理页、订单详情页、库存同步页。

4. 验收标准

  • 手机框宽度375px，6px深灰色边框，28px圆角，带阴影效果
  • 页面使用28px状态栏 + 44px导航栏 + 内容区 + 底部Tab栏标准布局
  • 订单管理页顶部有消息铃铛图标，右上角红色数字角标显示未读数量
  • 数据概览2x2网格卡片，展示今日订单数、销售额、待接单数、配送中数
  • 每个概览卡片带图标、数值、环比箭头（上升绿/下降红）
  • 订单状态Tab（全部/待接单/配送中/已完成/已取消），待接单带红色数字角标
  • 待接单订单卡片左侧有黄色高亮边框（4px）
  • 每张订单卡片顶部显示平台来源标签（京东红/美团黄/饿了么蓝）+ 订单号 + 时间
  • 订单卡片中间显示用户昵称+电话、商品明细（前2个+更多）、订单备注（黄色背景）
  • 订单卡片底部左侧显示实付金额（红色大字），右侧显示操作按钮
  • 不同订单状态显示不同颜色的状态标签（待接单黄/配送中蓝/已完成绿/已取消灰）
  • 列表顶部有"下拉刷新"提示，底部有"上拉加载更多"提示
  • 接单提醒弹窗有全屏半透明黑色遮罩 + 中央订单卡片 + 左右震动动画
  • 弹窗顶部红色渐变背景，显示60秒倒计时（monospace字体）
  • 弹窗底部有拒单（灰色）和立即接单（绿色）两个按钮
  • 订单详情页顶部大状态文字，不同状态不同颜色（黄/蓝/绿）
  • 详情页包含配送信息、商品明细、金额明细、订单备注四个卡片分区
  • 商品明细显示商品图、名称、规格、单价、数量，底部有商品合计
  • 金额明细包含商品金额、配送费、优惠金额，底部高亮显示实付金额
  • 订单备注使用黄色背景卡片样式
  • 底部操作栏根据订单状态显示不同按钮组合（待接单：拒单/确认接单等）
  • 库存同步页顶部有同步状态卡片，显示上次同步时间、同步状态、商品总数、差异数
  • 平台筛选Tab（全部/京东/美团/饿了么），选中态蓝色背景白色文字
  • 每张库存商品卡片显示商品图、名称、SKU、本地库存数量
  • 商品卡片中部显示三平台库存小标签（对应平台色），底部显示同步状态和单商品同步按钮
  • 同步状态分三种：已同步（绿）/待同步（黄）/同步失败（红）
  • 底部操作栏有"按平台同步"和"一键全量同步"按钮
  • 数据概览页包含本周销售趋势折线图（SVG绘制+渐变填充）
  • 平台销售占比使用CSS conic-gradient饼图，中心显示总单量
  • 热门商品TOP5排行，前3名有金银铜色排名徽章
  • 底部导航栏4个Tab（首页/订单/商品/我的），当前页激活态高亮
  • 所有字体使用系统默认字体栈，无外部依赖，纯CSS实现UI
