版本 V1.0 | 2026-07-01 | 状态：设计中

页面总览

角色权限管理功能用于管理后台系统的角色定义与权限分配。管理员可通过该模块创建不同的角色（如店长、收银员、库管等）， 为每个角色配置菜单权限及数据权限范围，并将角色分配给具体用户。通过角色权限体系实现精细化的权限控制， 确保不同岗位的用户只能访问其职责范围内的功能和数据。

字段规范表

角色表 (sys_role)

字段名 类型 必填 说明
id BIGINT 是 主键ID，自增
role_name VARCHAR(50) 是 角色名称，全局唯一
role_code VARCHAR(50) 是 角色编码，全局唯一，大写字母+下划线
description VARCHAR(200) 否 角色描述
status TINYINT 是 状态：0-禁用，1-启用，默认1
data_scope VARCHAR(20) 是 数据权限范围：ALL/DEPT/STORE/SELF
created_at DATETIME 是 创建时间
updated_at DATETIME 是 更新时间

权限表 (sys_permission)

字段名 类型 必填 说明
id BIGINT 是 主键ID，自增
parent_id BIGINT 否 父级权限ID，0表示顶级
perm_name VARCHAR(50) 是 权限名称
perm_code VARCHAR(100) 是 权限编码，如 system:role:read
perm_type VARCHAR(20) 是 权限类型：MODULE/PAGE/BUTTON
sort_order INT 否 排序号

验收标准清单

  • 角色列表页正确展示所有角色数据，包含角色名称、编码、描述、用户数、状态、创建时间
  • 角色状态标签正确显示：启用状态为绿色，禁用状态为灰色
  • 点击"新增角色"按钮弹出新增角色弹窗，包含基本信息、数据权限范围、菜单权限树三个区域
  • 新增角色表单：角色名称和角色编码不能为空，提交时进行前端校验
  • 数据权限范围下拉框包含全部数据、所属部门、所属门店、仅本人四个选项
  • 菜单权限树支持三级展开：模块级、页面级、按钮级，且展开/折叠交互正常
  • 权限树复选框支持三态：全选（checked）、半选（indeterminate）、未选，父级状态随子级变化
  • 子级权限独立勾选/取消不影响兄弟节点，但影响父级全选/半选状态
  • 点击"编辑"按钮加载角色现有数据，正确回显到弹窗中
  • 点击"分配用户"按钮弹出分配用户弹窗，显示角色名称作为标题
  • 分配用户弹窗中搜索框支持按用户名/手机号模糊搜索，已选用户显示为标签且可删除
  • 已分配用户列表表格展示用户名、姓名、手机号、所属门店，支持移除操作
  • 点击删除按钮弹出二次确认弹窗，提示该角色下已分配的用户数量及删除后果
  • 分页功能正常，支持页码切换和数据总量显示
