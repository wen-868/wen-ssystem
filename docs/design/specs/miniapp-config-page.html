字段规范

小程序配置字段

字段名 类型 必填 说明 示例
app_id string 是 小程序 AppID，来自对应平台开放平台 wx1234567890abcdef
app_secret string 是 小程序 AppSecret，加密存储，前端不可明文展示 enc:aes256:xxx...
app_name string 是 小程序名称，显示在小程序顶部 酒水优选
app_icon string (url) 否 小程序图标 URL，建议 144x144px PNG https://cdn.example.com/icon.png
platform enum 是 平台类型：wechat / alipay / douyin / kuaishou wechat

模板字段

字段名 类型 必填 说明 示例
template_id string (uuid) 是 模板唯一标识 tpl_abc123...
template_name string 是 模板名称 经典蓝白
template_description string 否 模板描述文案 蓝白配色，简洁大方...
template_thumbnail string (url) 是 模板缩略图 URL https://cdn.example.com/thumb.png
template_screenshots array[string] 否 大图预览截图列表，用于轮播展示 ["url1","url2","url3"]
status enum 是 模板状态：active / inactive active

发布日志字段

字段名 类型 必填 说明 示例
publish_id string (uuid) 是 发布日志唯一标识 pub_xyz789...
version string 是 发布版本号，遵循 semver v2.4.1
platform enum 是 发布平台：wechat / alipay / douyin / kuaishou wechat
template_name string 是 发布时使用的模板名称 经典蓝白
action enum 是 操作类型：publish / update publish
result enum 是 发布结果：success / failure success
error_message string 否 失败时的错误信息 代码包大小超过限制
publish_time datetime 是 发布时间 2026-07-01 10:15:32
status enum 是 当前生效状态：draft / published published

验收标准

  • 页面顶部显示"小程序配置"标题及面包屑导航"系统设置 / 小程序配置"
  • 平台 Tab 切换栏显示微信、支付宝、抖音、快手四个选项，默认选中微信
  • 点击不同平台 Tab 时，下方凭证配置、模板选择、发布历史等区域内容切换为对应平台数据
  • 重要提示区域以黄色背景卡片展示，文案明确指出 AppID 来源平台
  • AppID 输入框支持输入英文字母、数字及特殊字符，无长度限制校验提示
  • AppSecret 输入框默认以 password 类型显示密文，旁边有眼睛图标可切换明文/密文
  • 小程序图标上传区域显示虚线边框，点击可触发文件选择，支持预览已上传图片
  • 模板选择区以 3 列网格展示模板卡片，每张卡片包含缩略图、名称和描述
  • 选中模板卡片时，边框变为蓝色（2px solid #1677FF），右上角出现蓝色勾选图标
  • 点击"查看大图预览"可弹出预览弹窗，支持多张截图轮播查看
  • 一键发布按钮点击后进入 loading 状态，显示 spinner 及"正在编译发布..."文案
  • 发布成功后显示绿色结果卡片，包含版本号、模板名称和发布时间
  • 发布失败后显示红色结果卡片，包含错误信息及"重新发布"按钮
  • 发布历史表格包含版本号、模板、操作、结果、错误信息、发布时间六列
  • 发布历史表格中成功记录显示绿色"成功"标签，失败记录显示红色"失败"标签
  • 发布历史表格支持分页，底部显示页码和总条数
  • 左侧导航树中"小程序配置"菜单项高亮显示，与其他菜单项区分
  • 页面顶部统计卡片显示已配置平台数、已发布版本数、最新版本号和发布成功率
