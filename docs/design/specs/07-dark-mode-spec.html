1. 切换机制

方式触发条件优先级
系统偏好prefers-color-scheme: dark 媒体查询自动检测
手动切换[data-theme="dark"] 属性覆盖系统偏好
Class 切换.theme-dark 类名兼容旧版
/* 自动跟随系统 */
@media (prefers-color-scheme: dark) {
  :root { ... }
}

/* 手动切换（覆盖系统） */
[data-theme="dark"] { ... }

/* JS 切换 */
document.documentElement.setAttribute('data-theme', 'dark');
document.documentElement.removeAttribute('data-theme');

4. 暗色模式设计规则

规则说明
不纯黑背景使用深蓝灰 (#0F172A) 而非纯黑 (#000)，减少眼部疲劳
降低对比度暗色下白底黑字会刺眼，文字使用浅灰 (#E5E7EB) 而非纯白
提高品牌色亮度暗色下 #1677FF 亮度不足，提升至 #409EFF
语义色不变success/warning/danger 语义色在暗色下保持不变，确保识别性
阴影加深暗色下阴影需要更重才能产生层次感
图片不变产品图片、Logo 不随暗色模式变化
图表适配ECharts 图表颜色需在暗色下调整，保持可读性

5. 实现要点

/* 1. 使用 CSS 变量，不要硬编码颜色 */
/* 正确 */ color: var(--text-primary);
/* 错误 */ color: #1F2328;

/* 2. 语义色在暗色下不变 */
/* success/warning/danger 的 --color-* 值在暗色下与浅色相同 */

/* 3. 过渡动画 */
* { transition: background-color 0.3s, color 0.3s, border-color 0.3s; }

/* 4. 存储用户偏好 */
localStorage.setItem('theme', 'dark');
const theme = localStorage.getItem('theme') || 'auto';
