页面总览
商户端订单管理是面向商户的移动端H5/小程序应用，提供订单全生命周期管理能力。 商户可通过该功能查看各渠道订单列表、处理订单状态流转（确认接单、配送、完成）、管理异常订单、处理售后申请等。 覆盖微信、抖音、美团、饿了么、京东及线下等全渠道订单，支持订单状态筛选、数据概览、异常预警等核心功能。 目标用户为商户运营人员，使用场景为手机端浏览器或小程序环境。

字段规范

订单字段

字段名 类型 必填 说明
order_id string 是 订单唯一标识
channel enum 是 订单来源渠道：wechat/douyin/meituan/eleme/jd/offline
order_status enum 是 订单状态：pending/confirmed/delivering/completed/cancelled
customer_name string 是 客户姓名
customer_phone string 是 客户联系电话
total_amount decimal 是 订单总金额
discount_amount decimal 否 优惠金额
delivery_fee decimal 否 配送费
paid_amount decimal 是 实付金额
delivery_address string 否 配送地址
delivery_method string 否 配送方式
expected_delivery_time datetime 否 预计送达时间
order_note string 否 订单备注
is_abnormal boolean 是 是否为异常订单
abnormal_type string 否 异常类型，如缺货、超时等
created_at datetime 是 订单创建时间

售后字段

字段名 类型 必填 说明
aftersale_id string 是 售后单唯一标识
order_id string 是 关联的订单ID
aftersale_type enum 是 售后类型：refund/return_refund
aftersale_status enum 是 售后状态：pending/processing/refunding/completed/rejected
refund_amount decimal 是 退款金额
reason string 是 售后原因
description string 否 问题说明
return_logistics_no string 否 退货物流单号
return_express_company string 否 退货快递公司
created_at datetime 是 售后创建时间
验收标准
  • 订单列表页正确展示今日订单数、今日金额、待处理数、异常数四个数据概览卡片
  • 异常提醒横幅在有异常订单时正确显示，点击可跳转异常订单列表
  • 渠道筛选Tab（全部/微信/抖音/美团/饿了么/京东/线下）切换正常，数据过滤正确
  • 状态筛选Tab（待处理/已确认/配送中/已完成/已取消）切换正常，数据过滤正确
  • 待处理订单卡片左侧黄色边框高亮显示，底部操作按钮为"确认接单"和"拒单"
  • 异常订单卡片左侧红色边框高亮，显示异常图标和原因简述
  • 已确认状态的订单卡片底部显示"开始配送"按钮
  • 配送中状态的订单卡片底部显示"完成配送"按钮
  • 订单详情页正确展示订单状态、基本信息、商品明细、金额明细、配送信息、订单备注
  • 订单详情页底部操作栏根据订单状态显示对应按钮（待处理/已确认/配送中/已完成）
  • 异常订单详情页正确展示异常信息（类型、级别、原因）、关联订单、处理建议
  • 异常订单详情页包含申诉入口按钮和处理记录时间线
  • 售后列表页正确展示售后单，支持按售后状态Tab筛选
  • 售后详情页正确展示售后信息、商品信息、退款金额、处理进度时间线
  • 底部Tab导航正确高亮当前所在页面（订单Tab为active状态）
  • 下拉刷新和上拉加载更多功能交互正常
  • 各渠道标签颜色与渠道对应正确（微信绿、抖音黑、美团黄、饿了么蓝、京东红、线下灰）
  • 所有金额显示格式统一，实付金额和退款金额使用醒目样式展示
