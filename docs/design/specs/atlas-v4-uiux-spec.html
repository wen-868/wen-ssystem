01 设计理念

Atlas v4 是对系统视觉语言的全面重构。核心理念：让信息回归本质，让颜色回归职能。

1.1 核心原则

原则说明
信息优先界面黑白灰为主，颜色仅在操作引导（按钮）和状态传达（标签）时出现
极简克制KPI 图标背景、变化箭头、表单标签、卡片底色一律不使用彩色
导航突显侧边栏和顶部导航使用蓝色字体，与内容区形成唯一彩色识别带
一致性亮色/暗色双模，通过 CSS 变量统一切换，组件行为跨端一致

1.2 终端适配

终端屏幕宽度布局策略导航方式
桌面管理后台≥1024px侧边栏 200px + 内容区自适应左侧垂直导航
平板768-1023px侧边栏折叠为汉堡菜单顶部横栏 + 抽屉
手机（商家端/门店）320-767px单列纵向堆叠底部标签栏
设计哲学说明：颜色不是装饰，是语义。当一切都被染色时，没有任何颜色能传达信息。Atlas v4 通过剥夺大部分区域的彩色，让少数保留颜色的元素（激活导航、主按钮、状态标签）获得更强的引导力。

02 色彩系统

Atlas v4 的色彩体系以中性灰阶为基础，仅在三个语义点引入颜色：导航激活、操作引导、状态传达。

09 设计禁令附录（Design Bans）

以下做法在本系统中严格禁止：

✕
KPI 卡片图标使用彩色背景 — 应用 #F0F0F0
✕
数据涨跌使用绿色/红色箭头 — 应用 #999999
✕
表单必填标记使用红色星号 — 应用灰色文字"必填"
✕
表格行隔行变色 — 保持白底统一
✕
删除按钮填充红色 — 应用灰边框+红字
✕
侧边栏所有导航项统一蓝色 — 默认灰色，仅激活项变蓝 #5B6ABF
✕
卡片使用彩色顶部色条 — 应用灰底或无边线
✕
弹窗标题栏使用蓝色背景 — 应用白底+黑字
