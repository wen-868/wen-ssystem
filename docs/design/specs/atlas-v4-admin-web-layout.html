📐 设计要点说明

布局结构

左侧 220px 侧边栏 + 右侧自适应主内容区。顶部 60px 面包屑栏，下方滚动内容区。经典后台布局，信息层级清晰。

色彩应用

侧边栏浅灰底 (#FAFAFA)，导航项灰字，激活项蓝底蓝字。卡片白底灰边，数据文字纯黑，状态标签保留彩色（成功绿/警告橙/危险红）。

KPI 卡片

顶部装饰条用彩色细条（蓝/绿/橙/紫）点缀，图标区用浅灰底，数值文字纯黑加粗，趋势用小字号彩色标识。

表格设计

表头浅灰底，行分割线用浅灰，hover 态浅灰背景。禁用斑马纹（避免过多色块），状态用彩色 tag 区分。
