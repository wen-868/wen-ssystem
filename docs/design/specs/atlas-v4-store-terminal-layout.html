📐 设计要点说明

三栏式布局

左 180px 分类导航（图标+文字+数量），中间自适应商品网格（160px 卡片），右 380px 购物车+结算。比例合理，信息密度适中。

触屏优化

所有可点击元素最小 40px 高度，数量控制按钮加大（26px），结算按钮 52px 大按钮突出显示，适合收银触屏设备操作。

色彩应用

分类栏浅灰底（#FAFAFA），商品卡片白底灰边，价格保留蓝色突出。结算区白色背景，主结算按钮蓝色大按钮最醒目。

操作效率

顶部搜索框 + F1 快捷键，快捷支付方式底部一键选择，挂单按钮常驻，会员信息清晰展示折扣，最大化收银效率。
