08 动效系统

Token值曲线使用场景
--transition-fast0.15s easeeasehover 状态切换、图标变化、微交互
--transition-normal0.25s easeease展开/收起、切换、fade in/out
--transition-slow0.35s easeease页面切换、模态框进出、路由过渡
--transition-spring0.35s cubic-bezier(0.34,1.56,0.64,1)弹性弹窗弹出、通知出现、弹跳效果

动效原则

  • 出场快于入场：出场动画 0.15s，入场动画 0.25s-0.35s
  • 弹性用于强调：spring 仅用于需要吸引注意力的场景
  • 尊重用户偏好：prefers-reduced-motion 时关闭所有动画
  • 不超过 400ms：任何动画不超过 400ms，避免用户等待

11 表单设计规范

对齐项目统一标准 第六章，Element Plus 表单校验必须使用"三件套"模式：ref + :model + :rules，三者缺一不可。

表单三件套 — UI 表现

要素Vue 写法UI 影响缺失后果
ref ref="formRef" 提供表单实例引用，用于 formRef.validate() 手动触发校验 无法用 JS 调起校验，提交按钮时报错 Cannot read properties of undefined
:model :model="formData" 绑定表单数据对象，校验器读取 model 中的字段值进行验证 校验规则虽然定义了，但校验器读不到数据，校验永远不触发
:rules :rules="formRules" 定义校验规则，控制每个字段的验证逻辑和错误提示文案 表单提交无校验，脏数据直接入库

校验规则 UI 状态

状态样式触发时机说明
默认输入框正常边框 #DCDFE6初始加载无任何交互前的状态
聚焦边框变蓝 #1677FF + 外发光 0 0 0 3px rgba(22,119,255,0.1)click/focus用户正在输入
校验通过边框变绿 #10B981 + 绿色对勾图标blur 后校验通过输入格式正确，可提交
校验失败边框变红 #EF4444 + 红色错误文字（12px）blur 后校验失败输入格式错误，不可提交
禁用灰色背景 #F5F7FA + 灰色文字 #C0C4CC条件禁用不可编辑状态

提交按钮规范

场景按钮样式说明
新增/编辑弹窗主按钮"确定"（蓝色）+ 次要按钮"取消"（默认）右对齐，确定在右
表单页主按钮"保存"（蓝色）+ 次要按钮"重置"（默认）左对齐，保存后 toast 提示
批量操作主按钮"批量确认"（蓝色）选中项高亮后启用
危险操作主按钮"确认删除"（红色 #EF4444）需二次确认弹窗

12 错误提示设计

对齐项目统一标准 第三章（全局返回体），所有错误提示必须包含 traceId，方便问题追踪和飞书告警定位。

统一错误返回体

{
  "code": "400",
  "msg": "参数错误：商品名称不能为空",
  "traceId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "apiCost": 1
}

错误提示 UI 分类

类型UI 组件位置内容要点
表单字段错误 el-form-item 下方红色文字 输入框正下方 仅显示错误描述，不显示 traceId（避免干扰用户）
操作失败 Toast ElMessage.error() 页面顶部居中 "操作失败，请稍后重试。追踪ID: a1b2c3d4"
traceId 使用灰色小字 11px 显示在错误描述下方
批量操作失败 ElMessageBox.alert() 页面居中弹窗 弹窗标题"操作异常"，正文列出失败项 + traceId，底部"复制追踪ID"按钮
系统级错误 ElNotification 右上角通知 标题"系统异常"，内容"错误码: 500 · 追踪ID: xxx"，持续 5 秒，可手动关闭
网络超时 ElMessage.warning() 页面顶部居中 "网络请求超时，请检查网络连接后重试。" + 重试按钮
401 未认证 ElMessageBox.confirm() 页面居中弹窗 "登录已过期，请重新登录。" → 确认后跳转登录页
403 权限不足 ElMessage.error() 页面顶部居中 "您没有权限执行此操作。"
404 资源不存在 ElMessage.error() 页面顶部居中 "请求的资源不存在或已被删除。"

traceId 展示规范

规则：

  • traceId 在 Toast/弹窗中显示为灰色小字（11px, #9CA3AF），附在错误描述下方
  • traceId 支持一键复制（点击或右侧复制按钮）
  • 弹窗中的 traceId 附带"复制追踪ID"按钮，复制后按钮变为"已复制"（绿色）
  • 表单字段级别的校验错误不显示 traceId，避免信息过载
  • traceId 格式：UUID v4（36 字符），显示为 a1b2c3d4-e5f6-7890-abcd-ef1234567890

13 价格展示设计

对齐项目统一标准 第五章（价格隔离），不同角色看到不同价格，UI 上必须明确区分批发价、零售价、成本价。

价格类型与 UI 区分

价格类型UI 颜色字体前缀/后缀可见角色
零售价 #1F2328 黑色 font-weight: 600, 16px ¥ 前缀 全部角色
批发价 #1677FF 蓝色 font-weight: 600, 16px ¥ 前缀 + "批发"标签 批发商、管理员
成本价 #9CA3AF 灰色 font-weight: 400, 14px ¥ 前缀 + "成本"标签 仅管理员
划线价（原价） #9CA3AF 灰色 + 删除线 font-weight: 400, 13px ¥ 前缀 + text-decoration: line-through 全部角色
会员价 #EF4444 红色 font-weight: 600, 16px ¥ 前缀 + "会员"标签 会员、管理员

价格展示布局方案

场景布局说明
商品列表零售价(大) 批发价(小蓝) 成本价(小灰)三行并排或纵向排列，根据角色权限显示对应行
商品详情零售价(大) + 划线价(小灰) / 批发价(蓝标签) / 成本价(灰标签)价格区域用浅灰背景区分，标签用 22px 圆角小标签
销售开单根据客户类型自动切换价格类型零售客户显示零售价，批发客户显示批发价，不可手动切换
采购管理成本价为主要显示，批发/零售价为参考成本价字体加粗，批发/零售价用灰色小字辅助显示
数据报表金额列根据角色过滤，无权限列显示"***"管理员可见全部，普通用户仅见自己有权限的价格
