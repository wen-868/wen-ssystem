1. 页面总览

本规范是设计系统 v3.0 的营销场景补充，定义了促销活动相关的专属色系、倒计时组件、动效规范、标签和状态徽章。所有规范需与现有设计系统（文档 01-13）配合使用，确保营销场景下的视觉一致性。

适用范围：商户端营销中心、优惠券页面、限时折扣、积分商城、活动工作台等所有营销相关页面。

8. 验收标准

  • 7 个促销色系变量全部定义在 :root 中，与基础语义色共存不冲突
  • 颜色色块展示包含颜色名称、CSS 变量名、HEX 值、用途说明
  • CSS 变量定义代码块可直接复制到项目中使用
  • Tailwind 扩展配置代码块包含 colors 和 animation/keyframes 完整定义
  • 倒计时组件支持三种尺寸：大(24px)、中(20px)、小(16px)
  • 倒计时使用深色背景卡片 rgba(0,0,0,0.75) + 白色数字 + 标签
  • 倒计时颜色变化规则覆盖 >1小时、<1小时、<10分钟 三种场景
  • pulse-flash 动画关键帧正确实现 scale(1) → scale(1.05) → scale(1)
  • 按钮波纹效果从点击中心扩散，300ms ease-out
  • 商品卡片 hover 上浮 translateY(-4px) + 阴影加深，200ms
  • 库存进度条使用 linear 过渡，飘落粒子使用 float-up 动画
  • 4 种促销标签样式与实际渲染效果一致
  • "限时"标签：红色背景 #FF4757 + 白色文字 + CSS 三角形闪电图标
  • "满赠"标签：橙色背景 #FF6348 + 白色文字 + CSS 方块礼物图标
  • "秒杀"标签：红色渐变背景 + 脉冲动画
  • "已领完"标签：灰色背景 #B2BEC3
  • 5 种活动状态徽章：DRAFT/ACTIVE/PAUSED/ENDED/EXPIRED
  • ACTIVE 徽章包含绿色呼吸灯动画
  • ENDED 和 EXPIRED 徽章包含删除线效果
  • 与现有设计规范衔接说明表格清晰展示继承关系
  • 所有代码块使用 .code-block 样式，深色背景 + 等宽字体
