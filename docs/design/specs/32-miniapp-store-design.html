设计规格文档 — 酒类行业 C 端小程序

页面总览

本设计规格文档描述了酒类行业 C 端小程序店铺的完整用户界面设计，涵盖用户从浏览商品到下单购买的全流程。

核心功能模块：

  • 店铺首页：轮播 Banner、分类导航、精选推荐、热销排行榜
  • 商品列表：分类筛选、排序、商品展示
  • 商品详情：多图轮播、规格选择、配送信息、加入购物车
  • 购物车：商品管理、满减提示、结算功能
  • 个人中心：订单管理、地址管理、会员权益（后续扩展）

设计风格：深色主调搭配金色点缀，营造高端酒类品牌质感，突出产品尊贵属性。

字段规范表

以下定义了小程序店铺核心业务模块的数据字段规范。

商品表（product）
字段名 类型 必填 说明
idbigint是商品ID，主键
namevarchar(200)是商品名称
category_idbigint是分类ID
pricedecimal(10,2)是零售价
original_pricedecimal(10,2)否原价
stockint是库存数量
salesint否销量
imagesjson是商品图片列表
descriptiontext否商品详情
specsjson否规格属性列表
statustinyint是状态：0下架 1上架
sort_orderint否排序值
购物车表（cart）
字段名 类型 必填 说明
idbigint是购物车ID，主键
user_idbigint是用户ID
product_idbigint是商品ID
sku_idbigint否SKU ID
spec_textvarchar(200)否规格描述文本
quantityint是数量
pricedecimal(10,2)是加入购物车时的单价
selectedtinyint是是否选中：0否 1是
created_atdatetime是创建时间
updated_atdatetime是更新时间
订单表（order）
字段名 类型 必填 说明
idbigint是订单ID，主键
order_novarchar(32)是订单号，唯一
user_idbigint是用户ID
total_amountdecimal(10,2)是订单总金额
pay_amountdecimal(10,2)是实付金额
freightdecimal(10,2)否运费
discount_amountdecimal(10,2)否优惠金额
statustinyint是订单状态：0待付款 1待接单 2配送中 3已完成 4已取消
pay_statustinyint是支付状态：0未支付 1已支付 2已退款
delivery_typetinyint是配送方式：1配送 2自提
address_infojson是收货地址信息
remarkvarchar(500)否订单备注
created_atdatetime是下单时间
pay_timedatetime否支付时间
finish_timedatetime否完成时间

验收标准清单

以下是小程序店铺上线前必须满足的验收标准，共 14 项检查点。

店铺首页轮播图支持自动轮播和手动滑动切换，轮播指示点正确显示当前位置
分类导航点击可跳转到对应分类的商品列表页，当前分类高亮显示
搜索栏支持输入关键词搜索商品，搜索历史记录功能正常
精选推荐商品瀑布流展示正确，商品卡片显示图片、名称、价格、销量信息完整
热销排行榜正确显示销量前 10 名商品，前三名显示金色/银色/铜色徽章
商品详情页多图轮播正常，支持手势滑动和页码指示
规格选择弹窗可正常弹出和关闭，规格选项点击切换，选中状态金色边框高亮
商品数量加减器功能正常，数量不能小于1，不能超过库存
加入购物车按钮点击后有反馈提示，购物车角标数量实时更新
购物车商品支持单选和全选，合计金额随选中状态实时计算
购物车商品数量可修改，删除商品有确认提示，左滑删除交互流畅
满减提示条正确显示距离满减门槛的差额，满足条件时显示已享受优惠
底部 Tab 导航切换流畅，当前页面对应 Tab 金色高亮显示
空购物车状态显示正确，点击"去逛逛"可跳转到首页
