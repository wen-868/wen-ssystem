## 版本更新机制（电脑端 + 移动端）

总台 saas-admin →「版本发布」页维护各端版本（版本号、最低版本、是否强制、更新说明、下载地址、wgt 包地址），各端启动时自动检查并提示：

| 端 | 检查方式 | 更新动作 |
| --- | --- | --- |
| 工作台/收银台（Web） | 启动时 `GET /api/app/version/admin_web` | 有新版弹通知/弹窗，点击刷新 |
| 移动端 APP | 启动时 `GET /api/app/version/app_mobile` | 有 `.wgt` 热更新包 → 下载安装重启；否则提示去下载新安装包 |
| 移动端 H5 | 启动时同上 | 提示刷新 |
| 本地打印助手（Electron） | 启动后 6 秒检查 `print_agent` 版本 | 弹窗提示 + 一键打开下载地址 |

发布新版本流程：
1. 构建对应端产物（Web 直接部署服务器即更新；APP 打 APK/wgt；打印助手打包 exe 上传）；
2. 总台「版本发布」新增版本记录（版本号递增、填下载/包地址、更新说明、是否强制）；
3. 客户端下次启动自动收到更新提示；强制更新时不可跳过。

## 回滚方案

### 快速回滚
```bash
# 1. 停止当前服务
pm2 delete zhixiang-api

# 2. 恢复数据库 (如有必要)
mysql -u root -p liquor_inventory < /var/backups/mysql/liquor_inventory_YYYYMMDD_HHMMSS.sql

# 3. 回滚代码
git reset --hard HEAD~1

# 4. 重新部署
bash deploy/03-deploy.sh
```

### 数据库备份
- 自动备份: 每天 3 次（02:00 / 10:00 / 18:00，R95-04 增强，缩小事故恢复窗口）
- 备份路径: `/var/backups/mysql/`
- 保留策略: 保留最近 14 天，更早的自动清理（脚本内 `RETENTION_DAYS=14`）
- 备份文件名: `liquor_inventory_YYYYMMDD_HHMMSS.sql.gz`（含时分，同一天多次备份不覆盖）
- 手动备份: `sudo bash deploy/02-mysql-backup.sh`

crontab 示例（部署脚本 `06-onepan-bootstrap.sh` / `07-local-archive-deploy.sh` 自动写入）:

```cron
0 2 * * * /root/liquor-inventory-system/deploy/02-mysql-backup.sh >> /var/log/zhixiang-mysql-backup.log 2>&1
0 10 * * * /root/liquor-inventory-system/deploy/02-mysql-backup.sh >> /var/log/zhixiang-mysql-backup.log 2>&1
0 18 * * * /root/liquor-inventory-system/deploy/02-mysql-backup.sh >> /var/log/zhixiang-mysql-backup.log 2>&1
```

异地备份（可选）: 在 `.env` 中配置 `RSYNC_REMOTE="backup@<主机>:/var/backups/mysql"`（可选 `RSYNC_SSH_KEY` 指定私钥），脚本会在本机备份后自动 rsync 推送；不配置则仅本机备份。

## AI 底座部署与实时推送（2026-08-15 完善）

AI 底座为独立 NestJS 服务（端口 3016，pm2 进程 `zhixiang-ai-base`），由 `deploy/ai-base-deploy.sh` 在 git pull 后自动构建启动（`backend/ai-base` 为 pnpm 工程，服务器 Node 20 需 pnpm@9，脚本已处理降级）。

### 环境变量（backend/ai-base/.env）

- `JWT_SECRET`：必须与 backend/.env 一致（WebSocket 与 SSE 均用 JWT 解析租户）；部署脚本自动同步
- `DEEPSEEK_API_KEY` / `GLM_API_KEY`：LLM 服务商密钥，端到端验收 LLM 项依赖
- `EMBEDDING_MODEL`（如 `nomic-embed-text`）：配置后启动时自动加载 `knowledge/` 预置运营文档（单据编号/库存规则/系统功能/客户类型等级）到默认租户知识库；未配置时 RAG 降级禁用，服务正常启动

### 实时推送通道（WebSocket）

- 端点：`/api/ai/ws?token=<JWT>`，JWT 认证（HS256 + issuer/audience 与后端一致），按租户分组广播
- 巡检推送落库 `t_push_log` 后实时推送给该租户在线前端（admin-web AI 窗口展示卡片/通知）
- nginx 反代必须携带 Upgrade 头；`deploy/ai-base-deploy.sh` 部署时会**自动检查并写入** `/ai-api/` 反代（幂等、nginx -t 校验、备份回滚、自动 reload）；手动配置模板见 `deploy/nginx-production.conf` / `deploy/04-nginx.conf`
- 前端生产地址：admin-web 生产构建默认 `https://admin.onepan.cn/ai-api`（代码内 PROD 兜底，与 nginx 反代一致；工作台与 AI 底座同源承载）
