## 一、目标（**只做"已有门"的端点，机械接线**）

把 `app-mobile/src/config/permission-gates.ts` 的 `ENTRY_GATES` 里 **`status === 'gated'`** 的每一条：

```
{ id, domain, entry, page, endpoints: ['METHOD /api/...'], codes: ['x:y', ...] }
```

⇒ 其 `endpoints` 逐条在后端挂上 `codes`（声明式 `routeConfig` + `requirePermission`，与既有批次同形）。

⚠️ **门与接线必须同源**：码**一律取注册表**，不得自行改码；若你认为某条门码不对 ⇒ **只登记**（在回执报备），该条**跳过不接**。
