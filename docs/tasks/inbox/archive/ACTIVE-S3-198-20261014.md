## 二、本批要求（只做一个域，做透）

1. **选域**：从台账里挑**一个**域（建议：写端点较多但语义单一者，如库存/采购/客户其一；**避开** `platform*` 与营销（平台域已另立单、营销刚在 S3-196 改过））。
2. **先立码后接线**：该域里"无现成权限码"的端点，**先**在权限点目录里立码（沿用既有命名规范 `<moduleCode>:<action>`，**不得**用我卡面示例），再挂 `requirePermission(...)`；容器端点同理。
3. **台账联动**：更新 `rbac-wiring-baseline.json` 与缺口清单，**给守恒数字**（本批接线 N 条 ⇒ 缺口 709→709−N），并给 `guard-rbac-wiring --strict` 的前后退出码与差异。
4. **逐端点反测两侧齐**（至少覆盖该域全部新接线端点）：
   - 缺该权限码的令牌 ⇒ **403**（给原始响应）；
   - 有码的令牌 ⇒ 到达参数校验层（**不是** 401/403）；
   - 临时摘掉其中 1 个端点的 `requirePermission` ⇒ **用例变红**（证明判据有分辨力）。
5. **不得放宽既有鉴权**；`guard-route-auth` / `guard-tenant-status` / `guard-route-prefix` 必须仍 **EXIT=0**。
