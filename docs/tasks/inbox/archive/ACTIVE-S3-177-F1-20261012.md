## 二、根因（已定，不要重新论证）

两份测试的 `rawMount=true` 分支模拟 `auth:"none"` 文件，**不发** `x-csrf-token`；而新挂的 `csrfMiddleware` 先于 `requirePermission` 命中 ⇒ "无权限"用例拿到 `CSRF token 无效或缺失`、"有权角色"用例被 403 打掉。

**禁止**把 `csrfMiddleware` 挪到 `requirePermission` 之后来"让测试变绿"——本项目挂载层契约就是「csrf 先于路由匹配」（`rbac-g0-wiring.test.ts:368` 注释、踩坑[34]），端点的 `csrf → permission` 与之同构。
