## 三、硬性约束（违反即退回）

1. **最小改动**：只改与配置项读写相关的文件；不顺手重构、不动无关页面。
2. **禁模拟数据**：保存/回显全部走真实接口；无数据源 → 空态 + 逐项登记 S3（**不许兜底假值**）。
3. **配置项界面化**：不得写死默认值；未配置按设计稿**置灰阻断 + 提示原因**。
4. **敏感项**：密钥类走脱敏展示 + 二次确认 + **保存前后值快照**（留痕）。
5. **不建表红线**：优先复用现有配置存储（`t_platform_config` / `t_tenant_config` 等）；**若某项必须新建表或新数据模型，立即停下报备**，改走 S3，不许先建再说。
6. **契约先行**：新增/变更接口先更新 `docs/API接口文档.md`（含字段单位、枚举取值表），再动代码。
7. **字段名核对**：本批新增字段一律与后端实际返回逐字段核对（S2-01 已做过一轮 15 页/38 接口/210 字段，本批新增的仍需核）。
8. **文档换行**：改 md/sql 前后核对 `git diff --numstat`，**不许整文件换行重写**（本卡已踩两次）。
