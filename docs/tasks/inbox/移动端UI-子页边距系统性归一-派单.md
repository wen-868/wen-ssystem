## 二、规范化数值（只针对可判定元素）

1. **列表/滚动内容容器左右边距** → 统一 `32rpx`（解决「左右间距」）。仅指页面主内容容器（scroll-view 内容 / 列表外包层），**不含**搜索栏、按钮内 padding。
2. **列表卡片上下间距** → 统一 `20rpx`（解决「上下间距」）；卡片内 padding `24~28rpx`。
3. **列表卡片圆角** → 统一 `16rpx`（解决「卡片排列」）；卡片底色 `#fff` + 阴影 `0 2rpx 10rpx rgba(0,0,0,.03)`。
4. **宫格/双列卡片**（如优惠券、数据工具）：左右间距 `20rpx`、上下间距 `20rpx`、卡片圆角 `16rpx`、卡片等高对齐。
5. **分区标题**（如「会员列表」「统计」）统一：字号 `30rpx`、加粗、上方 `32rpx`、下方 `8rpx`（如需）。
