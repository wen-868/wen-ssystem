### R10-M1 安装 Pinia 状态管理 [P0]

- 优先级：P0
- 预计：0.5 天
- 状态：待开始
- 标准依据：项目统一标准 第十七章（前端状态管理规范）
- 文件：`admin-web/`

**问题：** admin-web 项目未安装 Pinia，标准第十七章要求全局状态统一走 Pinia 管理。当前用户信息、租户配置、权限等散落在 localStorage/sessionStorage 中。

**修复步骤：**
1. `npm install pinia`
2. 新建 `admin-web/src/stores/` 目录
3. 创建 `useAuthStore`（用户信息、token）、`useAppStore`（租户配置、权限）
4. 将 localStorage 读写迁移到 Pinia store

---

### R10-M2 表单行内规则统一为 form-level :rules [P1]

- 优先级：P1
- 预计：1 天
- 状态：待开始
- 标准依据：项目统一标准 第六章 6.2 节（表单校验三件套）
- 文件：`admin-web/src/views/` 13 个文件

**问题：** 2026-07-05 全局审计发现 13 个表单文件使用行内 `:rules`（如 `<el-form-item :rules="[{ required: true }]">`），不一致且难以维护。标准要求统一使用 form-level `:rules="formRules"`。

**修复步骤：**
1. 扫描全部含行内 `:rules` 的 form-item
2. 每个 form 抽取规则到 `const formRules = reactive<FormRules>({...})`
3. `<el-form>` 绑定 `:rules="formRules"`，删除行内 `:rules`
