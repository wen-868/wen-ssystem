### R9-M1 修复 error-handler.ts 错误日志写入 [P0]

- 优先级：P0
- 预计：0.5 天
- 状态：待开始
- 标准依据：项目统一标准 第十三章（错误处理规范）
- 文件：`backend/src/middleware/error-handler.ts`

**问题：** 测试报告发现 `error-handler.ts` 未调用 `insertErrorLog` 和 `reportToLingZhou`。P0 错误发生后，不会写入数据库、不会飞书告警——线上错误完全丢失。

**修复步骤：**
1. 在 error-handler 中调用 `insertErrorLog` 写入错误日志到数据库
2. 对 500 和 2000-2999 范围错误，调用 `reportToLingZhou` 飞书告警
3. 测试验证：触发一个 P0 错误 → 确认数据库有记录 + 飞书有通知

**验收：** 触发错误后数据库有记录，飞书收到通知

### R9-M2 store-terminal 全局错误捕获 [P0]

- 优先级：P0
- 预计：0.5 天
- 状态：待开始
- 标准依据：项目统一标准 第十三章（错误处理规范）
- 文件：`store-terminal/src/main.ts`

**问题：** `store-terminal/src/main.ts` 无全局错误捕获。门店终端错误完全丢失，用户看不到错误提示，开发者也看不到错误日志。

**修复步骤：**
1. 添加 Vue 全局错误处理器 `app.config.errorHandler`
2. 添加 Promise 未捕获异常处理器 `window.addEventListener('unhandledrejection')`
3. 错误信息同时展示给用户（Toast）和上报后端

**验收：** 触发错误后用户看到 Toast 提示，后端收到错误日志
