### R8-M1 对齐后端返回体格式变更

- 优先级：P0
- 预计：1 天
- 状态：待开始
- 标准依据：项目统一标准 第三章（全局返回体）、第六章 6.2 节
- 文件：`admin-web/src/api.ts` + 全部接口调用处

**问题：** 后端 R8-3 将返回字段从 `message` 改为 `msg`，新增 `traceId` 和 `apiCost`。前端必须同步适配，否则所有接口返回数据解析失败。

**修复步骤：**
1. `api.ts` 响应拦截器中，将 `response.data.message` 改为 `response.data.msg`
2. 全局搜索 `admin-web/src/` 下所有 `.message` 引用，改为 `.msg`
3. 错误提示统一使用 `error.response?.data?.msg` 而非 `error.response?.data?.message`
4. 如果需要展示 `traceId`，在错误提示中附带（方便后端排查）
5. 确保 `api.ts` 中 `axios.create({ timeout: 30000 })` 已配置（踩坑 13号）

**验收：** 全局搜索 `admin-web/src/` 下 `.message` 引用归零（除 Element Plus 的 `this.$message` 外），所有接口调用正常

### R8-M2 表单校验三件套全面检查

- 优先级：P0
- 预计：1 天
- 状态：待开始
- 标准依据：项目统一标准 第六章 6.2 节（表单校验规则）
- 文件：`admin-web/src/views/` 全部 .vue 文件

**问题：** 历史上多次出现表单校验不完整的问题（踩坑 12号、14号）。需要逐文件检查。

**修复步骤：**
1. 列出 `admin-web/src/views/` 下所有 `.vue` 文件
2. 逐个检查每个 `<el-form>` 是否同时具备：
   - `ref="xxxFormRef"` — 模板中声明
   - `const xxxFormRef = ref()` — script 中声明
   - `:model="xxxForm"` — 绑定数据对象
   - `:rules="xxxRules"` — 绑定规则对象
   - 每个 `<el-form-item prop="yyy">` — prop 与 model 字段对应
3. 空规则 `FormRules = {}` 和空 model `reactive({})` 必须补全
4. 提交表单时调用 `xxxFormRef.value?.validate()` 校验

**验收：** 每个 `<el-form>` 三件套齐全，`vue-tsc --noEmit` 0 错误
