## 二、五大 TAB 页验收要点

### 1. 首页（pg-home）
- 顶部搜索栏（右侧扫码/日历/通知图标）
- 数据卡：今日营业额（¥+涨幅）、今日订单（单数+涨幅）左右分栏；下方三列：本月营业额 / 本月订单 / **总客户数**
- 快捷入口（开单收银/会员管理等）
- 订单进度（待配送/待取货/待收款/已完成）
- 今日待办（库存预警等）
- 最新订单（客户名/渠道/单号/金额/状态）
- 7 日趋势柱状图
- 底部悬浮胶囊 tabbar（5 项，AI 紫色圆钮居中）

### 2. 商品（pg-products）
- 搜索栏（含扫码图标）
- 左侧分类侧栏 + 右侧商品列表（左右分栏）
- 商品卡：图片/首字母占位、名称、规格、**批 ¥ / 零 ¥ / 库 n** 三项价格、库存；卡高对齐缩略图、卡片间有间距
- 操作卡：建议核价/批量调价/价格异常

### 3. AI 助手（pg-ai-assistant）
- 顶部「AI·实时对话」单行
- 欢迎语 + 4 个快捷入口（今日经营分析/库存异常诊断/利润优化建议/快速开单）
- 底部输入栏（麦克风图标 + 输入框 + 发送纸飞机图标）

### 4. 功能中心（pg-functions）
- 顶部功能中心 + 搜索
- 高频宫格（开单收银/会员管理/进货入库/盘点调拨/收银对账/门店管理/单据打印/更多）
- 数据·工具（经营报表/销售排行/溯源/供应商管理/系统设置）

### 5. 我的（pg-profile）
- 用户卡（头像/姓名/角色/门店/营业中）
- 快捷入口（工作记录/库存预警/对账/单据打印）
- 门店管理（门店信息/员工管理/营业时间）
- 系统（消息推送/客服帮助/AI 设置/关于）
- 退出登录

## 三、功能子页面清单（需逐页对齐）

1. **快速开单**（pg-quick-order）：客户选择（散客）、扫码/手动添加、已选商品(数量±/条码/追溯码)、商品数/优惠/应收、收款/分享
2. **开单空态**（pg-quick-order-blank）：还没有添加商品、去添加商品
3. **订单管理**（pg-orders）：Tabs(全部/待付款/待发货/已完成/退款)、订单卡(单号/商品行/客户·渠道·时间/金额/状态/操作按钮)
4. **库存管理**（pg-inventory）：总SKU数/库存价值/预警商品、入库/出库/盘点、库存预警列表
5. **会员管理**（pg-members）：总会员/本月新增/活跃率、搜索、会员列表(等级/最近消费/累计消费)
6. **消息中心**（pg-messages）：Tabs(全部/订单/库存/系统)、消息列表(标题/时间/摘要/类型)
7. **数据报表**（pg-reports）：今日/本周/本月/本年、营业额/毛利/客单价/复购率、销售趋势、销售排行
8. **打印相关**：蓝牙打印/电脑打印/云打印/打印设置

## 四、验收流程

1. workBuddy 每完成一批改动 → 提交到仓库或交付产物
2. 凌舟构建 H5 → 用浏览器截图对应页面（手机视口）
3. 逐页与 `zxql-ui-preview.html` 原稿对比（结构、间距、色彩、字体、SVG 图标）
4. **达标** → 通过收口；**不达标** → 列出具体差距 → 返回 workBuddy 继续，直至全部通过
