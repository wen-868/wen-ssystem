## 四、同步纪律（防"进度源过期"）

1. **回传必须同批更新本文件对应行**（+ `current-tasks.md` 索引）；只写卡不更新进度源 = 回传不完整。
2. 本文件**连续两批未更新** ⇒ 判定失效，**冻结新派单**直到补齐（把"进度源过期"当成缺陷处理，而不是当成惯例）。
3. 任何"已完成"必须带**可复跑证据**（提交哈希 + run id + 命令/行号）；写"已完成"而无证据 = 未完成。
4. 看板的 S3 表降级为**卡片索引**；进度口径一律以本文件为准。
