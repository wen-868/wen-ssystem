### R8-3 统一返回体：message → msg，补充 traceId/apiCost

- 优先级：P1
- 预计：1 天
- 状态：待开始
- 标准依据：项目统一标准 第三章 3.1/3.2 节
- 文件：`backend/src/shared/response.ts` + 全部 controller

**问题：** 返回体字段名 `message` 与标准 `msg` 不符；缺少 `traceId` 和 `apiCost` 字段；42 个文件共 132 处使用 `message`；711 处直接 `res.json()` 绕过统一返回。

**修复步骤：**
1. `shared/response.ts` 中 `ok()` 和 `fail()` 改造：
   ```typescript
   import { v4 as uuid } from 'uuid';
   
   export function ok<T>(data?: T) {
     return { code: "0", msg: "成功", data, traceId: uuid(), apiCost: 1 };
   }
   
   export function fail(msg: string, code = "400") {
     return { code, msg, traceId: uuid(), apiCost: 1 };
   }
   ```
2. 全局搜索替换：`{ code, message` → `{ code, msg`
3. 所有直接 `res.json({ code: "0", message: ... })` 改为调用 `ok()`
4. 所有 `res.status(404).json({ code: "404", message: ... })` 改为调用 `fail()`
5. 路由文件中直接构造 JSON 的（如 `purchase.route.ts` 的 11 处）改为调用 `fail()`

**验收：** 全局搜索 `{ code, message` 归零，`{ code, msg` 为唯一格式
