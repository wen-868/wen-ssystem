## 一、方法与口径声明（先说清"我能覆盖什么、覆盖不到什么"）

1. **本沙箱的硬限制**（均有原始输出）：node **无法创建任何子进程**（`node -e "spawnSync(process.execPath,['-v'])"` → `EPERM`）⇒ `vitest`/`vite build`/`npm run` 链路上的 esbuild 服务起不来；**无 MySQL、无 docker、无网络**；`gh` token 失效。
2. **因此我把"运行期口径"做成了不依赖子进程的进程内真 HTTP 探测**：一次性在探针进程里 `USE_MOCK_DB=true` 起**真实 `dist/server.js`**（真实 auto-routes 挂载、真实 `requirePlatformAuth`、真实 express 错误处理），再从同一进程用 `http.request` 打真实回环请求。这能覆盖**路由挂载 / 鉴权 / 参数校验（zod→400）**，**不能**覆盖真实 MySQL 的 SQL 语义（collation、列存在性等）——这正是 §三.1 那条生产 500 的类别。
3. **未建 worktree 的偏差与理由**：派单卡 §"执行方须各建独立 worktree"。本沙箱 `.git` 为只读，实测 `git worktree add .c5v/wt-c5-1 08e216f2` → `fatal: could not create directory of '…/.git/worktrees/wt-c5-1': Permission denied`（EXIT=128），**无法建 worktree**。替代做法：`git rev-parse HEAD origin/main` 均为 `018b0ddc…` 且 `git status --porcelain` 仅有未跟踪 `.c5v/` ⇒ **主工作树内容 = C5-2 合并后 = main 内容**；C5-1 的内容另用 `git show 08e216f2`/`git grep 08e216f2` 按 ref 读取（A6 即按 ref 计数）。此偏差已如实登记，请凌舟判定是否可接受。
