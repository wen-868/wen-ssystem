## 五、saas-admin a11y 自动化覆盖缺口结论

当前 E2E 门禁（`e2e/a11y.spec.ts`）**仅覆盖 admin-web**；saas-admin 无任何 axe / color-contrast 扫描。
故本轮 saas-admin 改动**无法被现有门禁证明**——其达标来自脚本化对比度计算（`contrast-check.cjs`）与人工复核，而非 CI 门禁。

**可行性评估（不擅自实现）**：saas-admin 与 admin-web 同为 Vite + Element Plus 前端，可在 `e2e/` 下新增
saas-admin 配方的 Playwright + axe 用例，复用既有 `a11y.spec.ts` 结构；主要成本为把 saas-admin 登录态 / 路由挂载进 axe `run()`。
体量约 **0.5~1 人日**。建议另立任务，待派单确认后实施。
