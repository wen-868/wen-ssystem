## 一、可行性结论（30 分钟勘察，已给结论）

**saas-admin 无法像 admin-web 一样自动化进场到工作台**，根因是登录页带**一次性图形验证码**：

- `saas-admin/src/views/login/PlatformLogin.vue:84-94,145-157`：`GET /platform/auth/captcha`
  下发 SVG 验证码（5 分钟有效、一次性），登录必须填验证码；自动化无法绕过。
- 登录选择器也不同于 admin-web：`请输入邮箱 / 管理员账号` / `登 录`（admin-web 是 `账号`/`密码`/`立即登录`，无验证码）。
- 而 admin-web 的 E2E 用 `admin`/`admin123` 直接登录、无验证码，故能跑 axe。

**结论**：采用 S3-53 裁定降级方案——CI 保留双端矩阵结构，但 saas-admin 这一路当前**只跑
「对比度矩阵门禁」**（纯计算、不依赖浏览器）；浏览器 axe 扫描作为就绪件保留（默认 skip），
待验证码进场脚本就绪后启用。已明写：saas-admin 的 axe 扫描待进场脚本就绪，当前由对比度矩阵兜底。
**没有假装跑通**。
