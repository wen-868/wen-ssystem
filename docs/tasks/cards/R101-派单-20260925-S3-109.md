背景与依据（全部已取证，逐条给来源）：
  1. 缺陷语句：`docs/migrations/151_points_columns_fill.sql:12`

     —— `DECIMAL(6,4)` 的最大值是 **99.9999**，**默认值 100 超出范围 ⇒ 该 ALTER 必然失败**。
  2. 生产日志实证（2026-09-25 最近一次启动）：`[migration] 151_points_columns_fill.sql 失败: Invalid default value for 'redeem_ratio'`（pm2 `zhixiang-api-out.log`）。

     ⇒ 因 `redeem_ratio` 从未建成，它们全部报 `ER_BAD_FIELD_ERROR` 被跳过
