```diff
-        expect(m.msg).not.toMatch(/^[A-Za-z0-9\s.,:;'"()\-]+$/);
+        // eslint no-useless-escape：字符类末尾的 `-` 无需转义（S3-46；语义等价，仅去掉 `\`）
```

## 三、修复②：脚本语法检查前置于所有代码门禁 + `if: always()`

`.github/workflows/ci.yml` 的 `build-and-test` job：

```yaml
      - name: Install dependencies
        run: npm ci --legacy-peer-deps

      # S3-46：本步骤前置于所有代码门禁，并加 if: always()（双重保险）
      - name: Shell script syntax check (deploy/scripts)
        if: always()
        run: bash -n deploy/*.sh scripts/*.sh

      - name: Backend unit tests
        run: npm --workspace backend test

      - name: Backend lint gate (zero error)
        run: npm --workspace backend run lint
```

**为什么两个都做**（凌舟给的是"`if: always()` 或把它前置"，我两个都上）：

| 手段 | 防住什么 |
|---|---|
| **前置** | 防"任何代码门禁（lint / 单测 / 覆盖率）红了把它掩蔽"——它是全 CI 最便宜的检查，理应最先跑 |
| **`if: always()`** | 防"`npm ci` 等前置步骤失败把它掩蔽"——装依赖挂了也照样把脚本语法结论打出来 |

即：**它由"最后一个可能被跳过的检查"变成"第一个几乎不可能被跳过的检查"。**

**验证**：
- `js-yaml` 解析 `ci.yml` 通过；步骤顺序实测 `install=2 < script=3 < lint=5`，`if: always()` 已生效
- 同款命令本地预跑：`bash -n deploy/*.sh scripts/*.sh` → **EXIT 0**（即 CI 上该步骤会绿）
