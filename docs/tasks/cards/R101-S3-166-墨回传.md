## 二、契约与命令对照（为什么等效复跑能代表脚本行为）

等效复跑器（附录 E · `run-set.cjs`）逐条镜像脚本第 4.5 节，映射关系如下（第 3 列为"若上游修好、在服务器跑真脚本时应出现同行输出"）：

| 脚本行为 | 复跑器行为 | 复跑原始输出（摘要） |
| --- | --- | --- |
| `find ... \| LC_ALL=C sort` | `fs.readdirSync(dir).filter(.sql).sort()` | `002 → 011`（字节序 == 数字序） |
| `MYSQL_PWD=... mysql <db> < file`（整文件、`multipleStatements`） | `mysql2.createConnection({database, multipleStatements:true}).query(整文件)` | 同一套 SQL 在同一 MariaDB 上执行 |
| `MIG_RC=$?` + `-ne 0` ⇒ 打印报错 + `→ 失败（EXIT=n）` + `break` | `catch(e)` ⇒ 打印 `ERROR errno (sqlState): sqlMessage` + 同名行 + `break` | 见附录 B.2 / C.1 / C.3 |
| `grep -q '已存在，跳过'` ⇒ `→ 跳过` | `out.includes("已存在，跳过")` ⇒ 同名行 | 见附录 B.1 的 `007 → 跳过` |
| 汇总 + `❌ ... 失败脚本：<名>` + `exit 1` | 同文本 + `EXIT=1` | 见附录 B.2 / C.1 |

**差异（如实登记）**：① 复跑器在本机以 node+mysql2 直连本地 **MariaDB 11.4.5**（生产为 MySQL 8.0）；② 复跑器不发 `--default-character-set=utf8mb4`/`--host` 等 CLI 参数（改由连接参数等值表达）；③ 复跑器**未**执行脚本前半段（git/pnpm/pm2/nginx），只覆盖第 4.5 节。
