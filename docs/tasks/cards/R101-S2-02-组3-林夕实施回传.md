## 四、独立验收发现的问题（未采信子代理自述）

按「worker 自述 ≠ 文件实际」，对子代理产出逐项复核，**抓到 1 个真实缺陷**：

### 4.1 `.default()` 破坏「清空即未配置」语义（已修）

- **事实**：`plans`（Record）与 `packs`（数组）最初带 `.default({})` / `.default([])`。管理员清空配置、PUT 仅含 `version` 的包时，zod parse 自动补出空容器 → `readConfig` 的 `hasOwnProperty` 判定存在 → `_configured` 返回 **true** → **前端不置灰阻断，反显示「已配置」**，误导管理员。
- **子代理为何没发现**：补的「清空」用例注释明写「用 freeGrant（顶层键无默认值）验证」——挑了个本来就没 default 的包来测。**真正有风险的两个包一个没测，14 个用例全绿。测试绕开了问题而非暴露问题。**
- **处置**：去掉两处 `.default()` 改纯 `.optional()`；补 2 个点名针对容器型包的回归用例（PUT 仅含 `version` → 断言落库 `{version:1}` 且 GET `_configured === false`），注释写清坑因防后人加回。
- **连带修正**：我的契约 §2 只写「统一护栏与组2 完全一致」，未把「清空 = 未配置」写成可观测断言，导致实现者按字面理解跑偏 —— 契约已补写实。
