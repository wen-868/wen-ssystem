## 五、待业主决策（阻塞"自助找回"，不阻塞本单）

**真正的自助找回（验证码/邮件链接）需要一条能送达用户的通道**，而生产现在**一条都没有**：

| 通道 | 缺什么 | 需要业主提供 |
|:--|:--|:--|
| 短信 | `sms_access_key` / `sms_secret_key` / `sms_sign_name` / `sms_sdk_app_id` 全空；`sms_verify_enabled=0` | 阿里云/腾讯云短信 AK+SK、**已报备的签名与模板** |
| 邮件 | 生产 `.env` 无 SMTP/EMAIL 键，仓库无邮件发送实现 | 发信域名 + 服务商 API Key（或 SMTP 账号） |

⇒ 通道落地前，本单只能交付**人工找回**（员工→本店管理员、租户管理员→平台管理员）。**通道一并给齐后，再立"自助找回"单。**
