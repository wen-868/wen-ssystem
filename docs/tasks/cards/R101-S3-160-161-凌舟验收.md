## 二、S3-161 四场景（我的装置，走真实 App 流、不伪造密文）

| 场景 | 实读 | 判定 |
|:--|:--|:--|
| **A 首次登录（勾选）** | 「记住我」默认勾选=true；登录体 `{"rememberMe":true,...}`；落盘键 `enc_merchant_saved_account` / `enc_merchant_remember_me` / `enc_merchant_saved_password`；**存储内容不含口令明文** | ✅ |
| **B 重开客户端（token 在）** | 调用序列 **仅 `me`**（登录请求 0 次）；URL `#/pages/home/home` | ✅ 不需要重新登录，且 `init()` 真跑了 |
| **C token 失效后打开** | 清掉 `enc_merchant_token` 后重载 ⇒ 两框实读 `s3161_probe_account` / 口令长度 14（**零手动输入**）；仍停登录页；未自动发登录请求 | ✅ |
| **D 取消勾选登录** | 登录体 `{"rememberMe":false,...}`；`saved_account`/`saved_password` **无残留** | ✅ |

**两组反测（我亲手改坏再复原）**：
1. 拆 `restoreSavedCredentials()` ⇒ **11 passed / 1 failed**，红的正是 C「自动带出」；B 保持绿。
2. 拆 `App.vue` 的 `userStore.init()` ⇒ **11 passed / 1 failed**，红的正是 B「调用 /me」。
两次复原后文件 SHA256 与备份**逐位一致**（`login.vue=CC06C73B3D0F`、`App.vue=BE9CDCB6FBAB`）。

## 六、已知边界与后续
