### ③ 根因实测：本沙箱**禁子进程带管道** ⇒ esbuild 永远起不来（原始输出）

```
$ node -e "const cp=require('child_process');const a=cp.spawnSync(process.execPath,['-e','0'],{stdio:'ignore'});const b=cp.spawnSync(process.execPath,['-e','0']);
console.log('stdio=ignore(无管道) => status='+a.status+' err='+(a.error&&a.error.code));
```
