## 一、业主口径（原文，不得改写）

> **「统一色：白底，黑字，中间色浅灰，加状态色，全局统一」** —— 业主 2026-09-21

**解读（凌舟，若有歧义以业主原话为准）**：

1. **白底**：页面/卡片主背景＝白；浅灰只作分区面，不作品牌色倾向。
2. **黑字**：正文与标题用黑，不用彩色承担"正文可读性"。
3. **中间色浅灰**：中性阶（次要文字 / 边框 / 分隔）统一为**一条浅灰轴**，不允许同一语义在两端各取一个值。
4. **加状态色**：成功/警告/危险/信息保留语义色，但**必须达到文字可读门槛**（这正是 E-3 那 25 条的落点）。
5. **全局统一**：admin-web / saas-admin / app-mobile / website —— **同一语义只能有一个值**。

原则：**优先沿用本项目已被门禁证明过的值**，减少外溢；只在必要时新增。

| 主文字（黑） | `--text-primary` | `#000000` | 标题、正文 | 21.00（白底）；admin-web 现值已是 `#000000` |

## 三、统一性判据（硬，缺一不算完成）

1. **同一语义只有一个值**：admin-web 与 saas-admin 的**同名 token 必须同值**；app-mobile / website 的同语义必须映射到同一值。产出「同语义不同值」清单，**必须归零**。
2. **文字 ≥4.5:1、大文本 ≥3:1、非文本对象（1.4.11）≥3:1**，且**一律以 computed 实测为准**（R8.1：不得用源码声明值或规则先后顺序定论）。
3. **按钮/标签类"底 + 字"组合也要过 4.5:1**（E-3 未覆盖的一类：白字压 primary 底目前**未验证**，属于本卡必须补齐的口子）。
4. **反测**：任取 3 处改回旧值 ⇒ 对比度守卫必须红；还原 ⇒ 复绿。
5. **零非文字误伤**：核对改前/改后引用点，确认 `background` / `border` / `box-shadow` 用途无风格位移；确需位移的逐条列出并由凌舟批准。
