## 二、白名单判定（本单要点一：白名单式，不是"包含 1060 就算过"）

### 2.0 判定代码片段（`deploy/ai-base-deploy.sh:70-89`，逐字）

```bash
# S3-166-F1：迁移"已应用"错误的白名单判定。
#   为什么需要：生产已应用过 004/005（裸 ADD COLUMN）⇒ 重跑必报 1060；若一律硬阻断，
#   本脚本一上线就把 AI 底座发版掐死。故对"已应用/已存在"这一**窄类**错误容忍。
#   白名单只认这四个错误码，且**必须整条输出全部命中**才容忍（白名单式，不是"包含 1060 就算过"）：
#     1060 Duplicate column name ｜ 1061 Duplicate key name
#     1050 Table already exists ｜ 1091 Can't DROP ...; check that column/key exists
#   任一非白名单内容（1064 语法错、1146 表不存在、2002 连不上、其他任何码/关键字/告警行）
#   ⇒ 判定失败（fail-closed），由调用方走硬阻断。
ai_mig_error_all_tolerated() {  # $1 = mysql 的错误输出；返回值 0 = 全部属"已应用"
  local out="$1"
  [ -n "${out}" ] || return 1
  local rest
  # 1) 剔除全部白名单错误行（格式：`ERROR 1060 (42S21) at line 3: ...`）后，必须不剩任何非空行
  rest="$(printf '%s\n' "${out}" \
    | grep -vE '^[[:space:]]*ERROR[[:space:]]+(1060|1061|1050|1091)([[:space:]]|\(|:|$)' \
    | grep -vE '^[[:space:]]*$')"
  [ -z "${rest}" ] || return 1
  # 2) 且必须至少命中一条白名单错误（空输出/纯噪声不算"已应用"）
  printf '%s\n' "${out}" | grep -qE '^[[:space:]]*ERROR[[:space:]]+(1060|1061|1050|1091)([[:space:]]|\(|:|$)'
}
```

## 五、就绪探针闸门（本单要点二 / 验收 4）

### 5.1 实现（`deploy/ai-base-deploy.sh:390-422`）

```bash
# ---- 6.1 就绪探针：终态闸门（S3-166-F1） ----
# 为什么单列一条：/api/health 只证明**进程活着**；迁移步骤容忍了"已应用"类错误（1060 等）之后，
#   必须有终态判据，否则"容忍"会退化成"把结构缺失一起放过"。就绪探针（缺表/缺列 ⇒ degraded）
#   就是那个判据——容忍是手段，探针才是"结构真的跟上了"的裁判。
# 失败出口：沿用 ai_migration_fail（同一条 ❌ 标记 + 非 0 退出），点名"探针未就绪"并打印响应摘要。
# 口径说明：只有进程健康检查通过时才探（进程都没起来属第 6 步已有的软失败口径，不重复升级为硬阻断）。
if [ "${READY}" != "1" ]; then
  echo "==> [AI底座] 就绪探针跳过：健康检查未通过（同上软失败口径，收尾统一出标记）"
else
  AI_HEALTH_READY_URL="http://127.0.0.1:${AI_PORT}/api/health/ready"
  echo "==> [AI底座] 就绪探针 ${AI_HEALTH_READY_URL}"
  AI_READY_OK=0
  AI_READY_STATUS=""
  AI_READY_BODY=""
  AI_READY_NOTE=""
  for i in {1..15}; do
    AI_READY_NOTE=""
    # 不加 -f：非 2xx（如 503 + degraded JSON）也要把响应体读回来做摘要
    AI_READY_BODY="$(curl -sS --max-time 5 "${AI_HEALTH_READY_URL}" 2>&1)" || AI_READY_NOTE="curl 退出码非 0（服务不可达/连接被拒）"
    AI_READY_STATUS="$(printf '%s' "${AI_READY_BODY}" \
      | grep -o '"status"[[:space:]]*:[[:space:]]*"[^"]*"' | head -1 \
      | sed -e 's/.*:[[:space:]]*"\([^"]*\)"$/\1/')"
    if [ "${AI_READY_STATUS}" = "ready" ]; then
      AI_READY_OK=1
      echo "==> [AI底座] 就绪探针通过（status=ready，第 ${i} 次）"
      break
    fi
    sleep 2
  done
  if [ "${AI_READY_OK}" != "1" ]; then
    ai_migration_fail "探针未就绪：${AI_HEALTH_READY_URL} 未返回 status=ready（实际 status='${AI_READY_STATUS:-<空>}'${AI_READY_NOTE:+；${AI_READY_NOTE}}；响应摘要：$(printf '%s' "${AI_READY_BODY}" | tr -d '\n' | head -c 300)）"
  fi
fi
```

### 8.1 为什么是"等效"而非"真跑"

本沙箱无 POSIX shell、无数据库（§6.1），故用**规则抽取式夹具**：白名单正则、错误码、探针 JSON 解析正则、日志模板**全部从 `deploy/ai-base-deploy.sh` 原文抽取**（脚本改一处、夹具跟着变），夹具只补"控制流 + 假引擎"。**它证明的是判定规则的分辨力，不替代 `bash -n` 与真跑**（§6.2/§6.3）。

### 8.2 精简复跑脚本（保存为 `repro.py`，在仓库根目录执行 `python repro.py`）

```python
# -*- coding: utf-8 -*-
"""S3-166-F1 复跑夹具（精简版）：判定规则从 deploy/ai-base-deploy.sh 抽取，不硬编码。"""
import re, sys
SCRIPT = "deploy/ai-base-deploy.sh"
SRC = open(SCRIPT, encoding="utf-8").read()
BODY = re.search(r"^ai_mig_error_all_tolerated\(\)\s*\{(.*?)^\}", SRC, re.S | re.M).group(1)
LINE_RE, HAS_RE = [p.replace("[[:space:]]", r"\s") for p in re.findall(r"'([^']*ERROR[^']*)'", BODY)]
CODES = sorted(set(re.findall(r"\d{4}", LINE_RE)))

def tolerated(out):
    if not out: return False
    rest = [l for l in out.split("\n") if l.strip() and not re.match(LINE_RE, l)]
    return not rest and any(re.match(HAS_RE, l) for l in out.split("\n"))

TOK = re.search(r"""grep -o '("status"[^']*)'""", SRC).group(1).replace("[[:space:]]", r"\s")
SED = re.search(r"""sed -e 's/(\.\*:[^']*)'""", SRC).group(1).split("/")[0] \
      .replace("[[:space:]]", r"\s").replace(r"\(", "(").replace(r"\)", ")")
def probe_status(body):
    hits = re.findall(TOK, body)
    return re.match(SED, hits[0]).group(1) if hits and re.match(SED, hits[0]) else ""

MIGS = ["002_mcp_token.sql","003_ai_db_evolution.sql","004_platform_ai_config_fallback.sql",
        "005_session_archive_billing.sql","006_ai_execution_plan.sql","007_e5_auto_close.sql",
        "008_digital_employee.sql","009_audit_lane_categories.sql","010_rating_and_triage.sql",
        "011_employee_task_tenant.sql"]

def migrate(files, engine):   # 镜像第 4.5 节控制流
    total = ok = skip = already = 0; names = []; failed = ""; code = 0
    for name in sorted(files):
        total += 1; rc, out = engine.get(name, (0, ""))
        if rc != 0:
            if tolerated(out):
                errnos = ",".join(sorted(set(re.findall(r"\d{4}", "\n".join(
                    re.findall(r"^\s*ERROR\s+\d{4}", out, re.M))))))
                print(out); print("==> [AI底座][迁移] %s → 容忍（已应用：错误码 %s）" % (name, errnos))
                already += 1; names.append(name); continue
            print(out); print("==> [AI底座][迁移] %s → 失败（EXIT=%d）" % (name, rc))
            failed = "%s(EXIT=%d)" % (name, rc); code = 1; break
        if "已存在，跳过" in out:
            print("==> [AI底座][迁移] %s → 跳过（EXIT=0，幂等：已存在，跳过）" % name); skip += 1
        else:
            print("==> [AI底座][迁移] %s → 成功（EXIT=0）" % name); ok += 1
    print("==> [AI底座][迁移] 结果汇总：尝试 %d 个 / 成功 %d / 跳过 %d / 容忍（已应用） %d / 失败 %d"
          % (total, ok, skip, already, 1 if failed else 0))
    if already: print("==> [AI底座][迁移] 容忍（已应用）= %d 个：%s" % (already, ", ".join(names)))
    if failed: print("❌ [AI底座] 部署失败：数据库迁移失败…失败脚本：%s" % failed)
    print("EXIT=%d" % code); return code
```
