3. **A 族用的是类型断言 `as <实体类型>`，不是"补泛型"**：Element Plus 2.7 的 `ElTable` 无可用泛型实例化路径；另两条路（放宽处理函数形参为 `Record<string, any>`、改表格声明）会把实体类型退化成 `any` 或扩大改动面。该写法本仓已有先例（`TenantAiConfig.vue:44/53`、`TemplateCenter.vue:839/840`）且当前 0 错误。**这是"断言"而非"零风险"**：若某行数据实际结构不符实体类型，断言不会报错、运行期仍会炸——本单只清类型门禁，不改变该风险的存在与否。
4. **B 族我刻意没用 `String(route.params.id)`**：`String()` 会把缺失参数由 `undefined` 变成 `"undefined"`，从而改变 `if (!tenantId) return` 的判定语义（行为变更）。故用 `.as string` 纯编译期断言。若凌舟要求统一用 `String()`，请明示（会带来上述语义变化）。
