## 一、改动内容（`e2e/a11y.spec.ts`，唯一改动文件）

新增 `waitForVisualSettled(page)`，在两个 `@a11y` 用例的 `analyze()` **之前**调用，顺序严格为三步：

1. `page.waitForFunction`：等 `document.getAnimations()` 中没有 `playState === 'running'` 的项；
   `getAnimations` 不存在或抛错时**兜底放行**（不等），超时亦放行。
2. `page.addStyleTag` 注入 `*,*::before,*::after{transition:none!important;animation:none!important}`，
   掐断一切过渡/动画的中间帧。
3. 再等两帧（`requestAnimationFrame`），确保样式落地、布局稳定。

新增 `logAccentContrast(page)`：每次取样打印 `[a11y-accent]` 行 —— `.metric-num--accent` 的
`tagName` / 计算色 / 向上第一个不透明祖先的 `backgroundColor` / 由这两值算出的比值；
取不到元素时如实打印「未取到该元素 + 原因」（登录页即为此情况）。

**断言与阈值**：`expect(criticalSerious.length).toBe(0)` 与 `wcag2a/wcag2aa/wcag21a/wcag21aa`
四个 tag 一字未改；未给用例加 `test.retry` / `skip` / `fixme`。

**未改**：`.github/workflows/e2e.yml`（观察期取样次数 3→10 由凌舟在门禁侧统一处理，避免与 A-2/A-4 抢文件）。
