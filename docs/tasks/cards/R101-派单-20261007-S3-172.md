# 派单 · S3-172（P0）：演示登录**不受账号锁定限制** ＋ 平台超管**代重置租户账号口令**

- 派单人：凌舟（总负责人）｜2026-10-07
- 执行人：阿坚（后端）
- 触发：业主指令「演示登陆要解除帐号锁定不要限制」「忘记密码怎么找回？这些都要紧急完善」
- 单号：S3-172

---

## 〇、现状（凌舟已实测，勿再重复求证）

| 事实 | 证据 |
|:--|:--|
| 生产演示口令可用 | `POST /api/admin/auth/login {"username":"demo","password":"Demo@2026"}` ⇒ **200**（服务器本机发，1 次，未污染 fail_count） |
| 演示账号**会被锁定** | `auth.service.login()` 对 `locked_until > now` 一律 `AppError("账号已锁定…", 400)`，**不区分是否演示账号** |
| 失败计数**对演示账号也累加** | 同函数：口令错 ⇒ `login_fail_count+1`，达 `MAX_LOGIN_ATTEMPTS` 就写 `locked_until` |
| 限流**对演示账号也生效** | `login-fail-limiter` 的账号维度键含演示账号 ⇒ 被爆破后演示端会吃 429 |
| 「锁定降级免密」在生产是**死的** | S3-165 已禁生产免密（403）⇒ C6-9 / S3-159 承诺的降级路径在生产必然失败 |
| 免密**必须保持禁用** | 演示账号与真实账号 `admin`/`store_manager` **同在 `default` 租户**，免密 = 直接发 `SUPER_ADMIN` token ⇒ 等于开正门 |
| 平台侧**不能**重置租户账号 | 现仅有 `POST /api/platform/admins/:id/reset-password`（重置**平台**管理员）；**租户**超管忘了口令只能运维上服务器手工重置 |

## 一、交付物（4 项）

| # | 文件 | 要求 |
|:--:|:--|:--|
| ① | `backend/src/services/admin/auth.service.ts` | `login()` 对 `username === DEMO_USERNAME`：**跳过 `locked_until` 阻断**；口令错时**不累加** `login_fail_count`、**不写** `locked_until`。理由：演示口令是**公开值**，锁它只会毁演示，没有安全收益。**其它账号行为一字不改。** |
| ② | `backend/src/middleware/login-fail-limiter.ts` | 账号维度（含 `accountKey` / `accountIpKey` / 兜底）对**演示账号豁免计数**；**IP 维度保持不变**（防单机滥用）。导出常量/函数以便单测断言"演示账号被豁免"这件事本身。 |
| ③ | 平台端**代重置租户账号口令**（新端点） | 建议 `POST /api/platform/tenants/:tenantId/users/:userId/reset-password`：平台超管可为**指定租户**的管理员/员工重置口令，返回**一次性初始口令**，并写审计日志（谁、何时、重置了哪个租户的哪个账号）。**必须校验 `userId` 确属 `tenantId`**（防跨租户重置）。走 `requirePlatformAuth` + CSRF。 |
| ④ | 回传卡 `docs/tasks/cards/R101-S3-172-阿坚回传.md` | 格式见 §四。 |

## 三、验收标准（硬）

| # | 标准 | 判据 |
|:--:|:--|:--|
| ① | **演示账号锁定免疫** | 把 `demo` 的 `locked_until` 置为未来时间 ⇒ `login()` 仍签发 token；连错 10 次口令 ⇒ `login_fail_count` 仍为 0、`locked_until` 仍为 NULL |
| ② | **限流豁免** | 反复失败后演示账号仍可登录（不 429）；**对照**：同一批失败下**非演示账号**照旧被锁/被限流（证明豁免是定向的，不是整体放宽） |
| ③ | **平台代重置** | 平台超管为租户账号重置 ⇒ 返回一次性口令、该账号可用新口令登录、**旧口令失效**；跨租户 `userId` ⇒ 400/404（不许重置） |
| ④ | 反测两侧齐 | 把①②的豁免改回原样 ⇒ 对应断言**该红就红**；复原 ⇒ 绿（给原始输出） |
| ⑤ | 门禁 | `npx tsc -p tsconfig.json --noEmit` EXIT=0；`npx vitest run` **全量**（本沙箱跑不了如实报备，凌舟本机补） |
| ⑥ | 不回归 | 其它账号的登录/锁定/限流断言**一条不减少** |
