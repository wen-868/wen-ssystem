## 三、立项卡口径（供阶段二/三排期时直接引用）

- **优先级建议**：① 数据重置 = 高风险低频率（P2，需审批链）；② 异步加密导出 = 有明确合规诉求时再做（P2）；③ 批量操作 = 纯效率（P3）。
- **共同前置**：新表必须先过 DDL 草案评审（参照 `R101-C6-凌舟裁定（前置政策）.md`）；异步任务必须可取消、可查询、有超时与清理。
- **共同红线**：任何"重置/导出"都必须留**审计记录**（谁、何时、对哪个租户、范围），并不得绕过租户隔离。
- **不做的代价（已写明）**：三个入口长期停留在"本期不提供"，属**有意识的取舍**而非遗漏 —— 若业务确有需求，按本卡开工即可。
