### E（第 32 项）#289-E `wechat.routes.ts` 的 CSRF「假安全」 —— **已修（按已裁定方案 A）**

- 根因链（原始形态）：`requireWxAuth` 只设 `req.wxUser`（`middleware/wechat-auth.ts:9-23` 旧码）→ `csrfMiddleware` 在 `!req.user` 时直接 `return next()`（`middleware/csrf.ts:39-42`）⇒ 直接挂 CSRF 等于没挂。
- 落地：`requireWxAuth` 通过后设 `req.user`（最小形状：`id`=微信用户 id、`roles: []`、`storeId: null`、`tenantId`）+ `req.tenantId`（#8）；4 个写端点挂 `csrfMiddleware` 且认证在前（#9）；登录响应下发 `csrfToken`（#10）——否则客户端无从获得令牌，老端写端点会从"能调通"退化成 403（属**功能性回退**，故必须同批补）；老端 `miniapp/app.js` 自动带 `x-csrf-token`（#13/#14）。
- 运行期证据（`probe-after.txt`）：

```
[after] POST /api/miniapp/wechat/auth/unbind  (微信令牌，无 x-csrf-token)          -> 403  {"code":"403","msg":"CSRF token 无效或缺失"}
[after] POST /api/miniapp/wechat/auth/unbind  (微信令牌 + x-csrf-token=HMAC(33))   -> 200  {"code":"0","msg":"成功","data":{"message":"解绑成功"}}
```
- 租户口径（如实说明）：微信令牌本身不带租户，故 `req.tenantId` 取值顺序为「令牌内 `tenantId` → 请求头 `X-Tenant-Id`（多端既有约定，`app-mobile/src/api/request.ts:78`）」，**两者都没有时不伪造**（保持未设置）。这意味着 `bind`（`wechat.controller.ts` 读 `req.tenantId`）在老客户端"不带租户头"时仍会按既有口径失败 —— 本单**没有**发明新的租户来源，属需凌舟裁定的后续项（见 §七.3）。

裁定四问：

**① `/api/store` 前缀级覆盖只消除 1/20 ⇒ 另立单（总清单第 51 项）。**
范围：以**根前缀** `/api/store` 注册的其余 9 个文件，逐个收窄为「自己拥有的路径段」；判据 = 每个文件收窄**前后**的对照：`GET /api/store/no-such-path`（401 → 404）＋「被前缀压死的端点」逐条行为对照。
**不在本单顺手做** —— 一次触碰 9 个文件会失去可核对的对照面。
同批要求：在 `shared/auto-routes.ts` 增加「根前缀被多文件共享」的**告警**（只出声、不判红），把这类隐患从"靠人记得"变成"启动即报"。

**② A 的跨租户字面反例 ⇒ 要真库夹具（并入第 51 项）。**
理由：等价分支（服务层 SQL 带 `tenant_id`、取不到行 ⇒ 404）与真库夹具的差别**正是**「是否可能命中他人行」——归属类缺陷必须打到真库。用 S3-183-F1 的副本库，避开与其他单抢库。

**③ 老 miniapp 登录态载体 ⇒ 不换 JWT，建「消费者身份适配层」（总清单第 52 项）。**
理由：老端是微信原生客户端，手上只有微信令牌；让它去换商家 JWT 需要消费者持有商家账号，产品上不成立。
裁定：新增 `requireConsumerAuth`（接受微信令牌 ⇒ 解析出绑定的消费者身份 ⇒ 注入 `req.user`，`roles` 不含商家角色），使 `/api/miniapp/marketing/*` 的「我的」与写端点对**消费者身份**可用。判据 = 老端三处调用由 401 ⇒ 200 / 业务码。**本单不阻塞**。

**④ 微信 `bind` 的租户来源口径（令牌 → `X-Tenant-Id` → 不伪造）⇒ 认可。**
追加硬要求（并入第 52 项）：两者都缺时 `bind` 必须**显式失败且不落库**，并有用例锁死 —— 禁止「空租户静默写」。

**本轮由本单新登记（均已写入总清单）**：第 51 项（`/api/store` 前缀统一治理 + 跨租户真库夹具 + `auto-routes` 根前缀告警）、第 52 项（消费者身份适配层 + `bind` 无租户显式失败）。
