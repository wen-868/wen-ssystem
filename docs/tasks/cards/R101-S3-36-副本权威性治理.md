## 四、机械判定规则（写进流程，不靠人记）

动手改任何服务代码前，**三条全部为真**才允许动手：

1. `ls -a <目录>` 里**有 `.git`** —— 没有 `.git` 的一律视为**副本**，不得改。
2. `git -C <目录> remote -v` 的 origin **等于** `docs/部署链路对照表.md` 中该服务登记的权威仓库。
3. 生产检出目录（如 `/opt/zhixiang/ai-base`）的 `git remote -v` 与第 2 条**一致**。

任一条不满足 → **先更新对照表或提出异议，再动手**。

> 判定"部署自哪个仓库"**看生产检出的 `git remote -v`**，不看目录名、不看代码像不像。
