# R101-S3-72 品牌蓝统一加深（E-3「A 案」专项）立项卡

- **立卡人**：凌舟（总负责人）｜2026-09-21
- **归口**：墨（admin-web）｜**视觉基准**：林夕（UI/UX）｜**验收**：凌舟
- **来源**：派单 E-3 产出 `docs/tasks/cards/R101-E3-墨-S366.1用途分类.md` §3「品牌蓝两案」；凌舟裁定 **B 案先行（已由 H-1 落地）、A 案另立本卡**。
- **本卡写的是什么**：把 A 案从"一个可以顺手做的改动"降级为"需要业主确认的风格位移级变更"——**先定性，不动手**。

## 一、问题

`--color-primary` 现值用在**文字**上不达 WCAG 4.5:1（最严面 3.52:1）。E-3 给出两条路：

| 案 | 做法 | 处置 |
|---|---|---|
| **A** | 统一加深 `tokens.css:15` + `styles.css:26`（token 级） | **本卡**（另立专项） |
| **B** | 逐处最小改动：9 文件 / 11 条规则 | 已由 **H-1** 落地；代价是同色两值并存 |

## 二、A 案影响面（E-3 实测数字，非估算）

| 项 | 数字 |
|---|---|
| 触及文件 | **72** |
| `var(--color-primary)` 引用点 | **278** |
| 其中**非文字用途** | **153（69%）** = background 68 / border 51 / box-shadow 4 / EP 变量映射 11 / 其他 19 |

⇒ 属**风格位移级**变更：按钮底、边框、tag、分页 hover 会**一起变**。

## 三、凌舟裁定：本卡为什么不能"顺手做掉"

1. **归因困难**：与 S3-54 / S3-63 / S3-67 同期改动叠加后，出问题无法回答"这个颜色是哪一笔改的、改前是什么"。
2. **必须先分诊**：153 处非文字用途里，有的是 1.4.11 非文本对象（≥3:1）、有的是纯装饰（无阈值）、有的是背景（不适用）。**不分诊就改 = 会出现"为过门禁把背景灰也改深"的误伤**。
3. **品牌色不是可达性补丁**：它是业主可感知的视觉资产，改动需林夕的视觉基准 + 业主看板确认，**属必须决策项**。

## 五、验收标准（硬）

1. 全站 computed 复核：文字用途 ≥ 4.5:1、非文本对象 ≥ 3:1（**只认 computed，不认源码声明值** —— R8.1）
2. 非文字用途逐项对照表（改前 / 改后 computed），确认无误伤
3. 反测：把 `--color-primary` 改回旧值 ⇒ 对比度守卫必须红
4. 业主确认记录（截图或文字）落卡

## 六、红线

- **不得在无业主确认的情况下变更品牌主色**
- 不得与 S3-54 / S3-63 / S3-67 未合并的改动同批落地
- 不得为过门禁而改动背景 / 装饰类用途
- 不得把 A 案与 H-1 的 B 案值混用（避免同色三值）
