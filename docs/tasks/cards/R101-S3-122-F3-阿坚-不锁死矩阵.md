> 用途：在合并 S3-122-F2 的 32 处 `requirePermission` 接线**之前**，证明"接线不会把前端本来允许的角色锁死"，并据此产出补齐 SQL（交付物②：`docs/ops/S3-122-role-permission-align.sql`）。

**结论先行**

1. F2 的 32 处接线实际是 **9 个 permCode**（派单卡写"15 个"；根因是卡面命令未加 `--no-filename`，见 §〇）。
2. 9 个 permCode 中 **2 个会锁死前端本来允许的角色**：`sale:return`（锁 `STORE_OPERATOR`）、`finance:payment`（锁 `STORE_MANAGER`、`STORE_OPERATOR`）⇒ 已进入补齐清单（交付物② 2.1–2.3）。

4. 前端门禁里的 `CASHIER`（`:258/:263/:269`）在源码种子中**没有任何角色行**⇒ 无法用 SQL 补齐，属"角色缺失"，登记待核。
5. `inventory:adjust` / `inventory:create` / `inventory:approve` / `purchase:create` / `finance:create` 无缺口（现有角色已覆盖前端要求）。

function Match-Perm { param([string[]]$perms,[string]$code)
  if($perms -contains '*'){return $true}
  $di=$code.IndexOf(':'); if($di -gt 0 -and ($perms -contains ($code.Substring(0,$di)+':*'))){return $true}
  $ai=$code.LastIndexOf(':'); if($ai -gt -1 -and $ai -lt $code.Length-1 -and ($perms -contains ('*:'+$code.Substring($ai+1)))){return $true}
  return ($perms -contains $code) }
$codes=@('goods:price','inventory:adjust','inventory:create','inventory:approve','sale:create','sale:return','purchase:create','finance:payment','finance:create')
foreach($c in $codes){ $cells=@(); foreach($r in $roles.Keys){ $cells += $(if(Match-Perm $roles[$r] $c){'OK'}else{'--'}) }
  Write-Output ("{0,-17} | {1}" -f $c, ($cells -join ' | ')) }
