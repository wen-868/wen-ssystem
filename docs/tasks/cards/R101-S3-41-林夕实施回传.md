`vue@3.5.42` 的来源。**仅对齐声明（约束①）后，`npm ci` 立即由 EUSAGE 变为通过**
（`added 2982 packages`），无需先动 lock。即：**EUSAGE 的充分原因就是这条声明冲突**。

## 四、**未纳入提交**的内容及理由（按约束⑤判为噪声）

`npm install --package-lock-only` 全量重算会额外剥掉 **83 行 `libc` 字段**
（`"libc": ["glibc"]` / `["musl"]` / `"libc": "glibc"`，分布于 `@esbuild/*` 等平台包）。

- 定性：**npm 版本元数据差异**（committed lock 由 npm 11 写出、含 `libc`；npm 10 不写），
  **非依赖图变化** → 按约束⑤不入库。
- **等价性证明（强证据）**：把"本卡的最小改动版 lock"与"npm 10 全量重算版 lock"**逐行 diff**，
  差异**仅这 83 行 `libc`**，**非 `libc` 差异 = 0**。即：最小改动版 ≡ npm 10 规范输出 − 纯元数据漂移。
- 若凌舟希望入库 npm 10 版（含剥掉 `libc`），属**另一决定**，一条命令即可追加；本卡按约束⑤口径处理。
