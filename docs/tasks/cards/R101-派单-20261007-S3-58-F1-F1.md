## 〇、一行摘要

S3-58-F1 的 R3 平台 MFA 声称"零 DDL"，但生产 `t_platform_admin` **没有** `mfa_secret` / `mfa_enabled` 列 ⇒ 上线会让**平台控制台全员登录 500**。本单补齐迁移 + 把迁移接进部署流水线 + 加缺列防御，并给两侧反测。

## 一、判红事实（不是推断，可复跑）

| # | 手段 | 结果 |
|:--:|:--|:--|
| 1 | 生产只读 `SHOW COLUMNS FROM t_platform_admin` | 列 = id / username / password_hash / real_name / email / phone / role / status / last_login_at / created_by / created_at / updated_at —— **无 `mfa_enabled`、无 `mfa_secret`** |
| 2 | 生产只读执行 `platform-auth.service.ts:52` 的 SELECT 原文 | ``ERROR 1054 (42S22): Unknown column 'mfa_enabled' in 'field list'`` |

**为什么测试全绿**：mock 层（`backend/src/__tests__/mocks/mock-db-system.ts:192-198`）按 SQL 片段返回内存行，`mfa_enabled` 取到 `undefined` ⇒ `Number(undefined)===1` 为 false ⇒ 走"默认不强制"分支 ⇒ 永远绿。**mock 不校验列是否存在。**
