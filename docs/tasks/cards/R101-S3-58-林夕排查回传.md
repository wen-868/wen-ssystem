## 2. 证据二：`vite.config.ts` 的 proxy 行（临时代理未还原 + 关闭 TLS 校验）

### `admin-web/vite.config.ts:34-43`（问题项）

```ts
server: {
  port: 5173,
  // 本地预览临时代理：对接线上 API（验证后还原）
  proxy: {
    "/api": {
      target: "https://api.onepan.cn",
      changeOrigin: true,
      secure: false
    }
  }
},
```

三个独立问题：

1. **`target` 指向外部域名 `api.onepan.cn`** —— `/api` 全量转发到仓外第三方域名。
2. **`secure: false`** —— 关闭 TLS 证书校验，该链路存在中间人风险。
3. **注释自述「本地预览临时代理…（验证后还原）」—— 说明它本就是临时配置，但一直没还原。**

### 对照：`saas-admin/vite.config.ts:12-16`（正常）

```ts
server: {
  port: 5174,
  proxy: {
    target: "http://localhost:8080",
```

指向本机后端，无外泄。
