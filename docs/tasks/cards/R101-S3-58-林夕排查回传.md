## 3. 证据三：`vite.config.ts` proxy（登记为**配置变更**，不改）

### `admin-web/vite.config.ts:34-43`

```ts
server: {
  port: 5173,
  // 本地预览临时代理：对接线上 API（验证后还原）
  proxy: {
    "/api": {
      target: "https://api.onepan.cn",
      changeOrigin: true,
      secure: false
    }
  }
},
```

三个独立问题：

1. `target` 指向**外部域名** `api.onepan.cn` —— `/api` 全量转发到仓外第三方。
2. **`secure: false`** —— 关闭 TLS 证书校验，该链路存在中间人风险。
3. 注释自述「本地预览临时代理…（验证后还原）」—— **临时配置未还原**。

### 对照：`saas-admin/vite.config.ts:12-16`（正常）

```ts
server: { port: 5174, proxy: { target: "http://localhost:8080", ... } }
```

🔴 本项**登记为配置变更，由业主裁定后再动**（会影响 admin-web 本地预览与可能的线上构建）。
另见 S3-59 缺陷一：这条 proxy 同时导致 **CI 的 a11y 测试打的是生产 API**，是"红点漂移"的根因。

## 5. 措辞纪律（本卡的自我约束）

| ❌ 不这么写 | ✅ 这么写 | 原因 |
|---|---|---|
| 「外网 IP 已成功登录」 | 「公网可达 + 凭据有效 + 返回真实数据；**未授权访问证据为零**」 | 501 次请求中 referer 非本地的为 0 次 |
| 「日志证明存在未授权访问」 | 「暴露面成立，但未发现未授权访问证据」 | 拿不出证据就不能写成事实 |

**紧急度与对外口径**：暴露面是客观事实（弱口令 + 公网可达 + 真实库），该修；
但对外表述只能是"存在暴露风险"，**不能是"已发生未授权访问"**。
