# 派单 · S3-174（P0 安全）：把演示账号**迁出真实租户**——公网演示不得看到真实业务数据

- 派单人：凌舟（总负责人）｜2026-10-07
- 执行人：阿坚（后端）
- 单号：S3-174
- 触发：业主指令「演示登陆要解除帐号锁定不要限制」；凌舟在执行前做影响面核查时发现**真实数据暴露**

---

## 〇、🔴 问题（凌舟实测，生产只读）

| 事实 | 证据 |
|:--|:--|
| 演示账号在**真实租户**里 | 生产登录返回的 JWT payload：`{"id":3,"username":"demo","roles":["SUPER_ADMIN","STORE_OPERATOR"],"tenantId":"default"}` |
| `default` **就是真实业务租户** | `SELECT tenant_id, COUNT(*) FROM t_sale_bill GROUP BY tenant_id` ⇒ **`default` = 524 行**（另一个租户仅 1 行）；`t_member` 在 `default` = 9 行 |
| 演示口令是**公开值** | `Demo@2026` 写在产品前端产物里（admin-web 打包产物含该常量）与仓内 `.env.example` |
| 后果 | **公网上任何人用这个公开口令即可登入 `default` 租户并持有 `SUPER_ADMIN`** ⇒ 直接看到/操作真实客户的 524 张销售单等业务数据 |

**性质**：这不是"演示要不要限制"的问题，是**真实业务数据（含客户经营数据）对公网开放**。而且它**今天就已存在**（与 S3-172 无关；S3-172 只去掉"账号锁定"，而锁定对一个公开口令本来就没有任何防护价值）。
