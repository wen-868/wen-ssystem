### 二、逐端点说明（路径 / 鉴权 / 入参 / 返回字段 / 金额单位与精度 / 零假数据）

统一口径（6 端点全部适用）：

- **鉴权**：`routeConfig.auth = "requirePlatformAuth"` ⇒ 无令牌 **401**（`fail("未登录","401")`）。控制器与 servic**从不读 `req.tenantId`**（复跑：`rg -n "req\.tenantId|tenantId!" backend/src/{routes,controllers/platform,services/platform}/platform-billing*` ⇒ 零命中）；租户身份只来自请求参数 + 库表校验。
- **金额单位/精度**：所有金额列均为 `DECIMAL(12,2)` ⇒ **元、2 位小数**；响应体显式带 `amountUnit: "CNY"`、`amountScale: 2`（CSV 则表头写「(元/2位小数)」+ 响应头 `X-Amount-Unit` / `X-Amount-Scale`）。DECIMAL 出库在 service 出口统一 `Number()` 归一（mysql2 对 DECIMAL 返回字符串，不归一会让前端拿到 `"1234.50"`）。
- **零假数据**：无数据一律空数组/仅表头，绝不造数。

|---|---|---|---|
| **A-1** `GET /api/platform/billing/reconciliation-daily` | query `dateStart`/`dateEnd`（`YYYY-MM-DD` 且必须是**真**日期）/`status`/`platform`/`page`(≥1)/`pageSize`(1~100)；`dateStart > dateEnd` 拒绝 | `{ records: [{ id, platform, date, platformOrderCount, platformAmount, systemOrderCount, systemAmount, diffCount, diffAmount, commissionAmount, status, updatedAt }], total, page, pageSize, amountUnit, amountScale }`；无数据 `records: []`、`total: 0` | 400（日期非法/倒挂/分页越界）；401 |

口径细则（A-4 / A-6，避免被当成"已结清/已开票"）：

- **A-4 幂等**：`t_platform_settlement` 无 `(tenant_id, period_start, period_end)` 唯一键且禁止 ALTER ⇒ 应用层实现「先查（同租户+同账期+`status <> 'CANCELLED'`，`ORDER BY id ASC LIMIT 1`）→ 命中即返回 `idempotent: true` → 未命中才 INSERT → INSERT 后**再查一次**，若回读到更早的一单（并发先插）则返回那一份（`idempotent: true`）」。
- **A-4 金额**：订阅/增值计费引擎未落地（C4-0 §十一 A11，`config/api-billing.ts` ENABLED=false）⇒ `total_amount/pending_amount` 写死 `0.00`，响应 `amountSource: "UNAVAILABLE"` + `note` 说明，并把同义说明写入 `t_platform_settlement.remark`（留痕在库内，不靠响应体）。**不编造任何金额**。
- **A-6 复用 `t_invoice`**（零 ALTER、零新表）：`invoice_type='OUT'`、`related_type='PLATFORM_BILLING'`、`related_no=结算单号`、`tenant_id=请求租户`、申请即 `status='PENDING'`（无 `ISSUED` 字样）；`issue_date`/`issuer` 留空（未开票，不伪造）。`amount` 缺省取该租户结算单 `total_amount`；结算单解析优先级 `settlementId > settlementNo > 该租户最近一单（ORDER BY created_at DESC, id DESC）`，**未命中一律 400 且不写库**。
