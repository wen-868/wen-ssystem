**服务端错误原文**（生产 pm2 `zhixiang-api-out.log`，01:26:25）：

```
[ERROR] [GET] /api/platform/ai/metering-log — Illegal mix of collations
(utf8mb4_0900_ai_ci,IMPLICIT) and (utf8mb4_unicode_ci,IMPLICIT) for operation '='
```

⇒ 典型**真库才暴露**的缺陷：SQL 里比较的两侧**排序规则（collation）不一致**（本服务 4 条端点只有这一条落到该比较上）。**mock/单测环境（SQLite 或统一 collation）永远盖不住**。

2. 验证码**码字以 `<text>` 明文嵌在 SVG 里**（本项目已知并已登记：`middleware/login-fail-limiter.ts` 明写"限流是唯一爆破门闩"）⇒ 从 SVG 抽 `text` 节点拼接即得码；
