## 三、设计要求（设计稿 v1.6 逐页要点，逐项落实）

Tab1 模型接入：双分区（平台公共模型-全部租户可用含免费版 / 自定义模型-付费专属），每个模型显示名称、可用状态、供应商与用途、输入单价、输出单价、今日调用与成本、编辑入口。Tab2 计费策略：按套餐加成倍率表 + 月度额度用尽策略（停用/降级小模型/透支后付费）+ 免费赠送额度。Tab3 额度包商品（规格/价格/有效期/上架状态）。Tab4 积分抵扣：启用总开关 + 抵扣汇率配置（手动、非固定值；未配置时总开关自动置灰并提示）+ 四级扣减顺序（积分→套餐额度→额度包→超额计费）+ 抵扣流水。Tab5 计量流水（时间/租户/套餐/模型/消耗 Token/抵扣积分/余额/扣减来源）。Tab6 用量看板（消耗来源结构 + 趋势）。
