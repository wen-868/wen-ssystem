⚠️ 三点必须说清，否则「已覆盖」会被误读为「这些页面没问题」：

3. **视口只有 Desktop Chrome 默认**（1280×720 一类），未覆盖响应式/窄屏。

## 三、降级覆盖声明（本单采用的降级与它的边界）

1. **浏览器 axe 是本轮新增的真实渲染覆盖**，但它**只进观察期 `a11y` job（非 required，不阻断）**——因为基线存在真实违规（见回传卡），若进 required 会堵死所有 PR。
2. **静态对比度矩阵 `scripts/contrast-check.cjs` 继续保留**作为 saas-admin 的第二道面（纯计算、覆盖 token×surface + canvas 图表色），它与浏览器 axe 是**互补**关系：
   - 矩阵覆盖「token 声明值」，能发现"改了 token 就会红"；
   - 浏览器 axe 覆盖「真实渲染」，能发现硬编码色、层级叠加、透明背景叠加等矩阵看不到的问题。
   - ⇒ 二者都不可互相替代；本单**未**因接入浏览器 axe 而移除矩阵。
3. **未覆盖 ≠ 无问题**：U-1~U-7 中任一项现在都可能有违规，只是当前门禁照不到。
