|---|---|---|---|
| 1440×900 | 770px | #3174F1 | **1.699** |
| 1920×1080 | 1027px | #3174F1 | **1.699** |
| 1366×768 | 731px | #3173F1 | **1.715** |

- **卡点**：绝对定位的包含块取决于 `.login` 外层是否定位（外层元素未在本次核查范围内确认 `position`），且取样位置随视口尺寸变化。
- **结论（两种面都不达标）**：落在白面 = 2.523；落在品牌渐变 ≈ 1.70。**均不达标**。

### 8-2 `src/views/ai-config/PlatformAiConfig.vue:489` `.v11-dim .btn` —— 失败主因是父级 `opacity`，改 `--g4` 修不好

- 父级 `.v11-dim` 设 `opacity:0.55` + `filter:grayscale(1)`（`:484-485`），底层为 `.v11-gate` 的斜条纹 `repeating-linear-gradient(-45deg,var(--g0),var(--g0) 8px,var(--g1),var(--g1) 16px)`（`:473`）。

- 即使取建议值 #6E6E6E，合成后仍只有 **2.194:1**，**依然不达标**。
- 另注：该按钮 `pointer-events:none`（`:488`），属**停用状态**；WCAG 1.4.3 对"停用 UI 组件上的文字"有豁免。**建议：不随本次 `--g4` 取值处理，另案处理父级 `opacity`。**

### 8-3 `src/views/ops/TicketSystem.vue:437` `.zx-scope .btn.is-off` —— 是否算"停用组件"需裁定

- 自身 `background:var(--g0)`（`:436`）→ 相邻面 #F7F7F7，现状 **2.355:1**，不达标。
- 样式声明 `cursor:not-allowed`，但源码注释写"按钮置灰禁用（**仍可点击**，仅给出待接入提示）"。
  - 若裁定为**停用/禁用组件** → 适用 WCAG 1.4.3 豁免，**不适用阈值**；

### 9-1 文本类 / 非文本类：**建议统一取 `#6E6E6E`**

**取 #6E6E6E 的理由：**
1. 在最严常见面 **#F7F7F7（画布底 / `--g0`）上为 4.76:1**，对 4.5:1 有 0.26 余量，能抗取整误差与子像素抗锯齿。
2. **不能直接用现成的 `--g5` #737373**：它在白面上 4.74 达标，但在画布底 #F7F7F7 上只有 **4.43:1，差 0.07 不达标** —— 这正是本表必须逐点追溯相邻面的原因。
3. 理论最亮可取值是 #717171（#F7F7F7 上 4.556），余量仅 0.056，不建议。
4. 若凌舟希望复用既有灰阶以少引入新值：**#666666（`--gray-500`）** 是最省事且余量充足的选择（画布底 5.36:1）。
5. 非文本类若单独放行，最严面 #F7F7F7 上只需 ≤ **#8F8F8F**（3.02:1）；但既然共用一个 token，统一取 #6E6E6E 更简单，且不会破坏视觉层级（比 #8F8F8F 略深，仍在中性灰范围内）。
