## 六、追加口径（业主 2026-10-15）：**三端必须统一，不能各端出现不同的账号/权限**

### 6.1 先摆事实：三端现在是**三套身份域**（不是同一个登录口）

| 端 | 登录身份 | 后端身份源 | 令牌 |
|:--|:--|:--|:--|
| 总台 `saas-admin` | **平台管理员** | `t_platform_admin`（平台级，无 `tenant_id`） | platform JWT（`type=platform_admin`） |
| 工作台 `admin-web` | **租户用户** | `t_sys_user` + `t_sys_role`（按 `tenant_id` 隔离） | 租户 JWT |
| 移动端 `app-mobile` / miniapp | 租户用户 / 消费者 | 同上（或微信令牌→消费者身份） | 租户 JWT / 微信令牌 |

⇒ 同一个字符串账号**天然不能**在三端是"同一个身份"：平台超管与租户超管是**两套权限体系**（这正是 S3-193 刚建立平台侧 `requirePlatformPermission` 的原因）。

### 6.2 凌舟据此定的"统一"口径（可执行、不假装拉平）

**统一的是"账号 + 口令 + 演示入口 + 文案"，不强行拉平权限模型**：

1. **账号口令统一**：三端演示入口都用 **`admin` / `admin@2026`**，不再出现第二套口令（`Demo@2026` 全仓清零）。
2. **三端各自有同名同口令的账号**（这是"同一账号三端可登"的唯一实现方式）：
   - 总台：`t_platform_admin.admin` 口令 = `admin@2026`（**平台侧**身份）；
   - 工作台/移动端：`t_sys_user.admin`（default 租户）口令 = `admin@2026`（**租户侧**身份）。
   ⚠️ 口令**同名同值**，但**身份与权限各自独立**——这是必须向业主讲清的一点，不能对外宣称"一个账号一套权限"。
3. **权限口径统一**（真正要防的"各端不一致"）：
   - 同一角色在**工作台与移动端**必须解析出**同一权限集合**（都读 `t_sys_role.permissions`）；移动端**不得**再自带第二套角色/权限常量；
   - 平台侧（总台）权限统一走 `requirePlatformPermission` + `t_platform_role_permission`，**不再**用 `t_sys_role`；
   - **跨端一致性门禁**：新增一条只读核对脚本/用例，**同一角色在三端解析出的权限集合必须一致**（移动端 vs 工作台），不一致即红。
4. **演示入口统一**：三端演示登录按钮**都**指向各自身份域里的 `admin/admin@2026`；文案、`.env.example`、`VITE_DEMO_*` 全部同一套。

### 6.3 追加验收判据

- 三端各自的 `admin/admin@2026` **均可登录**（给三端原始响应）。
- 全仓 `rg "Demo@2026|store_manager"`（**示例/文档处**）⇒ 不再作为演示凭据；演示相关引用只指向 `admin`。
- **跨端权限一致性**：同一角色在移动端与工作台解析出的权限集合**逐条相同**（给对照输出）；若历史上确有差异，**逐条列差异并说明是否修复**。
- 平台侧与租户侧**仍是两套**：本条**不**要求把平台超管与租户超管拉平；若业主确要"总台也用租户身份登录"，属**换鉴权体系**，需单独立项（会推翻 S3-193 的平台机制）。

### 6.4 业主 2026-10-15 最终确认（**定案，不再摇摆**）

> 原话：**"需要全部一致，租户账号不能进入总台"**

据此定案：

1. **统一面**：账号 + 口令 + 演示入口 + 文案 —— 三端一致（`admin` / `admin@2026`）。
2. **权限口径**：**同一身份域内**一致（工作台与移动端同角色 ⇒ 同一权限集合；平台侧统一走 `requirePlatformPermission`）。这就是"全部一致"的落地含义。
3. **边界必须保留且要**加门禁**：**租户账号（`t_sys_user` 签发的租户 JWT）**打总台任何端点必须 **401/403**，总台前端也不得接受租户令牌**。这是硬红线，不是"可选加固"。
   - 追加验收判据：拿**租户 `admin` 的令牌**打总台端点 ⇒ **401/403**（给原始响应）；拿**平台 `admin` 的令牌**打工作台端点 ⇒ 同样**必须被拒**（双向越权都要拒）。任一侧放行即**判红**。
