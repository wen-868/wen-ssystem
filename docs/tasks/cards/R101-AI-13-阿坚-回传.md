## 存量违规行：发现 + 处置方案（**只出方案，未执行**）

### 一、只读发现（SQL 形状，仅示意，**本卡未执行**）

业务库（`t_ai_external_model` / `t_tenant_ai_config` / `t_platform_ai_config`）：

```sql
-- 1) 外部模型库：非 https / 内嵌凭据 / 受限网段字面量（字面量类一次扫全）
SELECT id, name, provider_base_url, enabled, updated_at
FROM t_ai_external_model
WHERE provider_base_url NOT LIKE 'https://%'
   OR provider_base_url LIKE '%@%'
   OR provider_base_url REGEXP '^https?://(127\\.|10\\.|172\\.(1[6-9]|2[0-9]|3[01])\\.|192\\.168\\.|169\\.254\\.|0\\.|\\[?::1\\]?|\\[?fc|\\[?fe80)';

-- 2) 商户可写端点（同口径；商家管理员可改本租户）
SELECT tenant_id, api_endpoint, enabled, updated_at
FROM t_tenant_ai_config
WHERE api_endpoint IS NOT NULL
  AND ( api_endpoint NOT LIKE 'https://%' OR api_endpoint LIKE '%@%'
        OR api_endpoint REGEXP '<同上正则>' );

-- 3) 平台端点（**只告警不处置**：卡内裁定平台端点只记录）
SELECT id, default_endpoint, updated_at FROM t_platform_ai_config WHERE id = 1;
```

⚠️ **SQL 只能扫「字面量/协议/凭据」类**；`https://` 域名解析到私网（含内网域名）扫不出来，
需应用侧异步复扫（复用 `assertPublicResolvableTarget`，逐行解析全部 A/AAAA）。

### 二、处置选项与影响面

| 选项 | 做法 | 影响面 | 本卡是否做了 |
|---|---|---|---|
| **甲（已落地，建议）** | 运行时**拒绝加载** + ERROR 日志留痕（含 host） | 违规模型不可用（fail-closed）；其余模型与租户不受影响；无需改数据，**零数据风险** | ✅ 已实现（registerModel / getRuntimeConfig） |
| 乙（告警观察） | 对 ERROR 日志 `拒绝注册` 做监控告警；或新增只读巡检端点（另开卡） | 只观测不阻断已注册实例（重启后才生效）；需监控接入 | 未做（未新增入口，避免超范围） |
