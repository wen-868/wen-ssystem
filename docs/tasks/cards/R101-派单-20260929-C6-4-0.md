一、为什么必须先做这一单（凌舟调查的决定性结论）
  1. 规划原文：「**调取的本质是租户主动发起的单向数据复制**（公共主数据 → 租户私有档案），**落库即隔离**」；「**调取计入租户商品配额**」。
  2. 但实测：**"调取"全仓只有 UI 文案**（`rg -n "调取" --glob '!docs/**'` 仅命中 `saas-admin/src/views/library/LibrarySpus.vue` 的平台侧描述），**没有任何租户侧复制端点**；存在的只有 `/api/open/library/*`（API Key 鉴权的**读取**，C3 产物）与 `/sku/barcode/:barcode`（扫码式查询）。
  3. ⇒ **先有 COPY 动作，才谈得上"调取流水"**；凌舟已裁定（业主 2026-09-27 追认）：**先做 COPY（含流水表 + 配额），不要先建空流水表**。

     · **端点清单**（逐字路径 + 方法 + 请求/响应契约 + 状态码），至少覆盖：调取前预览（可选）、执行调取、调取结果查询、调取流水查询（平台侧 + 租户侧各自可见范围）；
