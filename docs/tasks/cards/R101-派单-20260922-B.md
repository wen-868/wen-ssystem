接口口径（**必须逐条实现，不得自由发挥**）：
- **响应严格对齐** `SyncDeltaResponse`：`since` 原样回显请求的 since；`until` = **本页返回记录中最大的 `updated_at`**（无记录时 = 请求的 `since`）；`hasMore` = 是否还有下一页。
- `changes[].action` 三态：新增/修改 → `UPSERT`；物理删除 → `DELETE`（若表无软删除，可只支持 UPSERT，但**必须在回传里写明**）；状态位变更 → `STATUS_CHANGE`。
- **租户隔离**：一律走 `queryWithTenant` / `queryOneWithTenant`（禁止裸 `query` 拼字符串），**跨租户数据不得出现在任何一页**。
- **只读**：三个接口**不得**写任何表。
- `since` 缺失/非法/未来时间：**必须行为确定**（建议：缺失 = 1970-01-01 第一页；非法 = 400 并给明确 message；未来 = 空 changes + `until = since`），把选择写进回传。
- 分页：`page`（默认 1）、`pageSize`（默认 100、上限 500），排序 `updated_at ASC, id ASC`（**保证翻页稳定**）。
