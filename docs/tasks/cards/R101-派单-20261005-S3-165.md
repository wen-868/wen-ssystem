# 【派单 S3-165】（P0 安全）禁用**生产**的免密 `demo-login`（非生产保留），并把演示链路改为只走口令登录
（落卡时间：2026-10-05｜凌舟 · 跨仓项之一，AI 底座线点名）

```
【派单 S3-165】`POST /api/admin/auth/demo-login` 是**免密**接口：空 body 即返回 `default` 租户的 `SUPER_ADMIN` 令牌。它必须**在生产关闭**；非生产环境保留（联调有用）。同时把移动端「演示登录」的降级路径改掉——现在它在口令登录被锁时会**降级到该免密通道**，生产关掉后必须给出可操作提示而不是死路。
派单人：凌舟（总负责人）｜2026-10-05
执行方：阿坚（后端 · 本地通道）
优先级 / 时间盒：P0 · 一次跑完
基线：以开工当日 origin/main 为准（自证须给远端真值：gh api repos/wen-868/wen-ssystem/commits/main --jq .sha）

一、事实（凌舟已核实）
  ① 端点与实现：`backend/src/server.ts:220` 注册 `POST /api/admin/auth/demo-login` → `controllers/admin/auth.controller.ts` 的 `demoLogin` → `services/admin/auth.service.ts` 的 `demoLogin()`：自动建 `demo` 账号、幂等绑 `SUPER_ADMIN`、**被锁定会自动恢复**，返回完整令牌与 `csrfToken`。
  ② 生产可用且**无需任何凭据**（2026-10-05 实测：`curl -X POST .../demo-login -d '{}'` ⇒ 200 + 令牌）。这是 `ZXQL-AI/docs/规范/生产安全核查.md` 登记为 **P0** 的那条。
  ③ **演示账号本身已不依赖它**：`demo` / `Demo@2026`（合规口令）可正常登录；且 S3-160-F1b 已把"演示账号 + `rememberMe:true` ⇒ 30 天长效"限定为**仅演示账号**可用 ⇒ 演示体验不受本单影响。
  ④ 但移动端有降级路径：`app-mobile/src/pages/login/login.vue` 的 `handleDemoLogin()` 在**口令登录返回"锁定/失败次数过多"时**会调 `authApi.demoLogin()`（打 `POST /admin/auth/demo-login`）并提示「演示通道已接管」。**生产关掉后这条降级必然失败**。

二、范围（钉死）
  **做**：
   · ① **后端**：把 `demo-login` 改为**按环境门控**——`NODE_ENV === "production"` 时该端点**不可用**（返回 404 或 403，二选一，但**必须**在响应里给出明确文案，例如"演示登录在生产环境已禁用"；**不得**静默 200）。非生产（含 `USE_MOCK_DB=true` 的 CI）保持现状可用——注意**不得**破坏 e2e/CI（它们跑 mock 环境）。
   · ② **口径来源要单一**：判定写在**一处**（建议放 `middleware/auth.ts` 或 `config/env.ts` 旁的显式开关函数），不得在多处各写一遍 `NODE_ENV === 'production'`。
   · ③ **单测**：①生产 ⇒ 该端点被拒（给状态码与文案）；②非生产 ⇒ 仍 200 且返回令牌；③既有 `demoLogin()` 的幂等/自动恢复逻辑不回归。
   · ④ **移动端降级文案**（最小改动）：生产禁用后，降级失败时的提示必须**可操作**（例如"演示通道已停用，请用演示账号登录"），**不得**只留"演示通道不可用"这种无出路文案。可只改 `login.vue` 里那一句 catch 文案与注释。
  **不做**：不改演示账号口令、不改 `rememberMe` 口径、不改 401 逻辑、不改其它端点、不加新依赖、不改数据库。
```
