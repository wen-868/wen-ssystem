  2. 现状机制（G2 审计已实测）：app-mobile **无 `meta.roles`/`beforeEach` 角色门禁**；功能菜单由 `app-mobile/src/config/function-menu.ts:175` 按 **`code.split(':')[0]` 模块前缀**过滤，前缀集来自 `GET /admin/menus/user`（读 `t_sys_role_menu`）；**接口失败即回退全量**（`functions.vue:150-156`）。
  3. 生产 `t_sys_role_menu` **347 行 / `t_sys_menu` 64 行**（11 CATALOG + 53 MENU），角色差异明显（`STORE_MANAGER` 33 / `STORE_OPERATOR` 21 …）⇒ **菜单可见性是可判定的**，但**多个被调用的页面在 `t_sys_menu` 里根本没有码**（G2 实测：`finance:reconciliation`、`finance:expenses`、`customer:stored-card` 均**不存在**；`member-detail` **无自身注册项**），且**「我的」页与首页存在"无条件入口"**（`profile.vue:180`）⇒ 这些页面对**所有登录角色**可达。
