## 一、问题：命令本身检不动东西

`bash -n <script> <args...>` 把**第一个之后的参数当作脚本的位置参数**（`node --check` 同理）。
于是 `bash -n deploy/*.sh scripts/*.sh` **只检了 glob 展开后的第一个文件**：

| 事实 | 值 |
|---|---|
| `deploy/*.sh` 总数 | **12** |
| 实际被检 | **1**（字母序首位 `02-mysql-backup.sh`） |
| 从未被检 | **11**，含我们反复加固的 `auto-deploy.sh`（第 7）、`ai-base-deploy.sh`（第 6） |
| `scripts/*.sh` | 目录下 **0 个 .sh** → 字面量被当位置参数传入，静默无意义 |

**我上一轮（S3-46）把位置与 `if: always()` 都做对了，但没验命令本身**——
这正与凌舟自陈的同一盲点同形（他接受 S3-39 时用同一条命令宣布"6/6 通过"）：
**工具用法本身没验，结论就是假的。**

## 三、修复

```yaml
- name: Shell script syntax check (deploy/scripts)
  if: always()
  run: |
    set -uo pipefail
    checked=0; fail=0
    for f in deploy/*.sh scripts/*.sh; do
      [ -e "$f" ] || continue          # 空 glob 兜底
      checked=$((checked + 1))
      if ! bash -n "$f"; then echo "::error file=${f}::shell 语法错误"; fail=1; fi
    done
    echo "已语法检查 ${checked} 个 shell 脚本"
    if [ "${checked}" -lt 1 ]; then echo "::error::未匹配到任何待检脚本"; exit 1; fi
    [ "${fail}" -eq 0 ] || exit 1
```

**两个额外设计**（防的是"再次退化成假门禁"）：
1. **打印已检查数量** —— 若某天这个数变回 1，一眼能看出又只检了第一个；
2. **`checked -lt 1` 也判失败** —— 防"glob 写错/目录清空 → 一个都没检却 exit 0"这种反向假绿灯。
