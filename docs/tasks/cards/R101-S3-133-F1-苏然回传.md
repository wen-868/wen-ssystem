## 四、对业务代码的建议区（**仅建议，未改码**，红线①）

`backend/src/shared/auto-routes.ts` L98–103 对单文件 `await import()` 用 `try/catch + continue` **吞掉**导入异常，是"注册失败静默化"的根因。本单不动码，建议后续由凌舟派单考虑：
1. **结构性fail-fast**：区分"开发环境/mock 依赖缺失"（可 continue）与"真实语法/逻辑错误"（应抛出），可在 catch 中按错误类型或显式白名单判定；
2. **注册结果自校验**：`setupRoutes` 结束时对比"扫描到的文件数"与"成功注册的配置数"，差额 > 0 时 `logger.error` 汇总，便于线上第一时间发现掉线路由；
3. 上述任一项落地后，本卡的"总数守恒"判据可相应简化，但**不建议**在 fail-fast 落地前移除任何一条判据。
