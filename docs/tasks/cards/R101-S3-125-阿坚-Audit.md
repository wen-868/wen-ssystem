## 二、权限持有人集合复算（F1 `matchPermission` × 生产角色实值）

复跑命令（与 G0/G1 同源；本单亦由进程内装置真跑复算，输出见回传卡 §四-2）：

```powershell
function Match-Perm { param([string[]]$perms,[string]$code)
  if($perms -contains '*'){return $true}
  $di=$code.IndexOf(':'); if($di -gt 0 -and ($perms -contains ($code.Substring(0,$di)+':*'))){return $true}
  $ai=$code.LastIndexOf(':'); if($ai -gt -1 -and $ai -lt $code.Length-1 -and ($perms -contains ('*:'+$code.Substring($ai+1)))){return $true}
  return ($perms -contains $code) }
$roles = [ordered]@{
  'SUPER_ADMIN'=@('*'); 'OPERATION_ADMIN'=@('*')
  'STORE_MANAGER'=@('store:*','sale:*','customer:*','inventory:*','report:*','dashboard:*','finance:payment','goods:price','finance:daily-settle')
  'STORE_OPERATOR'=@('sale:create','sale:view','inventory:view','dashboard:view','sale:return','finance:daily-settle')
  'SALES_STAFF'=@('sale:create','sale:view','customer:view','customer:visit','dashboard:view')
  'PURCHASE_STAFF'=@('purchase:*','supplier:*','inventory:inbound','report:purchase')
  'FINANCE_STAFF'=@('finance:*','report:*','customer:statement','supplier:statement','dashboard:view')
  'WAREHOUSE_STAFF'=@('inventory:*','trace:*','transfer:*','stock-check:*')
  'CUSTOMER_SERVICE'=@('customer:view','aftersale:*','miniapp:*','notification:view')
  'READONLY'=@('*:view') }
foreach($c in @('finance:create','sale:create')){
  $hit=@(); foreach($r in $roles.Keys){ if(Match-Perm $roles[$r] $c){$hit+=$r} }
  Write-Output ("{0,-15} 持有人 = {1}" -f $c, ($hit -join ', ')) }
```

| 权限点 | 持有人集合 | 命中语义 |
|:--|:--|:--|
| `finance:create` | `SUPER_ADMIN, OPERATION_ADMIN, FINANCE_STAFF` | `*` ×2 + `finance:*` 域通配 |
| `sale:create` | `SUPER_ADMIN, OPERATION_ADMIN, SALES_STAFF, STORE_OPERATOR, STORE_MANAGER` | `*` ×2 + 精确码 ×2 + `sale:*` 域通配 |
| 关键否定项 | `STORE_MANAGER / STORE_OPERATOR / SALES_STAFF / WAREHOUSE_STAFF / CUSTOMER_SERVICE / READONLY ∉ finance:create`；`CUSTOMER_SERVICE / READONLY ∉ sale:create` | — |

### 5.1 卡面要求复跑的 SQL（原文照抄，供凌舟在生产/本机执行）

```sql
-- 0) 表行数（卡面口径：347 / 64）

SELECT COUNT(*) FROM t_sys_menu;

-- 1) 角色 → 菜单（逐字符可复核；这是本单判据的唯一数据源）
SELECT r.role_code, m.menu_code
FROM t_sys_role_menu rm
JOIN t_sys_role r ON r.id = rm.role_id
JOIN t_sys_menu m ON m.id = rm.menu_id
WHERE r.tenant_id = 'default' AND m.tenant_id = 'default'
ORDER BY r.role_code, m.menu_code;

-- 2) 逐菜单反查持有角色（本单"该菜单持有角色"一栏的直接来源）
SELECT m.menu_code, GROUP_CONCAT(DISTINCT r.role_code ORDER BY r.role_code) AS holders
FROM t_sys_menu m
LEFT JOIN t_sys_role_menu rm ON rm.menu_id = m.id
LEFT JOIN t_sys_role r ON r.id = rm.role_id
WHERE m.tenant_id = 'default'
GROUP BY m.menu_code
ORDER BY m.menu_code;

-- 3) 反查单个页面对应菜单的持有者（示例：store:list / sale:bill）
SELECT m.menu_code, r.role_code
FROM t_sys_menu m
JOIN t_sys_role_menu rm ON rm.menu_id = m.id
JOIN t_sys_role r ON r.id = rm.role_id
WHERE m.menu_code IN ('store:list','sale:bill')
ORDER BY m.menu_code, r.role_code;
```
