## 三、逐卡裁定

### QODER-23

- `aesGcmDecrypt` 在任何标签比较前拒绝 `tag.length !== 16`，长标签不能只靠前 16 字节通过。
- 原概率用例已改成先断言 16 字节、再确定性翻转 `tag[0]`；新增 18 字节非规范标签用例。
- R1 摘长度守卫仅 18 字节用例红，R2 摘比较失败分支仅翻转用例红；两轮复原 SHA 一致。
- 补做项不是本卡返工：`iv.length !== 12` 与短 tag 测试归 QODER-23F1。

### QODER-24

- semver 仅接受严格更高版本；等值、降级、非法版本不提示。
- `.wgt` 必须 https、无凭据、非 IP、标准端口、与 API 同源、路径以 `.wgt` 结尾。
- 下载后读取原始字节、实算 SHA-256，并与 `packageSha256` 比较；缺失、格式非法、实算不一致均删除临时文件且不安装。
- `updateUrl` 只能来自集中白名单决策；不再直接打开后端原值。
- 后端当前没有 `packageSha256` 字段，因此 `.wgt` 自动直装关闭、改走可信下载页，这是正确的失败关闭结果。后端补字段另列外部前置。
- r1/r2/r3/r4 四组反测均有红档；作废轮与重试链已保留，未把 `INJECT_EXIT!=0` 当有效反测。

- **不通过原因 1**：四树 mp-weixin 均出现 `<custom-tab-bar>` 与平台内置组件撞名警告；产物仍为 `components/custom-tab-bar.*`，而微信 `custom:true` 没有对应原生 `custom-tab-bar/` 目录。不能把构建 exit 0 当 MO-18 闭环。
