## 六、本次发现的工具陷阱（已同步踩坑日志 [110]–[113]）

1. `.gitignore` 的 `*.log` 会连带吞掉 `docs/**/*.log` → 证据日志永远无法入库。
2. `git worktree remove --force` **不会**清掉 Junction 所在的空壳目录；必须用 `cmd /c rmdir <junction>` 摘链，且**禁止**用 `Remove-Item -Recurse`（会顺着 junction 删主仓依赖）。
3. 用 `git status --porcelain` 的带引号路径去查 `main:<path>`，非 ASCII 路径会**全部假 ABSENT**（本次差点把 5,000 个"新增文件"当真）；必须 `-z` 或 `core.quotepath=false`。
4. `git hash-object` 不给 `--path` 时不做 CRLF 归一 → 纯换行差异被误判为"内容不同"；`git branch --no-merged main` 在 squash-merge 仓里同样**全是假阳性**。
