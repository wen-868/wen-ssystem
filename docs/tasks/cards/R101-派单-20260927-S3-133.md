## 一、事实（凌舟实测，两次数值差 6.7 倍）

| 场景 | 命令 | 结果 |
|---|---|---|
| 单跑（机器空闲） | `npx vitest run src/__tests__/shared/auto-routes.test.ts` | **19/19 通过，18.18s**（其中 tests 17.33s、transform 11.25s） |

⇒ 该用例**耗时贴边**（18s vs 120s 上限，余量 6.7×），在 CI 或本机并发下**会随机判红**。S3-125/G2 那轮我就因此拿到一次"全量 1 failed"，单跑复绿 —— **这类抖动会污染"红=真缺陷"的可信度**（与踩坑 [81]/[143] 同族：门禁的可信度取决于它是否稳定）。

2. **根因假设 + 证伪**：给出**至少 2 个**假设（例：① 冷启动 transform 占比高 ⇒ 预热/缓存可解；② 扫描全目录并真实注册 ⇒ 与文件数线性相关），**逐个证伪或证实**（给命令与原始输出）。
3. **处置建议（治标 + 治本各一条，标注代价）**：
