## 二、证据（可复跑：命令 + 原始输出 + 行号）

### 2.1 改了什么（哪里有问题 → 改了什么 → 为什么）

- **哪里有问题**：`backend/src/shared/migration.ts:90`（HEAD 版本 `:84`）的模式 `/(CREATE\s+TABLE\s+(?:IF\s+NOT\s+EXISTS\s+)?)([a-z_][a-z0-9_]*)/gi` 只认裸表名；`` CREATE TABLE IF NOT EXISTS `x` `` 时可选组回溯为空、名字组抓到 `IF` ⇒ `CREATE TABLE t_IF NOT EXISTS `x`` ⇒ ER_PARSE_ERROR。
- **改了什么**：10 个既有模式的**名字组**统一变为 `` (`[a-z_][a-z0-9_]*`|[a-z_][a-z0-9_]*) ``（`migration.ts:93-103`），命中后按引号形态重建（回调 `:106-113`：`` `x` `` → `` `t_x` ``；无引号 → `t_x`）；补了函数级中文注释说明根因与"不配对反引号不匹配"的边界。
- **为什么**：反引号形态加前缀后必须保持引号形状（不能出 `` t_`x` ``、更不能出 `t_IF`）；模式族必须**逐个**都支持反引号（不得只覆盖本单用到的 `CREATE TABLE` 形状）；不带反引号的输入输出逐字节不变（回归零差异）。
