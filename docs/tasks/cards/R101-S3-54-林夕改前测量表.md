## 5. 最严面结论

**最严背景面 = `#F0F0F0`**（相对亮度 L = 0.871367）

- 出处一：`MainLayout.vue:1164` `.notify-item-time` —— 父级 `.notify-item:hover{background:var(--bg-soft)}`，`--bg-soft` = `#F0F0F0`（tokens.css:97）。这是 5 个文本引用点中唯一的非白底面。

## 7. 无法追溯 / 风险项（如实单列）

### R1【重要】`--input-border` 在构建产物中被 Element Plus 默认规则覆盖

在 `admin-web/dist/assets/index-BaYScwY1.css` 中，业务规则与 EP 默认规则**特异性相同**（均为 0,1,0），但 **EP 规则位置更靠后 → EP 胜出**：

| 位置 | 来源 | 规则 |
|---|---|---|
| ≈20700 | 业务 styles.css:762 | `.el-input__wrapper,.el-select__wrapper{...box-shadow:0 0 0 1px var(--input-border) inset}` |
| ≈21249 | 业务 styles.css:781 | `.el-textarea__inner{...box-shadow:0 0 0 1px var(--input-border) inset}` |
| 95192 | EP el-input.css | `.el-textarea__inner{...box-shadow:0 0 0 1px var(--el-input-border-color,var(--el-border-color)) inset}` |
| 99173 | EP el-input.css | `.el-input__wrapper{...box-shadow:0 0 0 1px var(--el-input-border-color,var(--el-border-color)) inset}` |
| 115302 | EP el-select.css | `.el-select__wrapper{...box-shadow:0 0 0 1px var(--el-border-color) inset}` |

- EP 默认 `--el-input-border-color: var(--el-border-color)`，项目 styles.css:36 覆盖 `--el-border-color: #E2E2E2`。
- **推论：实际渲染的边框色是 #E2E2E2，而不是 --input-border 的 #CCCCCC。** #E2E2E2 在 #FFFFFF 上仅 **1.2955:1**、在 #F0F0F0 上 **1.1368:1**，比 #CCCCCC 更差。
- **影响：单改 `--input-border` 很可能视觉无变化。** 请凌舟裁定是否需同步提高业务规则特异性（如加 `.el-form` 前缀）或直接改 `--el-border-color`。
- 置信度说明：证据取自既有构建产物 `dist/`（其中 `--input-border:#CCCCCC` 与 tokens.css 一致，判断为较新构建），**未运行浏览器实测**，建议改动前用 DevTools 复核一次。

### R2 P5 `.reset-tip` 为死代码，无法测 DOM 实际底色

- `SystemConfigView.vue` 中 `.reset-wrapper/.reset-alert/.reset-card/.reset-title/.reset-desc/.reset-form/.reset-tip`（724–761 行）**全部只有 CSS 定义，模板中无任何引用**；全仓检索 `reset-tip|reset-card|reset-title` 同样只命中 CSS。
- 因此只能按 CSS 声明（`.reset-card{background:#fff}`）给出面 = #FFFFFF，**无法验证真实渲染底色与使用位置**。若后续启用该块需重新测量。

### R3 Element Plus 版本差异

- `admin-web/package.json:26` 声明 `^2.7.6`，但实际安装（仓库根 `node_modules`）为 **2.14.3**；`admin-web/node_modules` 仅 7 个包、不含 element-plus，实际解析走根目录。
- 本表引用的 EP 默认值（`--el-bg-color-overlay:#fff`、`--el-fill-color-blank:#fff`、popover / input 背景）取自 2.14.3 的 `theme-chalk`。若 CI 装的是 2.7.x，默认值应一致但**未实测确认**。

### R4 输入框禁用态存在 1:1 完全不可见边框（不在本次 token 作用域）

- EP：`.el-input.is-disabled .el-input__wrapper{background-color:var(--el-disabled-bg-color);box-shadow:0 0 0 1px var(--el-disabled-border-color) inset}`，特异性 (0,3,0) > 业务 (0,1,0)，仍由 EP 接管。
- 项目覆盖 `--el-fill-color-light:#F0F0F0`（styles.css:46）→ `--el-disabled-bg-color` = #F0F0F0；`--el-border-color-light:#F0F0F0`（styles.css:37）→ `--el-disabled-border-color` = #F0F0F0。
- **底色与边框同色，对比度 1:1，禁用输入框边框完全不可见。** 走 EP 变量链，**改 --input-border 修不到**，单独登记。

### R5 P6/P7 外侧面为保守取值
