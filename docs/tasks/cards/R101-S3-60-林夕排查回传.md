## 3. 根因

| 位置 | 内容 | 作用 |
|---|---|---|
| `admin-web/src/views/Dashboard.vue:714` | 卡片钉死 `height: 420px` | 容器高度被写死，不随内容伸缩 |
| `admin-web/src/views/Dashboard.vue:720` | `flex: 1; min-height: 0` | 允许内部压缩，但溢出内容不外露 |

⇒ 二者叠加：内容渲染完成并**溢出**后，`.el-card__body` 才成为「可滚动区域」；
浏览器允许鼠标滚轮滚动，但**该容器没有可聚焦能力**，键盘用户（Tab 键）永远到不了。

**为什么是 3/8 间歇**：溢不溢出取决于当次请求返回的数据量。
配合 S3-59 缺陷一（E2E 打生产 API `https://api.onepan.cn`），数据量随生产实时状态漂移 → 命中率漂移。

## 4. 修法（二选一，由墨择一）

### 方案 A：给可滚动容器加键盘可达性

```html
<div class="el-card__body" tabindex="0" role="region" aria-label="趋势明细">
```

- `tabindex="0"` → 可被 Tab 到达
- `role="region"` + `aria-label` → 屏幕阅读器能识别这是一个具名区域

### 方案 B：改成卡片内不滚动的布局

去掉 `Dashboard.vue:714` 的 `height: 420px` 钉死，改由内容决定高度（或给出足够高度），
使 `.el-card__body` **根本不产生内部滚动**。
