### R8-S1 制定标准化验收 checklist

- 优先级：P0
- 预计：0.5 天
- 状态：待开始
- 标准依据：项目统一标准 第十一章、附录A
- 文件：新建 `docs/reports/验收-checklist.md`

**任务：** 根据《项目统一标准》附录A 的每一项差距，制定可执行的验收检查项。

**checklist 必须覆盖：**
1. **结构性验收**（对照标准第一章）
   - `config/` 目录存在且含 8 个文件
   - `middleware/` 目录存在且含 6 个文件
   - controller 层无直接数据库操作
   - 目录命名符合标准

2. **返回体格式验收**（对照标准第三章）
   - 所有 API 返回 `{ code, msg, data, traceId, apiCost }`
   - 全局搜索 `{ code, message` 归零
   - 全局搜索 `res.json({ code` 归零（除 `ok()`/`fail()` 内部）

3. **业务约束验收**（对照标准第五章）
   - 价格守卫应用到 5 类路由
   - 手写 `customerType === "WHOLESALE"` 归零
   - 追溯码出入库自动绑定
   - 订单流程统一入口

4. **提交门禁验收**（对照标准第七章）
   - `npx tsc --noEmit` 0 错误
   - `npm run build` 成功
   - `npm audit` 0 漏洞

5. **前端验收**（对照标准第六章）
   - 前端 `message` → `msg` 适配完成
   - 表单校验三件套齐全
   - 依赖安全版本

**验收：** checklist 覆盖标准附录A 全部 13 项差距
