### 状态管理弹窗规格

```
组件: el-dialog
宽度: 480px
圆角: var(--radius-lg)
标题: "订单状态变更" (16px, 600, center)

表单字段:
  - 当前状态: 只读显示, .status-tag
  - 目标状态: el-select (根据当前状态动态生成可选目标)
  - 操作备注: el-input (type=textarea, rows=3, placeholder="选填")
  - 物流公司: el-select (发货时显示, 选项: 顺丰/圆通/中通/申通/韵达/其他)
  - 物流单号: el-input (发货时显示, placeholder="请输入物流单号")

状态流转规则 (基于 fulfillment.ts):
  待付款 → 待配送 (付款完成)
  待配送 → 配送中 (START_DELIVERY)
  待配送 → 已完成 (COMPLETE)
  待配送 → 已拒绝 (REJECT)
  配送中 → 已完成 (COMPLETE)
  配送中 → 已拒绝 (REJECT)
  任意非已完成 → 已取消 (CANCEL)

确认提示:
  - 根据目标状态动态显示提示文字
  - 拒绝/取消: 红色警告图标 + 提示
  - 其他: 蓝色信息图标 + 提示

底部按钮:
  - [取消]: type=default
  - [确认变更]: type=primary
  - 间距: 12px
```
