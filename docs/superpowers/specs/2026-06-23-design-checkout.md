## 组件详细设计

### A. 顶部导航栏
```
高度: 56px
背景: var(--bg-card)
阴影: var(--shadow-card)
内容:
  - 左侧: ← 返回按钮 (24x24 icon, 点击返回上一级)
  - 中间: "收银台" 标题 (var(--text-page-title), 700)
  - 右侧: [门店选择下拉] [操作员头像+姓名]
交互:
  - 门店切换 → 重新加载商品库存
  - 快捷键 F2 = 聚焦搜索框
```

### B. 左侧 - 商品搜索区
```
背景: var(--bg-soft)
内边距: 16px
间距: 12px

1. 搜索框 (高度 40px)
   - 圆角: var(--radius-md)
   - 占位符: "扫码或输入商品名称/编码"
   - 右侧扫码图标按钮
   - 焦点态: border-color → var(--border-focus) + var(--shadow-focus)
   - 快捷键: F2 聚焦

2. 分类标签 (横向滚动)
   - 标签高度: 32px
   - 圆角: 16px (胶囊)
   - 选中态: bg=var(--color-primary), text=white
   - 未选中: bg=white, text=var(--text-secondary)
   - 间距: 8px
   - 分类: 全部 | 白酒 | 红酒 | 啤酒 | 饮料 | 零食 | 其他

3. 商品卡片网格 (2列)
   - 卡片尺寸: 自适应，最小 140px
   - 圆角: var(--radius-md)
   - 背景: var(--bg-card)
   - 阴影: 0 2px 8px rgba(0,0,0,0.06)
   - 内容:
     · 商品图片 (1:1, 圆角 8px)
     · 商品名称 (14px, 500, 单行省略)
     · 价格 (18px, 700, var(--color-primary))
     · 库存 (12px, var(--text-muted), "库存:23")
     · [+ 加入] 按钮 (全宽, 32px高, 圆角 8px)
   - 库存 ≤ 5: 库存文字变 var(--color-warning)
   - 库存 = 0: 卡片置灰, [+ 加入] 禁用
   - 点击 [+ 加入]: 商品飞入购物车动画 (scale-in)

4. 搜索结果列表 (搜索时替代网格)
   - 列表项高度: 56px
   - 左侧: 缩略图 40x40
   - 中间: 名称 + 价格
   - 右侧: [+ 加入] 按钮
```

### C. 中间 - 购物车区
```
背景: var(--bg-page)
内边距: 16px 24px

1. 客户选择栏 (高度 48px)
   - 左侧: "客户：" 标签 (14px, var(--text-secondary))
   - 中间: 客户名称 (14px, 500, var(--text-primary))
   - 右侧: [选择] 按钮 (outline, 32px高)
   - 点击 [选择]: 弹出客户选择弹窗
     · 搜索框 + 会员列表
     · 支持手机号/姓名搜索
     · 底部 [新增散客] 按钮

2. 商品列表 (可滚动, flex: 1)
   - 每项高度: 80px
   - 分隔线: 1px solid var(--border-normal)
   - 内容布局:
     · 左侧: 商品名称 (14px, 500) + SKU编码 (12px, var(--text-muted))
     · 中间: 单价 (14px) × 数量
     · 数量控件: [-] [数量] [+] (按钮 28x28, 圆角 6px)
     · 单位切换: [箱] [瓶] toggle
     · 右侧: 小计金额 (14px, 700) + [删除] icon
   - 箱/瓶换算: 点击 [箱] → 数量按箱比换算
   - 删除: 点击 [删除] → 二次确认 → 移除

3. 底部合计栏 (高度 56px, 固定底部)
   - 背景: var(--bg-soft)
   - 圆角: var(--radius-md)
   - 内容: "合计：X件    ¥ X,XXX.XX"
   - 金额: var(--text-amount-lg), 700, var(--color-primary)
```

### D. 右侧 - 结算区
```
背景: var(--bg-card)
左边框: 1px solid var(--border-normal)
内边距: 24px
布局: flex column, justify-content: space-between

1. 金额明细区
   - 每项高度: 36px, flex row, space-between
   - 标签: 14px, var(--text-secondary)
   - 金额: 14px, 500
   - 行: 商品金额 | 优惠 | 抹零
   - 分隔线: 1px dashed var(--border-normal)
   - 应收金额行:
     · 标签: 16px, 700, var(--text-primary)
     · 金额: var(--text-amount-lg), 700, var(--color-primary)

2. 支付方式区
   - 标题: "支付方式" (14px, 500, margin-bottom: 12px)
   - 按钮网格: 2列 x 3行
   - 按钮样式:
     · 高度: 44px
     · 圆角: var(--radius-md)
     · 边框: 1px solid var(--border-normal)
     · 选中态: border=var(--color-primary), bg=var(--color-primary-soft)
     · 图标 + 文字
   - 选项: 现金 | 微信 | 支付宝 | 银行卡 | 赊销 | 混合支付
   - 赊销选中时: 展开应收截止日期选择器

3. 备注输入
   - 文本域, 高度 60px
   - 圆角: var(--radius-md)
   - 占位符: "选填备注..."
   - 边框: 1px solid var(--border-normal)

4. 提交按钮
   - 高度: 52px
   - 全宽
   - 圆角: var(--radius-md)
   - 背景: var(--color-primary)
   - 文字: "提交订单" (16px, 700, white)
   - hover: bg=var(--color-primary-hover)
   - active: bg=var(--color-primary-active)
   - 禁用态: opacity=0.5, cursor=not-allowed
   - 快捷键: Enter 提交

5. 快捷操作栏
   - 3个按钮横向排列
   - 按钮样式: text button, 13px, var(--text-secondary)
   - 选项: [挂单] [取单(2)] [清空]
   - 挂单数显示角标
```

## 交互细节

| 交互场景 | 行为 | 动效 |
|---------|------|------|
| 扫码输入 | 自动聚焦搜索框，扫码后自动加入购物车 | fade-in-up |
| 点击 [+ 加入] | 商品加入购物车，数量+1 | scale-in + 飞入动画 |
| 数量 [-] 到 0 | 弹出确认"是否移除该商品？" | pulse |
| 切换箱/瓶 | 数量按箱比自动换算，价格同步更新 | - |
| 选择客户 | 弹窗搜索会员，选中后显示客户名称+等级 | slide-in-right |
| 选择支付方式 | 高亮选中按钮，赊销展开日期选择器 | fade-in |
| 提交订单 | 校验购物车非空 → 调用 API → 成功/失败提示 | scale-in |
| 挂单 | 当前购物车暂存，清空界面，角标+1 | slide-in-left |
| 取单 | 弹窗显示挂单列表，选择恢复 | slide-in-right |
| 快捷键 F2 | 聚焦搜索框 | - |
| 快捷键 Enter | 提交订单（需购物车非空+已选支付方式） | - |
| 快捷键 Esc | 取消当前弹窗/操作 | - |
