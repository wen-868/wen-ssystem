## 完整流程设计

```
Step 1: 选择场景
  ┌──────────────────────────────────────┐
  │  [门店现场] → 立即收款模式            │
  │  [外出拜访] → 生成收款链接模式        │
  └──────────────────────────────────────┘
         │
         ▼
Step 2: 选择客户
  ──────────────────────────────────────┐
  │  [搜索客户] → 弹窗搜索会员            │
  │    · 支持手机号/姓名模糊搜索          │
  │    · 显示: 名称 + 类型标签 + 手机号   │
  │    · 选中后显示客户等级和授信额度     │
  │  [散客] → 不关联客户                  │
  └──────────────────────────────────────┘
         │
         ▼
Step 3: 添加商品
  ┌──────────────────────────────────────┐
  │  [搜索商品] → 弹窗搜索商品            │
  │    · 支持名称/SKU编码搜索             │
  │    · 显示: 名称 + 库存 + 价格         │
  │    · 价格根据客户类型自动切换          │
  │      - 批发客户 → wholesalePrice      │
  │      - 零售/散客 → storePrice         │
  │  [扫码] → 调用摄像头扫码              │
  │    · 扫码成功自动加入购物车           │
  └──────────────────────────────────────┘
         │
         ▼
Step 4: 调整数量
  ──────────────────────────────────────┐
  │  箱/瓶双单位输入                      │
  │    · 箱: stepper 控件 (min=0, max=999)│
  │    · 瓶: stepper 控件 (min=0, max=999)│
  │    · 箱瓶换算: 1箱 = 6瓶 (可配置)     │
  │    · 小计 = 单价 × (箱数×箱比 + 瓶数) │
  │  [删除] → 二次确认 → 移除商品         │
  └──────────────────────────────────────┘
         │
         ▼
Step 5: 金额调整
  ┌──────────────────────────────────────┐
  │  折扣: 输入金额 (不能为负数)          │
  │  抹零: 输入金额 (不能为负数)          │
  │  应收 = 商品总额 - 折扣 - 抹零        │
  │  实时计算，输入时即时更新             │
  └──────────────────────────────────────┘
         │
         ▼
Step 6: 选择销售类型
  ┌──────────────────────────────────────┐
  │  [现销] → 直接收款                    │
  │  [赊销] → 展开应收截止日期选择器      │
  │           → 到期日默认为当前+30天     │
  └──────────────────────────────────────┘
         │
         ▼
Step 7: 提交
  ┌──────────────────────────────────────┐
  │  门店现场:                            │
  │    1. 创建销售单                      │
  │    2. 弹出收款方式选择                │
  │    3. 选择: 现金/微信/支付宝/转账     │
  │    4. 确认收款 → 成功提示             │
  │                                      │
  │  外出拜访:                            │
  │    1. 创建销售单                      │
  │    2. 弹出收款链接配置                │
  │    3. 设置有效期 (默认72小时)         │
  │    4. 生成链接 → 复制链接分享         │
  └──────────────────────────────────────┘
```

## 组件详细设计

### A. 页面头部
```
高度: 56px
背景: var(--bg-card)
布局: flex, space-between, center
内容:
  - 左侧: ← 返回按钮 (icon: arrow-left, 24x24)
  - 中间: "销售开单" 标题 (18px, 600, var(--text-primary))
  - 右侧: [单据] 按钮 (icon: orders-o, 跳转销售单列表)
```

### B. 场景切换 Tabs
```
组件: van-tabs (type="card")
高度: 40px
选项:
  - 门店现场 (STORE) → 默认选中
  - 外出拜访 (VISIT)
样式:
  - 选中态: bg=var(--color-primary), text=white
  - 未选中: bg=transparent, text=var(--color-primary), border=var(--color-primary)
  - 圆角: var(--radius-md)
切换影响:
  - 门店现场 → 底部按钮显示"立即收款"
  - 外出拜访 → 底部按钮显示"生成收款链接"
```

### C. 客户信息卡片
```
容器: .card (bg=var(--bg-card), radius=var(--radius-lg), shadow=var(--shadow-card))
内边距: 16px

已选客户状态:
  - 第一行: 客户名称 (15px, 500) + 类型标签 (van-tag)
    · 批发: type=primary, plain, "批发"
    · 零售: type=success, plain, "零售"
  - 第二行: 手机号 (13px, var(--text-secondary)) + 等级 + 授信额度
  - 第三行: [重新选择] 按钮 (type=default, size=small, plain)

未选客户状态:
  - [搜索客户] 按钮 (type=primary, size=small, icon=search)
  - [散客] 按钮 (type=default, size=small, plain)
  - 间距: 10px
```

### D. 商品搜索区
```
容器: .card
搜索框:
  - 高度: 40px
  - 圆角: var(--radius-md)
  - 占位符: "输入商品名称/SKU编码"
  - 右侧: [扫码] 按钮 (icon: scan)
  - 焦点态: border=var(--border-focus) + var(--shadow-focus)
扫码功能:
  - 调用 wx.scanCode (小程序) / navigator.mediaDevices (H5)
  - 扫码成功 → 自动搜索并加入购物车
```

### E. 已选商品列表
```
每项结构:
  - 顶部: 商品名称 (14px, 500) + 单价 (14px, 600, var(--color-primary))
  - 第二行: SKU编码 (12px, var(--text-muted))
  - 数量行:
    · 箱: 标签 "箱" (13px) + stepper (min=0, max=999, integer)
    · 瓶: 标签 "瓶" (13px) + stepper (min=0, max=999, integer)
    · 间距: 20px
  - 底部: 小计金额 (14px, 500) + [删除] 按钮 (type=danger, size=mini, plain)
  - 分隔线: 1px solid var(--border-normal)
  - 内边距: 12px 0

箱瓶换算逻辑:
  - bottlesPerBox: 从商品数据获取 (默认6)
  - 总瓶数 = boxQty × bottlesPerBox + bottleQty
  - 小计 = unitPrice × 总瓶数
  - 修改箱数时，瓶数不变，总瓶数联动更新
```

### F. 金额汇总卡片
```
容器: .summary-card (bg=var(--bg-card), radius=var(--radius-lg), shadow=var(--shadow-card))
内边距: 16px

行结构:
  - 商品总额: 标签 (14px, var(--text-secondary)) + 金额 (14px, 500)
    · 标签右侧显示总瓶数: "商品总额 (8瓶)"
  - 折扣: 标签 + van-field (type=number, width=100px, 右对齐)
    · 占位符: "0"
    · 校验: 不能为负数
  - 抹零: 标签 + van-field (type=number, width=100px, 右对齐)
    · 占位符: "0"
    · 校验: 不能为负数
  - 分隔线: 1px solid var(--border-normal)
  - 应收金额: 标签 (16px, 600, var(--text-primary)) + 金额 (18px, 700, var(--color-danger))

计算公式:
  receivableAmount = max(0, goodsAmount - discountAmount - roundingAmount)
  实时计算，输入时即时更新
```

### G. 销售类型切换
```
容器: .card
标题: "销售类型" (14px, 600, margin-bottom: 12px)
选项:
  - [● 现销] (默认选中)

  - 提示文字: "赊销订单将在到期日生成应收账款" (12px, var(--text-muted))
```

### I. 底部操作按钮
```
容器: .action-footer (sticky bottom, bg=var(--bg-card), shadow top)
内边距: 16px

门店现场模式:
  - [立即收款] 按钮
    · type=primary, block, round, size=large
    · 点击 → 校验购物车非空 → 弹出收款方式选择

外出拜访模式:

```

## 弹窗设计

### 客户选择弹窗
```
组件: van-popup (position=bottom, round, maxHeight=80%)
结构:
  - 标题: "选择客户" (16px, 600, center)
  - 搜索框: van-search (placeholder="输入手机号/姓名搜索")
  - 结果列表: van-cell-group (inset)
    · 每项: 客户名称 + 类型标签 + 手机号
    · 点击 → 选中并关闭弹窗
  - 空状态: van-empty (description="无搜索结果")
  - 底部: [新增散客] 按钮 (type=default, block)
```

### 商品搜索弹窗
```
组件: van-popup (position=bottom, round, maxHeight=80%)
结构:
  - 标题: "选择商品" (16px, 600, center)
  - 搜索框: van-search (placeholder="输入商品名称/SKU编码")
  - 结果列表: van-cell-group (inset)
    · 每项: 商品名称 + 库存 + 价格
    · 价格根据客户类型显示:

      - 零售/散客: storePrice ?? retailPrice
    · 点击 → 加入购物车并关闭弹窗
  - 空状态: van-empty (description="无搜索结果")
```

```

  - 生成前:
```
