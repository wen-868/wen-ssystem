## 看板列规格

```
每列:
  - 宽度: 280px (固定, 不伸缩)
  - 最小高度: calc(100vh - 200px)
  - 背景: var(--bg-soft)
  - 圆角: var(--radius-md)
  - 内边距: 12px

列头部:
  - 高度: 48px
  - 布局: flex, space-between, center
  - 状态名称: 14px, 600, 对应状态颜色
  - 数量徽章: 圆形, 24x24, 对应状态色背景, 白色文字, 12px, 600
  - 左侧色条: 3px 宽, 全高, 对应状态颜色

拖拽区域:
  - flex: 1
  - overflow-y: auto
  - 最小高度: 200px
  - 拖拽进入时: bg 变浅, 边框虚线高亮
  - 拖拽占位符: 虚线边框卡片, 高度与实际卡片一致
```

## 拖拽交互设计

```
拖拽规则:
  - 仅允许向"下游"状态拖拽 (不可逆向)
  - 允许的目标状态:
    · 待付款 → 待确认, 已取消
    · 待确认 → 待配送, 已拒绝
    · 待配送 → 配送中, 已完成, 已拒绝
    · 配送中 → 已完成, 售后中
    · 已完成 → 售后中
    · 售后中 → 已退款
  - 已拒绝/已取消/已退款: 不可拖出

拖拽流程:
  1. mousedown 卡片 → cursor=grabbing, 卡片半透明
  2. 拖动中 → 显示拖拽幽灵 (ghost), 原位置留占位符
  3. 进入目标列 → 目标列高亮 (border=对应状态色, dashed)
  4. 释放 → 校验状态流转合法性
     · 合法: 调用 API 更新状态 → 卡片动画飞入新列 (slide-in-right)
     · 非法: 卡片弹回原列 (spring-back 动画) + toast 提示
  5. 拖出看板区域 → 卡片弹回原列

拖拽反馈:
  - 合法目标列: border=2px dashed 对应状态色, bg 变浅
  - 非法目标列: border=2px dashed var(--color-danger), bg=var(--color-danger-soft)
  - 拖拽幽灵: 原卡片样式, opacity=0.8, box-shadow 增强
  - 占位符: 虚线边框, bg=var(--bg-soft), 高度=实际卡片高度
```
