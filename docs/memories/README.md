## 迁移后操作流程

**每个成员迁移到 TRAE IDE 后，第一件事：**

1. `git pull` 拉取最新代码
2. 打开 `docs/memories/` 中自己的记忆文件，完整阅读
3. 再读以下三份核心文档：
   - `docs/项目规则.md` — 核心规则
   - `docs/项目统一标准.md` — 唯一标准
   - `docs/踩坑日志.md` — 20 个踩坑记录
4. 确认 `docs/tasks/current-tasks.md` 中的当前任务状态
5. 开始工作

**凌舟（项目管理）迁移后额外步骤：**
1. 读取 `docs/memories/凌舟-记忆.md` 恢复完整记忆
2. 确认所有成员记忆文件已生成
3. `npm install` 在所有项目目录执行
4. 跑一轮全量验证确认迁移无损
5. 启动下一轮任务（services 层覆盖率）

## 记忆文件内容要求

每份记忆文件必须包含：
1. **我是谁** — 角色、职责、工作原则
2. **项目全貌** — 技术栈、目录结构、关键文档位置
3. **团队成员** — 每个人的强项/弱项/核查要点
4. **轮次历史** — R1~R15 完整记录
5. **核心决策** — 为什么这样做
6. **踩坑教训** — 20 条关键教训
7. **当前质量状态** — R15 完成后的各项指标
8. **剩余技术债** — 迁移后处理的内容
9. **迁移检查清单** — 到 IDE 后必须确认的事项
10. **工作习惯** — 个人专属操作习惯
