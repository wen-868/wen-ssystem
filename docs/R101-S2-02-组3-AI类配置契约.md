## 三、四组配置包字段定义

统一护栏（与组2 完全一致）：

- `version`：正整数，落库时强制写入
- `_unconfigured: string[]` / `_configured: boolean`：**只读元字段**，`_` 前缀，前端据此置灰阻断，**不得回写**
- 未落库 / JSON 解析失败 → 返回「全部未配置」空包，**绝不回退到任何默认业务值**

### 3.1 `ai:billing_strategy` — 套餐加成倍率与月额度用尽策略

设计稿依据：L966~L976

```jsonc
{
  "version": 1,
  "plans": {
    "<planCode|planId>": {
      "multiplier": 1.2,                 // 加成倍率，> 0，用于 AI 超额费用 = 模型成本单价 × 倍率
      "exhaustion": "disable",           // 月度额度用尽策略：disable | downgrade | overage
      "downgradeModel": "",              // exhaustion=downgrade 时的降级目标模型（可空）
      "note": "停用 + 升级引导"           // 运营说明文案
    }
  }
}
```

- `exhaustion` 枚举：`disable`（停用+升级引导）、`downgrade`（降级至基础模型）、`overage`（超额计费）
- **超额单价不入库**：`overage` 只表示策略类型，具体单价属 S3-03，本包不存该字段
- 设计稿示例值（免费版 1.0x / 基础版 1.2x / 标准版 1.1x / 旗舰版 1.0x）**仅为设计稿示意，不得作为默认值写入代码或数据库**

### 3.2 `ai:free_grant` — 免费版赠送额度

设计稿依据：L982~L984

```jsonc
{
  "version": 1,
  "monthlyCalls": 50,      // 每月赠送调用次数，非负整数
  "grantModel": ""         // 赠送模型标识（如 deepseek-v3）
}
```

- 「免费额度月初重置不累计」是**固定业务规则**（设计稿 L984 明文），**不做成配置项**

### 3.3 `ai:quota_pack` — 额度包商品

设计稿依据：L991~L994

```jsonc
{
  "version": 1,
  "packs": [
    {
      "id": "pack-light",
      "name": "AI 加量包 · 轻量",
      "tokens": 500000,          // 额度 Token 数，正整数
      "price": 99,               // 售价（元），> 0
      "validMonths": 12,         // 有效期（月），正整数
      "applicablePlans": [],     // 适用套餐范围，空数组 = 不限
      "purchaseLimit": null,     // 限购数量，null = 不限
      "status": "on_sale"        // on_sale | off_shelf
    }
  ]
}
```

- 设计稿示例值（500,000 Token / ¥99、3,000,000 Token / ¥499）**仅为设计稿示意，不得作为种子数据**
- 「本月售出 214 份」类销量数据来自交易，**本卡不做，页面保持空态**

## 五、红线报备（本轮不修，交凌舟裁定）

**ai-base（NestJS，端口 3016）全服务零鉴权。**

- 检索 `backend/ai-base/src` 下 `useGlobalGuards` / `AuthGuard` / `UseGuards` / `@Public` / `IS_PUBLIC` —— **零命中**
- `AiConfigController`（`backend/ai-base/src/gateway/ai-config.controller.ts`）8 个端点全部无鉴权装饰器，
  含：平台默认配置（默认 API Key 掩码）、租户 AI 配置列表/详情/更新、用量统计、计费套餐
- 前端 `saas-admin/src/api/ai-config.ts` 直连 `http://localhost:3016`（`resolveAiBase()`，L31-35），仅携带 JWT 但**后端不校验**

风险：若 3016 端口对外可达，AI 配置（含密钥掩码、租户用量、计费）可被未鉴权读取。
与踩坑 [64]（`t_subscription_plan.features` 被 `auth:"none"` 公开端点透出）同类。

**本轮不修**（用户裁定：只报备不擅动），原因：
1. 属安全项，超出「配置项落库与回显」任务边界
2. 未确认 3016 的实际部署拓扑（是否只监听 127.0.0.1 / 前置是否有网关），盲目加 guard 可能误伤内部调用

建议后续专项卡处理，并先确认部署拓扑。

## 六、P0 硬编码修复（本卡必改项）

### 6.1 违规事实

`saas-admin/src/views/ai-config/AiBillingConfig.vue:179`：

```html
<b>换算示例</b><span>（按当前配置汇率折算）：10 万积分 ≈ <b>500 万 token</b> 可抵扣量 ≈ 按公共模型均价约抵 <b>¥250</b> 用量</span>
```

与设计稿 L1017 **逐字一致**——即把设计稿的示意数字当常量抄进了产品。

**问题**：文案自称「按当前配置汇率折算」，但汇率是管理员可配置的（`ai:points_rate`），
示例却恒定显示 1 积分 = 50 token 的推算结果（10 万 → 500 万 → ¥250）。
管理员把汇率改成 1:100 后，页面仍显示 500 万 token，**数字与配置自相矛盾**。

### 6.2 修复口径

换算示例改为**实时计算**，输入两项：

1. **汇率**：`GET /api/platform/ai-billing/points-rate` → `points` / `tokens`
2. **公共模型均价（¥/千 Token）**：前端调 `listExternalModels()`（已有封装，走 ai-base 3016），
   取平台公共模型的输入/输出单价计算均价

计算：`示例积分(10 万) → 可抵扣 Token = 100000 × (tokens / points)`，
`金额 ≈ 可抵扣 Token / 1000 × 公共模型均价`

**任一项缺失（未配置 / 接口不可用）→ 对应段显示「—」，并提示需先配置。
绝不回退到 500 万 / ¥250 等任何写死数字。**
