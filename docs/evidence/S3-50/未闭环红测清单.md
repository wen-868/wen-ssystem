## 2. 补做时的通用纪律（照抄派单卡红线）

1. 反测一律**分支 + PR**（`ci.yml`/`e2e.yml` 均有 `on: pull_request`；`deploy.yml` 只在 push main 时部署，故 PR 不会触发生产部署）。
2. **一次只合一个会触发部署的 PR**；反测 PR 一律 draft，**不得合并**。
3. 取证完成后**关 PR、删分支**（E-2 善后口径），把 run id + 步骤名 + 断言结论写回卡片。
4. **不得**为凑绿放宽断言、**不得**用 `|| true` 掩盖退出码、**不得**把"步骤显示 success"当作"它能失败"。
5. 每项反测必须**打在目标对象上**：坏在 glob 末尾（S3-49 教训）、坏在"该门禁真正读取的输入"上（R8.1：层叠/覆盖类问题只用 computed 值定论）。
