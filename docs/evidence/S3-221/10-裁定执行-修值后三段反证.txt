## 5. 顺手修复（门禁脚本旧缺陷，**main 上已存在**）

`scripts/contrast-check.cjs` 的 `escapeForRegExp()` 替换串曾被前一次编辑吞掉，写成了一段注释文本：

```js
// 改前（错误，替换串是注释文本）：
return s.replace(/[.*+?^${}()|[\]\\]/g, "\\// ── 解析（读取真实文件取值）─────────────────────────");
// 改后（正确：整段匹配回填）：
return s.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");
```

影响面：现有 token 名不含正则元字符 ⇒ 一直**零影响**；但将来任何含 `.`/`-`/`(` 等的 token 名会被误判成"token 未找到"而假红。已在同批修复并 `node --check` 通过（`git show origin/main:scripts/contrast-check.cjs` 可复核该缺陷在 main 即存在，非本单引入）。
