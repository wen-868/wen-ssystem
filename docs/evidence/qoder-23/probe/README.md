## 与任务书口径的差异（已按实测写代码，不硬套旧文）

任务书 `QODER-23-gcm-tag-length.md:27` 与派单消息把缺陷描述为「`tag[16..]` 溢出为 undefined，异或后为 NaN ⇒ `diff \|= NaN` 结果仍是 0」。实测否掉了"NaN"这条路径（F2/F3）：**长 tag 的越界字节根本没进循环**（循环上界恒为 16），所以缺陷面不是"NaN 把 diff 洗成 0"，而是"循环只看前 16 字节 ⇒ 多余字节自由"。结论方向不变（18 字节标签确实被静默接受，E4 实测），守卫与用例照 §二 落地；措辞差异记此报备，见回传卡 §九。
