**口径（重要，回应凌舟 B3）**：
1. **设置弹窗已关闭**：原型页面内置自检脚本（V12/V14 系列 ck() 断言，源码 L8635~）会在加载过程中
   主动 openSetWin('conn') 打开设置弹窗做断言、跑完由 estore() 收口。旧版取证"加载后 2.5s 截图"
   恰好落在自检中途 ⇒ 截到弹窗态。本版改为**等自检收口 + 调原型自身 closeSet()**，并复验
   setwinVisible=false / maskVisible=false / toastCount=0 后才截图。**未用临时改 display 冒充可见态。**
2. **同主面联动**：截图时先探测原型**当前真实主面**（feed / chat / manual），再把实现切到**同一主面**
   后截图，保证两图可互核。本轮原型自检收口后停在 chat（会话面）⇒ 实现同切 chat。
   因此 1440 的 impl-1440.png 与四态①impl-chat-1440.png 为**同一状态**（内容一致，属预期）。
3. 已知差异（不影响结构核对）：原型有会话列表/员工切换/在线数（需 AI 底座会话与在线端点，本单 D-1 已裁定暂缺）；
   实现有顶栏「数字员工/任务进度」真实数据格与就绪失败重试入口。
