## 三、处置（逐条）

必需项 env 名**沿用两个脚本的既有约定**（`API_BASE` / `ADMIN_URL` / `ADMIN_USERNAME` / `ADMIN_PASSWORD`，
后者与本仓 S3-175 起的旧名 `DEMO_PASSWORD` 等价、`ADMIN_PASSWORD` 优先）；无既有名字的一律新立并沿用
同族命名（`SAAS_URL` / `M_URL` / `WWW_URL`）。**全部条目一律改为 env 注入，缺任何一项即 exit 1。**

| 改前 | 改后 |
|:--|:--|
| 五条硬编码域名常量（all-domains #1–#5） | `process.env.API_BASE / ADMIN_URL / SAAS_URL / M_URL / WWW_URL`，缺失即 exit 1 |
| `DEMO_PASSWORD \|\| "admin@2026"`（all-domains #6） | `ADMIN_PASSWORD ?? DEMO_PASSWORD`（两者都未设 ⇒ exit 1）；**零内置口令** |
| health / http 形态字面量（all-domains #7–#12） | `HEALTH_URL = API_BASE.replace(/\/api$/,"") + "/health"`；`toHttp(url)` 由 env 地址推导 http 形态 |
| `username: "admin"`（all-domains #13） | `username: ADMIN_USERNAME`（env 注入） |
| CORS Origin 字面量（all-domains #14） | `new URL(ADMIN_URL).origin` / `new URL(SAAS_URL).origin`（同源推导） |
| production #1–#4 的 `\|\| 默认值` | 全部去掉回落分支；必需项缺失即 exit 1 |
