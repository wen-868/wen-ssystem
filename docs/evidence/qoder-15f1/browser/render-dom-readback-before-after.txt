                                            修复后 不标红（无效值不参与比较）
  行5 number 0 < 8.5                     → 修复前标红 / 修复后标红（真低价，两侧一致，无回归）
  行6 千分位串 1,234.56 < 2,000.00       → 修复前标红 / 修复后标红（该组合字典序碰巧与数值同向，无回归）
