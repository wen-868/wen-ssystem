## 二、已知兼容性基线

- 移动端 H5 构建产物为 Vite + uni-app 运行时，已替换 DCloud CDN 外部资源（vite.config.ts 内联透明像素），避免离线/CDN 加载失败
- APP 端 API 基址统一为 `https://api.onepan.cn/api`（2026-08-15 修复，老包需重新打包）
- 桌面客户端支持 x86/arm64 双架构（electron-builder 配置），品牌图标已打包
