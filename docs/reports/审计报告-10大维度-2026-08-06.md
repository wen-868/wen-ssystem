## 维度明细

### 1. 安全合规
- **扫描**：`rg` 硬编码密钥/密码/token；抽查命中文件
- **发现**：
  - 命中 15 个文件，抽查确认**均为误报**（变量名、注释、测试环境 `setup.ts` 的 JWT_SECRET、token 注入代码）
  - 测试环境 `JWT_SECRET="test-secret-key-for-vitest"`（backend/src/__tests__/setup.ts）属测试专用，可接受
  - 生产密钥均走 `.env`（backend/.env、ai-base/.env），未入库
- **待办（P1，派单阿坚）**：`npm audit` 依赖漏洞审计；权限面复核（越权/CSRF/租户隔离抽检）

### 2. 性能
- **测量**：admin-web dist 4.2MB；app-mobile H5 产物 1.3MB
- **发现**：
  - 主入口 index-*.js 363KB（gzip 113KB），可接受
  - echarts 独立 chunk 468KB，已按需加载但有优化空间
  - 图片优化/长列表虚拟滚动未专项核查
- **待办（P1，派单墨）**：图片懒加载与压缩核查；echarts 按需导入复核；长列表虚拟滚动评估

### 3. 代码质量
- **扫描**：`rg console.(log|debug)` + TODO/FIXME
- **发现**：
  - `npx vue-tsc -b` 0 errors ✅（R76-03 已修复）
  - console 候选 4 处：`app-mobile/src/api/modules/ai.ts`、`pages/ai-chat/ai-chat.vue`、`backend/src/shared/feishu-report.ts`（含测试文件）
- **待办（P2）**：确认并清理 console 残留（阿澈/阿坚按归属）

### 4. 架构与规范
- **统计**：backend 1067 文件、admin-web 201、app-mobile 162
- **发现**：目录分层（controllers/services/routes/shared）、自动路由、lint/构建脚本均规范；backend 文件量大，关注 services 层分层质量
- **待办（P2）**：无紧急项，随 R76-02 覆盖率提升持续治理

### 5. UI/主题一致性 🔴
- **扫描**：`rg "#[hex]" admin-web/src/views + components` → **1116 处硬编码颜色**
- **发现**：
  - Dashboard 等页面大量使用 Element 默认色（#409eff/#67c23a/#e6a23c）与渐变，未用品牌蓝 #3F6FEF 与 tokens.css 语义 token
  - 与 R74 设计稿「纯蓝+灰阶」标准不符，视觉不统一
- **修复建议（P0，派单墨）**：分页分批将硬编码色替换为 tokens.css 变量；图表色用 --chart-* token；完成后抽查 Dashboard/列表页

### 6. 跨平台兼容
- **扫描**：条件编译 12 处；安全区 `safe-area-inset` 166 处
- **发现**：H5/App 双端构建通过；安全区处理充分；CSS 兼容性未发现明显问题
- **待办（P2）**：三端（H5/App/小程序）表现差异对比留待小程序维度一并核

### 7. 小程序专项
- **扫描**：miniapp 目录存在，含 API 模块
- **待办（P1，派单阿澈）**：分包体积、隐私合规声明、合法域名配置、版本更新机制核对

### 8. App 端专项
- **扫描**：plus 原生能力在 `utils/security.ts`、`pin-ssl.ts`、`crypto.ts`
- **发现**：加密/证书锁定/安全存储齐备；无 nvue 页面（符合技术栈）；**Android 云打包仍阻塞（R73-03，DCloud 503，需用户换网络重试）**
- **待办（P2）**：App 包体积优化（4.2MB 内核查）、热更新/推送评估

### 9. 冗余与死代码
- **统计**：views 156 个 vs 路由引用 153 个
- **待办（P1，派单墨）**：精确对照路由与 views，找出未引用页面/组件/静态资源；检查 package.json 未使用依赖

### 10. API 契约
- **扫描**：admin-web request.ts 封装规范（baseURL/超时 30s/Token 注入/CSRF/401 处理）
- **发现**：
  - 请求层规范 ✅
  - **`POST /api/admin/reports/export` 已在后端实现但未录入 `docs/API接口文档.md`**（阿澈 R76-04 提请）
- **待办（P1，派单阿坚）**：补录 reports/export 契约；核对其余已实现未收录接口
