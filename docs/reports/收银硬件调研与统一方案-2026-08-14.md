## 二、行业收银逻辑（理解结论）

1. **收商品**：扫码枪扫商品条码 → 自动检索加入购物车（连续扫码不中断），数量默认 1、同码累加。
2. **收付款**（应收金额确认后两种主流方式）：
   - **反扫（扫码枪扫顾客付款码）**：扫出 16~24 位数字串 → 收银软件识别渠道（微信 18 位 10~15 开头 / 支付宝 16~24 位 25~30 开头 / 云闪付 62 开头）→ 调对应支付 API 扣款 → 回调记账。
   - **正扫（收款盒子）**：收银软件把金额传给盒子 → 盒子亮码 → 顾客扫码 → 盒子播报结果 → 回调收银软件记账。
   - 现金/余额/转账：直接记账并找零、弹钱箱。
3. **收尾**：打印小票、语音播报、钱箱弹开（现金）。

## 三、本次统一完善内容

### 后端

1. **微信支付 APIv2 付款码支付**（`backend/src/config/wechat-pay-v2.ts`）：
   - `/pay/micropay` 反扫扣款 + `/pay/orderquery` 轮询（USERPAYING 等待输密码场景）；
   - XML 报文 + MD5 签名（V2 官方签名规则）。
2. **支付宝当面付**（`backend/src/config/alipay-f2f.ts`）：
   - `alipay.trade.pay`（scene=bar_code）+ `alipay.trade.query` 轮询；
   - RSA2 签名与响应验签。
3. **扫码支付统一服务**（`backend/src/services/payment/scan-pay.service.ts`）：
   - 付款码渠道识别（微信/支付宝/云闪付/收款盒子）；
   - 支付成功后落销售单收款（写支付流水、扣库存、记录交易号与付款码）；
   - 通道未配置返回明确错误，绝不假记账；订单已支付兜底防重复扣款。
4. **接口**：
   - `POST /api/store/sale-bills/:billNo/pay-by-code`：收银台反扫收款；
   - `GET /api/store/payment/channels`：收银台支付通道状态。
5. **支付方式枚举统一**：收银台实际发送的 `WECHAT/BALANCE` 此前会被后端 Zod 枚举拒绝（只能过 `CASH/TRANSFER/OTHER_WECHAT/ALIPAY`），本次统一放行。
6. **支付配置扩展**：`t_payment_config` 新增 `api_key`（微信 APIv2 密钥）、`box_config`（收款盒子 JSON）；保存时 enabled 支持布尔/字符串归一化；收款盒子配置复用微信配置行。

### 前端（收银台）

1. **连续扫码修复**：商品命中加入购物车后清空输入框并保持焦点，连续扫多件不再拼接条码。
2. **结算弹窗扫码收款区**：打开弹窗自动聚焦付款码框（可关），扫码即识别渠道并调用支付接口；失败保留单号可重试（不重复建单）。
3. **收银硬件设置**（本机 localStorage）：现金收款自动弹钱箱、收款成功语音播报、结算自动聚焦付款码框。
4. **支付配置管理页**：微信增加 APIv2 密钥字段；新增“收款盒子”Tab（服务商/激活码/应用ID/串口）。

### 本地打印助手

- 新增 `POST /cash-drawer`：向打印机发送 ESC/POS 钱箱脉冲（`1B 70 00 19 FA`），收银台现金收款成功后自动调用。

## 四、配置与部署说明

### 微信付款码反扫（扫码枪收顾客微信付款码）

1. 微信商户平台 → 账户中心 → API 安全 → 设置 **APIv2 密钥**（32 位）；
2. 系统 → 支付配置 → 微信支付：填写 AppID、商户号、APIv2 密钥并启用、保存；
3. 收银台结算弹窗直接扫顾客付款码即可。

### 支付宝当面付（扫码枪收顾客支付宝付款码）

1. 支付宝开放平台创建应用并开通「当面付」；
2. 系统 → 支付配置 → 支付宝：填写 AppID、应用私钥、支付宝公钥并启用、保存；
3. 收银台结算弹窗直接扫顾客付款码即可。

### 收款盒子（聚合收款，预留）

- 系统 → 支付配置 → 收款盒子：填写服务商名称、激活码/设备号（或串口参数）并启用、保存；
- 通道未配置时收银台会明确提示，不会产生模拟收款数据；
- 具体服务商 SDK/串口协议在确定服务商后接入 `scan-pay.service` 的 BOX 分支。

### 钱箱 / 语音

- 钱箱：小票打印机 RJ11 口接钱箱，收银台硬件设置打开“现金收款后自动弹钱箱”；
- 语音：浏览器内置语音合成，无需额外硬件，硬件设置中可关闭。
