### 补测试发现并修复的真实缺陷（3 个）
1. 超期赊销扫描 affectedRows 取值错误 → 超期标记从未生效
2. 短信模板创建 insertId 取值错误 → 返回 id 恒为 undefined
3. 秒杀表结构漂移（admin 与社区营销共用表列不一致，秒杀不可售卖）
4. 微信新用户登录 insertId 取值错误 → 首次登录 userInfo.id 恒为 undefined（2026-08-15 补充）
5. 营销资产创建 insertId 取值错误 → 创建返回 id 恒为 0（2026-08-15 补充）
6. 购物车更新 affectedRows 取值错误 → 更新不存在商品时误报成功（2026-08-15 补充）
7. 赠品规则创建 insertId 取值错误 → 创建返回 id 恒为 0（2026-08-15 补充）
