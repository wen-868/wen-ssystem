v1.1V1.1 定向修订：补入「自定义AI模型权限规则」——免费客户不支持自定义模型，仅付费客户（基础版及以上）支持。修订落点：① 版块03 套餐管理·功能开关矩阵新增「自定义AI模型接入」开关项（免费版锁定）；② 版块05 AI计费·模型接入重构为「平台公共模型 / 租户自定义模型」双分区并叠加免费版租户付费墙示意；③ 版块05 计量流水新增「来源」列（公共模型 / 自定义模型）；④ 计费策略·免费版赠送额度补充关联说明。所有修订处均带 v1.1 角标，可对照 v1.0 逐处核验。
v1.2V1.2 定向修订：新增「积分抵扣 Token」机制——Token 按实际用量照常计量，结算/扣减时以积分按汇率冲抵应计费用（用量计费 + 积分冲抵；积分余额映射为可抵扣 Token 量，如 10 万积分按当前配置汇率 ≈ 可抵扣 500 万 token）。修订落点：① 版块05 AI计费新增「积分抵扣」Tab（位于额度包商品之后、计量流水之前，计量流水/用量看板顺延为 Tab 5 / Tab 6）——含可手动配置的汇率表单（积分面额 × Token 数，保存留痕）、抵扣范围（仅限平台公共模型，自定义模型不可用）、扣减顺序（积分优先 → 套餐内含 → 额度包 → 超额计费）、积分抵扣流水与租户余额映射示例；② 版块05 计量流水「来源」列升级为扣减来源四标签（套餐含量 / 额度包 / 积分抵扣 / 超额计费）；③ 版块05 用量看板新增消耗来源结构与积分抵扣占比；④ 版块06 老带新台账积分出口补「AI 用量抵扣」类型示例。规则要点：汇率由平台管理员手动配置，调整仅对新消耗生效（消耗时锁定汇率、不追溯）；抵扣不可退、不可转赠；老带新积分冲回时若已消耗，从后续获取积分中扣减。所有修订处均带 v1.2 角标，可对照 v1.1 逐处核验。
v1.3V1.3 定向修订：新增「代理商管理」版块（第 16 版块，代理商配置 + 代理商分润两大区域）。修订落点：① 代理商配置——列表页（代理商名称 / 等级 / 授权区域 / 联系人 / 发展商户数 / 累计销售额 / 累计分润 / 状态）与右上角「开通代理商」入口；开通 / 编辑表单（基本信息、授权区域省市区多选、层级选择一级 / 二级、专属推广码自动生成、签约有效期、结算账户）；层级权益配置卡（可售套餐范围按套餐模板勾选、拿货折扣区间、是否允许发展下级代理开关）。② 代理商分润——分润比例矩阵（行 = 代理商层级、列 = 套餐档位、单元格可输入比例，未配置完整时整体置灰并提示「请先配置分润比例」，呼应平台「比例不内置定死、手动配置」原则）；分润模式开关行（新签订单开 / 续费订单关附比例 / 增值收入关）；计算基数说明（分润基数 = 订单实收现金金额，积分抵扣部分与平台券部分不计入，与 v1.2 积分抵扣机制咬合）；结算规则（账期月结 / 季结、提现门槛、结算方式）；分润台账（待结算 / 已结算 / 已冲回）；结算管理（待结算汇总、按账期生成结算单、提现申请审核）；冲退规则（商户退款或订单作废 → 分润自动冲回）。③ 双轨归因：老带新 = 商户侧积分奖励（营销成本线）、代理商分润 = 现金分佣（渠道成本线），两条线并存互不替代；同一商户同时存在两种归因时，代理商邀请优先于老带新归属。所有修订处均带 v1.3 角标，可对照 v1.2 逐处核验。

运营大盘 Operations Dashboard

平台首屏驾驶舱：六项核心指标卡 + 租户增长趋势 + 套餐分布 + 收入构成，右侧常驻待办事项与系统健康状态。所有指标只聚合不下钻，页脚固定口径声明；底部新增报表导出卡（租户财务报表 / 资源消耗报表，v1.5）。

02

租户管理 Tenant Management

租户全生命周期驾驶舱：多维筛选 + 列表行内操作（详情 / 续费 / 冻结 / 模拟登录 / 概况 / 数据导出 / 重置数据）。右侧演示详情抽屉展开态——基础信息、6 项配额进度、套餐变更时间线与模拟登录审批提示。状态色规范：正常 欠费 冻结 已注销。下方第二张界面图为 v1.5 新增的模拟登录确认 / 数据重置 / 数据导出 / 租户概况四个弹窗 v1.5

03

套餐管理 Plan Engine

套餐即引擎：不内置固定套餐，任何套餐都由平台自主创建（定价 / 周期 / 功能开关矩阵 / 资源配额 / 升降级规则五段式配置），当前预置的免费/基础/标准/旗舰模板仅是可编辑、可停用的初始数据——改配置即改商品。右侧演示「新建套餐」滑出表单。

04

租户账单计费 Billing & Settlement

「能收费、能对账、能催缴」的资金闭环：账单总览指标 + 四个 Tab（账单流水 / 欠费管理 / 对账中心 / 增值扣费 v1.5）。为便于开发一次看全，设计稿将四个 Tab 面板纵向铺开呈现，每个面板标注所属 Tab，实际界面为点击 Tab 切换。增值扣费与 AI 超额逐笔可查，日对账差异 <0.1% 告警。

05

AI 中心 · 计费管理 AI Metering & Billing

大模型计费完整链路：① 模型接入（单价）→ ② 计费策略（套餐倍率 + 免费赠送）→ ③ 额度包商品 → ④ 积分抵扣（积分按汇率冲抵结算）→ ⑤ 计量流水（逐次计量）→ ⑥ 用量看板。密钥由平台托管不落地，所有租户请求经 AI 网关转发计量，额度不足在网关层直接拒绝。设计稿将 6 个 Tab 纵向铺开，实际界面为 Tab 切换。v1.2

06

营销 · 渠道推广 Growth Marketing

增长引擎：渠道推广码（注册自动归因）+ 老带新台账（奖励 = 实付 × 20%，年度上限 60,000 积分，7 天冷静期，退款/注销自动冲回）。弹窗演示「生成推广码」。

07

平台管理员权限 Admin & RBAC

RBAC 三级权限（菜单 → 页面 → 按钮级）+ 数据范围权限。内置四类角色（超管/运营/财务/客服，不可删除）；「平台管理员账号与角色」仅超级管理员可操作；高危操作（删租户/改价格/吊销密钥）一律二次确认 + 留痕。弹窗演示「邀请管理员」。

08

系统配置 Global Settings

全平台唯一配置源：基础信息 / 功能开关 / 数据字典 / 第三方对接。租户实际可用功能 = 全局开关 ∩ 套餐开关 ∩ 租户级开关；密钥展示脱敏（前 4 后 4），修改需密码 + 验证码双因子；对象存储含租户存储上限与三档超额预警，短信 / 邮件通道支持租户自有密钥开关（v1.5）。

09

模板中心 Templates

一键开店的支撑层：初始化模板（编号规则 / 单位换算 / 打印模板 / 默认仓库账户体系）在开户时值复制给租户（复制而非引用，模板后续修改不回写已开户租户）；打印模板可设为公共模板供全部租户选用；新建租户支持一键套用初始化模板，数据导入 / 导出模板双侧齐备（v1.5）。

10

运维 · 监控告警 Monitoring & Audit

平台健康度总览：API 监控（请求量 / 成功率 / P95 耗时 / 异常接口 TOP）+ 各租户 API 调用量统计与超限告警阈值配置（v1.5）+ 存储监控（租户占用排行与超额红色预警）+ 日志中心三 Tab（管理员操作 / 租户登录 / 系统错误，仅追加不可删改）+ 代登录审计独立 Tab（五步审计法：申请→审批→限时会话→留痕→回放）。

11

公告管理 Announcements

官方触达通道：向全部或指定租户推送公告（站内 + 短信可勾选），支持定时发布、撤回、已读统计与按标签/套餐圈选。群发超过全量租户 50% 需强制预览 + 二次确认，发布后 10 分钟内可一键撤回；发布表单必选公告类型（版本更新 / 维护通知 / 欠费提醒 / 营销活动 / 运营通知）与推送范围 v1.5。弹窗演示「新建公告」。

12

工单系统 Ticket Desk

有 SLA 的服务闭环：待处理 / 处理中 / 已解决列式看板，卡片带分类徽标与 SLA 剩余时间条（故障类首响 2h / 解决 8h；功能类首响 8h / 解决 3 个工作日）。右侧演示工单详情：对话时间线（公开回复 / 内部备注分色）+ 状态流转。免费版仅可提交故障类工单（每周 ≤2 个）。

13

版本发布 Release & Canary

灰度可控、可回滚：三档灰度策略（内测标签租户 → 旗舰等指定租户 → 按百分比），内测租户运行 ≥48h 且无 P0/P1 告警方可放量；批次错误率超阈值自动暂停。发布完成自动生成更新公告（联动公告管理）。弹窗演示「新建发布向导」。

14

开放平台 Open Platform

生态能力储备：租户 API 密钥治理（签发 / 轮换 / 吊销，Secret 仅签发时可见，调用计入套餐 API 额度）+ Webhook 事件订阅（失败重试 3 次：1min/5min/30min 指数退避，连续失败自动暂停订阅）。签名 HMAC-SHA256 + 时间戳 ±5 分钟防重放。弹窗演示「签发密钥」。

15

登录页 Sign In

分栏式登录页：左侧品牌区（logo + slogan + 抽象网格插画风背景）承载产品价值感，右侧登录表单（账号密码 + 图形验证码，预留短信登录与 2FA 扩展）。登录安全策略：连续 5 次失败锁定 15 分钟；会话空闲 30 分钟自动登出。

16

代理商管理 Agent & Reseller v1.3 新增

渠道伙伴现金分佣体系：① 代理商配置（列表 / 开通表单 / 授权区域 / 层级权益）+ ② 代理商分润（比例矩阵 / 模式开关 / 台账 / 结算 / 冲回）。分润比例不内置定死，由平台手动配置，矩阵未配置完整时分润整体不生效；分润基数 = 订单实收现金金额（积分抵扣与平台券部分不计入，与 v1.2 积分抵扣机制咬合）。设计稿将两个子页面纵向铺开，实际界面为子菜单切换。

17
