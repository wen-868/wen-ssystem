### 7. P1-3 头像首字取值未判空（6 处加固）

## 四、待决策事项（未单方面改动）

1. **费用「驳回」语义**（`expenses.vue` / `expense-detail.vue`）
   后端只有 `PENDING / APPROVED / VOIDED`，**没有 REJECTED 状态**，也没有驳回接口；原实现 `POST /:expenseNo/approve {status:'REJECTED'}` 会被后端忽略并**直接把费用置为已通过**（数据风险）。本轮已改为调用 `POST /:expenseNo/void`（状态置 `VOIDED`），先消除误审批风险。请选择：
   - ① 后端新增 `rejectExpense` 接口与 `REJECTED` 状态（推荐，语义正确）；
   - ② 前端把按钮文案改为「作废」，与后端能力对齐（最小改动）。
2. **优惠券「详情 / 编辑」为假功能**：`coupons.vue` 的 `viewDetail / editCoupon` 目前仅弹 toast（无页面跳转）。需要新建券详情页与编辑页（或复用 `create-coupon` 增加编辑模式）。
3. **「已结束」Tab 的筛选方式**：后端无 `ENDED` 枚举，当前按有效期在前端本地过滤（分页语义为"每页过滤"）。如需精确分页，建议后端按下发 `valid_end < NOW()` 支持 `ended` 查询参数。
4. **后端改动未部署**：`getOrderDetail` 补字段需部署后生效（git pull → `cd backend && npm run build` → `pm2 restart zhixiang-api` → 校验 `/health` 200）。
5. **构建备份目录清理**：`dist.bak.* / dist.old* / dist_build_bak / app_bak_*` 多个目录（约 3.5GB）待确认是否删除。
